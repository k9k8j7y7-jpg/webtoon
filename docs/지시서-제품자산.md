# 지시서 — 제품 자산 (실사 제품을 웹툰 컷에 넣기, 참조 생성 방식)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업

> "실행해". 테스트는 **새 비공개 에피소드 "제품 테스트"**로만 — "자연바람
> 아로마 헤어팩 광고"(ep30, 랜딩 참조)는 절대 손대지 않음.

> [근거] 도도 — 광고 포지션의 핵심은 "우리 제품이 그대로 나오는가". scratch
> 결과(A 참조 생성, gpt-image) 라벨 "SCALP SUPPORT OIL+ / 170g" 판독·색·
> 비율 OK → **"광고주가 제품을 이해시키기엔 충분" 판정**. 제품 디테일
> 컷은 실사 사진 컷(기존 product_items 오버레이·사진 첨부)으로.

> 보류(정밀 모드 백로그).

## 목표 (도도가 화면에서 보게 되는 것)
- STEP 3 자산 준비에 **"제품" 섹션이 광고형 아니어도 항상** 보임. [제품
  추가] → 사진(필수) + 들고 찍은 사진(선택 "크기를 자동으로 맞춰요") →
  [분석] 2초 → 이름·색·라벨 글자·형태·크기가 채워져 나옴 → 확인·수정 →
  저장. 카드엔 누끼 썸네일 + "병 · 한 손 크기"
- STEP 4 콘티 컷 카드마다 **"제품 등장"** 토글(자동 검출된 건 켜져 있고
  수동으로 끄고 켬) + 상단 "8컷 중 3컷에 제품"
- STEP 5 제품 등장 컷엔 📦 배지. 생성·재생성 때 제품 사진이 참조로 **항상**
  들어감(2인 컷이어도 탈락 안 함)
- **빠른 한 컷**에 "제품 사진 (선택) — 모델이 들고 있게 그려요" 한 칸.
  올리면 결과가 "내 제품 든 컷". 1패킷 그대로
- 컷 편집기의 기존 실사 제품 오버레이는 **"실사 제품 올리기"**로 이름
  명확히(디테일 컷용)

## 1단계 — 백엔드
- **마이그레이션 step34**: products에 `description TEXT`(자동 추출 요약:
  색·라벨 글자·재질), `shape VARCHAR(20)`(bottle/can/box/tube/flat/
  pouch/other), `size_hint VARCHAR(20)`(palm/one_hand/two_hands/
  tabletop/large), `size_ratio FLOAT NULL`(제품 높이 ÷ 손 길이, 들고
  사진에서), `holding_photo_url VARCHAR NULL`, `label_text TEXT`(라벨에
  적힌 글자 그대로). 기존 features는 유지(메모)
- **POST /products/{id}/analyze** (0패킷, gemini-2.5-flash 비전):
  photo_url → {name 후보, colors, label_text, shape, size_hint 추정,
  description}. holding_photo_url 있으면 손 길이 대비 제품 높이로
  size_ratio 계산(MediaPipe Hands 가능하면 사용, 아니면 비전 모델 추정)
  → size_hint도 ratio로 보정(<0.5 palm, 0.5~1.3 one_hand, 1.3~2.5
  two_hands, 그 이상 tabletop/large). 응답은 저장 전 "제안"이고 사용자
  확인 후 PUT로 저장
- **누끼 썸네일**: 등록 시 rembg(흰 배경이면 PIL 임계) → sheet_url 또는
  thumb_url. product_items 오버레이도 이 누끼를 기본으로
- **프롬프트 한 곳** `app/prompts/product.py`: build_product_clause(product)
  → "Include this exact product (reference image): {name}, {shape},
  colors {colors}. Keep the label text exactly as '{label_text}'. Size:
  {size 상대 표현 — palm-sized / fits in one hand / held with both hands /
  tabletop}. Do not redesign the packaging." 기존 product_desc 주입을 이
  함수로 교체
- **참조 슬롯 규칙**(5장 한도): has_product 컷은 제품 사진을 **2순위**
  (캐릭터 시트 1장 다음)로 고정. 나머지 슬롯에 표정·장소. 2인 이상이면
  표정 참조 1장으로 줄임. 어떤 참조가 들어갔는지 generation_logs에 기록
- **has_product 수동**: cut spec `has_product` 사용자 override 필드
  (null=자동 검출 따름, true/false=수동). 콘티 저장 API에 반영. 자동 검출
  (_detect_product_in_cut)은 그대로
- **비광고 허용**: 백엔드 가드 없음 확인(dead import 정리). 대본·콘티
  프롬프트에서 제품 정보 주입은 **광고형이면 AD_ADDON 그대로**, 비광고면
  "등장 제품: {name}(소품으로 자연스럽게)" 한 줄만
- **빠른 한 컷**: QuickRequest에 `product_photo`(선택) → "빠른 컷"
  프로젝트에 products 행 생성 + analyze 자동 → ref 1슬롯 + product
  clause. 장면 문구에 제품 언급 없으면 "{name}을(를) 들고" 자동 보강.
  패킷 1 유지
- generation_logs에 refs(어떤 참조 들어갔는지)·product_id 기록

## 2단계 — 프론트
- **Gate3 제품 섹션** 항상 표시(isAd 조건 제거). 카드: 누끼 썸네일·이름·
  형태·크기 칩. [제품 추가] 모달: ① 제품 사진 업로드(필수, "흰 배경이면
  더 좋아요") ② 들고 찍은 사진(선택, "크기를 자동으로 맞춰요") ③ [분석]
  → 결과 폼: 이름(input) · 색(칩) · 라벨 글자(textarea, "이 글자가 그림에
  그대로 들어가요") · 형태(칩 7) · 크기(칩 5, 들고 사진 있으면 자동 선택
  + "손 길이의 1.2배") → [저장]. 편집도 같은 모달
- **Gate4 콘티** 컷 카드: "📦 제품 등장" 토글(자동 ON이면 "자동" 작은 표시),
  상단 요약 "N컷 중 M컷에 제품". 제품 없는 에피소드엔 토글 숨김
- **Gate5** 카드 📦 배지, 재생성 드롭다운에 "제품 참조 포함" 체크(기본 ON)
- **빠른 한 컷**: 캐릭터 선택 아래 "제품 사진 (선택)" 업로드 1칸 +
  썸네일, 올리면 장면 플레이스홀더가 "제품을 들고 웃는다 / 제품을 손님에게
  건넨다"로 바뀜. 결과 화면 그대로
- **컷 편집기**: product_items 버튼 라벨 "실사 제품 올리기"(툴팁 "제품
  사진을 그대로 얹어요 — 디테일 컷용")
- 폰 375·412 다크. 업로드는 기존 이미지 업로드 컴포넌트 재사용
