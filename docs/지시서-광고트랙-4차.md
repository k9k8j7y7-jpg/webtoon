변화 없음)에 빨간 "이미지 생성 0/4 (0%)" 박스. 3차에서 "idle 시
비표시"로 고쳤는데 그대로. → **원인 먼저**: 콘티 자동 생성(approve_
assets → auto storyboard → gate4 auto)이 jobs에 pending/queued 행을
만들어 두는지, 아니면 프론트가 마지막 job을 status 무관하게 보여주는지
조사 후 보고. 수정은 원인에 맞게 — pending 행이면 생성 버튼 누를 때
만들도록, 프론트면 status in (running, done-3초) 만 표시. 재현: 새
인스타툰 → 승인 → 완성 첫 화면 캡처(패킷 변화 0).

**(52) 문구 두 개** — ① 새 에피소드 모달 컷 수 칩 부제 "훅·문제·해결·
CTA / +포인트·사용법 / 자세히"가 암호 같음 → **4컷 "짧고 강하게" /
6컷 "장점·쓰는 법까지" / 8컷 "차근차근 자세히"**. 연재툰 6·8·10도 같은
말투("6컷 한 편 기본 / 8컷 여유 있게 / 10컷 길게"). ② 대본 카드 1컷의
훅 문구 라벨이 "나레이션"으로 보임 → **"훅"** 라벨(다른 색). 마지막 컷
헤드·서브는 "카피" 라벨.

**(53) 장소 칩 표시** — 씬 칩 "📍 도심 거리" 하나인데 컷은 거리→거실→
샤워→거울로 이동. 배경은 컷 설명이 우선이라 그림은 맞게 나옴(ep 확인).
→ 광고 트랙은 칩을 **"📍 도심 거리 외 3곳"**(컷별 장소가 2개 이상이면)
으로. 컷별 장소는 대본 생성 결과에서 추출해 cut.location_hint로
저장(이미 action에 있으면 그대로, 추출만). 이미지 프롬프트 변경 없음.

**(54) 인스타툰·연재툰 카피 글씨체 선택** — 한 컷엔 대본 카드 "카피

단어)이 있는데 인스타툰·연재툰엔 없어 손글씨 고정. → **같은 줄을
인스타툰·연재툰 대본 카드에도 노출**. 저장 위치 동일(copy_design),
1컷 훅과 마지막 컷 카피에 **같이** 적용. 강조 단어 칩은 마지막 컷
헤드카피 단어로. 재생성 드롭다운 "카피 디자인 바꾸기" 링크도 노출.

**(55) 재생성 진입 방식** — [재생성]은 즉시 실행, 옆 ▾로만 메모 시트.
