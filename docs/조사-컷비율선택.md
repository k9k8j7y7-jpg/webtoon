# 조사 — 에피소드 컷 비율 선택 (1:1 / 9:16)

> 2026-09-15 조사 완료. 구현 지시 대기.

## 배경

신모델(gemini-3.1-flash-image)이 비율을 실제 준수하면서 기존 정사각 에피소드와 새 세로 컷이 섞이는 문제 발생. 해결책: 에피소드별 비율을 생성 시작 전에 선택 + 첫 생성 후 잠금.

## 1. aspect_ratio 경로 전수

| 구간 | 현재 상태 | 수정 필요 |
|---|---|---|
| **gemini_image.py `generate_image()`** | `aspect_ratio` 파라미터 받지만 **Gemini API config에 미전달** (버그) | `image_config={'aspect_ratio': ar}` 추가 |
| **컷 생성 (`images/service.py`)** | `generate_image()` 호출 시 aspect_ratio 미전달 → 기본 "9:16" | 에피소드 비율 읽어서 전달 |
| **프롬프트 (`prompts/service.py`)** | `"vertical scroll format"` 하드코딩 (line 143) | 1:1 시 `"square format"` 등으로 분기 |
| **캐릭터 시트** | 1:1 고정 (`gemini_image.py:100,117`) | **변경 불필요** (시트는 항상 정사각) |
| **장소 레퍼런스** | 16:9 고정 (`gemini_image.py:133`) | 에피소드 비율에 따라 분기 (16:9 또는 1:1) |
| **BubbleOverlay/SfxLayer** | SVG 기반, 좌표 0~1 정규화 | **영향 없음** |
| **EffectLayer** | x/y/width 모두 0~1 정규화 | **영향 없음** |
| **CutEditor 캔버스** | 이미지 naturalWidth/Height에서 동적 계산 | **영향 없음** |
| **Export 4경로** | PNG/세로=원본비율 유지, 인스타=1:1 크롭, A4=비율 유지 fit | **영향 없음** |

## 2. 비율 저장 위치

`episodes.gate_status`가 JSON 컬럼 → **마이그레이션 없이 필드 추가 가능**.

```json
{
  "aspect_ratio": "9:16",
  "aspect_ratio_locked": true,
  "gates": { ... }
}
```

## 3. 배경효과 PNG + 1:1 컷

EffectLayer는 `item.width`(0~1) × 실제 이미지 너비로 크기 결정. aspect ratio는 PNG 원본에서 계산. 1:1 컷에서 9:16 효과 PNG는 세로로 길게 나올 뿐 늘어나지 않음(width 기준 비례 축소). 특별 처리 불필요.

## 4. 기존 에피소드 소급

- 이미지가 1건이라도 있는 에피소드 → `aspect_ratio` 미설정 시 `"1:1"` 간주 (기존 정사각 이미지 호환), 자동 잠금
- 새 에피소드 → 기본 `"9:16"`
- 잠금: `aspect_ratio_locked = true` (첫 이미지 생성 시 백엔드에서 설정)

## 5. 핵심 발견: Gemini API aspect_ratio 미전달 버그

`aspect_ratio`가 `generate_content()` config에 전달되지 않고 있었음. 3.1 모델이 비율을 준수한 건 프롬프트의 `"vertical scroll format"` 지시와 모델 기본 동작 덕분.

SDK 확인 결과 `image_config` 필드로 전달 가능:
```python
config=types.GenerateContentConfig(
    response_modalities=["IMAGE", "TEXT"],
    image_config={"aspect_ratio": "9:16"},  # ← 추가
    ...
)
```

## 구현 계획

### 백엔드
1. **gemini_image.py**: `image_config={'aspect_ratio': ar}` config에 추가
2. **gate_status JSON**: `aspect_ratio` + `aspect_ratio_locked` 필드 (마이그레이션 불필요)
3. **images/service.py**: 에피소드에서 비율 읽어 `generate_image(aspect_ratio=...)` 전달
4. **prompts/service.py**: 비율별 프롬프트 분기 (vertical scroll format / square format)
5. **locations/service.py**: 에피소드 비율 전달 (16:9 or 1:1)
6. **잠금 검증**: 이미지 생성 시 aspect_ratio_locked 체크, 비율 변경 거부

### 프론트엔드
7. **Gate3 UI**: 스타일 선택 옆 "컷 비율" 선택 (1:1 / 9:16) + 잠금 상태 표시 + 경고 문구("첫 이미지 생성 후 변경 불가")

### 변경 불필요 확인
- 캐릭터 시트: 1:1 고정 유지
- BubbleOverlay/SfxLayer/EffectLayer: 0~1 정규화 좌표 → 비율 무관
- CutEditor: naturalWidth/Height 동적 계산 → 비율 무관
- Export 4경로: 원본 비율 유지 또는 자체 크롭 → 비율 무관
