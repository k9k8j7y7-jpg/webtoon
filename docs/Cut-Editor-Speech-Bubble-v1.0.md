# Project T — 컷 편집화면 (말풍선 편집) 수정 지시서

> **버전:** v1.0
> **작성일:** 2026-08-01
> **대상:** Claude Code
> **참조 문서:** docs/ 의 Cut-Spec-Schema-v1.0, Korean-Text-Speech-Bubble-System(말풍선 12종), 전역 원칙(사용자 편의)
> **범위:** 게이트 5 이미지 미리보기를 "컷 편집화면"으로 확장. 말풍선을 위치·꼬리·크기·종류·텍스트까지 편집. **1단계(말풍선)만.** 효과음·배경효과는 다음 단계.
> **중요도:** ★최상위. 말풍선 배치가 "누가 말하는지" 안 보이면 웹툰이 성립 안 함. 사용 여부를 가르는 핵심.

---

## 배경 및 핵심 방침

**문제:** 말풍선이 무조건 컷 상단에 세로로 쌓임. 다인 컷(예: 준호+민영)에서 누가 무슨 말을 하는지 위치·꼬리로 구분이 안 됨. 실제 웹툰은 말풍선이 화자 근처에 있고 꼬리가 화자를 가리킴.

**근본 한계:** AI가 그린 이미지에서 인물 좌표를 알 수 없음 → 완벽한 자동 배치 불가. **해결책은 사용자 수동 조정.** (상용 웹툰 도구도 사람이 수동 배치)

**핵심 방침:**
- 이미지(그림)는 **재생성으로만** 변경. 편집화면에서는 **그 위 말풍선 레이어만** 편집.
- 말풍선은 코드(SVG)로 얹으므로, 편집·저장 시 **이미지 재생성 없음(과금 없음).**
- 자동 배치는 "그럴듯한 시작점"만 제공, 완벽은 사용자가 수동으로 다듬음.

---

## A. 진입 — 미리보기를 편집화면으로

## A-1. 진입 UI
- 현재 컷 이미지의 "+" 아이콘(미리보기 진입)을 **직관적 텍스트 버튼**으로 변경.
  - 예: **[미리보기]** 또는 **[컷 편집]** (아이콘 + 텍스트).
- 클릭 시 전체화면으로 컷이 크게 뜸.

## A-2. 보기/편집 모드 분리 (실수 방지)
- 전체화면은 먼저 **"보기 모드"**로 뜸 (크게 감상만).
- 화면에 **[편집]** 버튼 → 클릭 시 **"편집 모드"**로 전환.
- 편집 모드에서 말풍선 조정 가능. **[저장]**/**[취소]** 버튼.
- 이유: 단순히 크게 보려는 사용자가 실수로 편집하지 않도록.

---

## B. 말풍선 편집 (편집 모드에서)

편집 모드에서 각 말풍선을 다음 5가지로 조정:

## B-1. 위치 이동 (드래그) — 필수
- 말풍선을 **마우스/터치로 드래그**해서 컷 안 어디든 이동.
- 화자 근처로 옮겨 "누가 말하는지" 명확하게.

## B-2. 꼬리 방향
- 말풍선 꼬리가 **어느 방향(캐릭터)을 가리킬지** 조정.
- 방식: 꼬리 끝점을 드래그하거나, 방향(상/하/좌/우) 선택.
- 나레이션(자막)은 꼬리 없음 — 해당 없음.

## B-3. 크기 조정
- 말풍선 크기를 키우거나 줄임 (모서리 핸들 드래그 등).
- 텍스트가 넘치지 않는 최소 크기는 보장.

## B-4. 종류 변경 (12종)
- 기존 아이콘 팔레트(Korean-Text-Speech-Bubble-System B-3) 재사용.
- 편집 모드에서 말풍선 선택 → 팔레트로 12종 중 교체.

## B-5. 텍스트 수정
- 말풍선 안 텍스트를 직접 수정 (기존 대사 편집 재사용).

---

## C. 자동 배치 (기본값) — 화자 기반

편집화면 진입 전, 말풍선이 처음 놓이는 위치를 개선. 지금은 무조건 상단 → 화자 기반으로.

## C-1. 좌우 배치 규칙
- 컷의 dialogue 화자(speaker) 정보를 기준으로:
  - **화자 1명:** 상단 중앙 (또는 인물 반대편)
  - **화자 2명:** 첫 화자 = 좌측, 둘째 화자 = 우측 (좌우로 분리)
  - **화자 3명+:** 순서대로 좌→우 분산, 겹치면 세로 오프셋
- 완벽한 인물 위치 매칭은 불가하므로 "그럴듯한 시작점"만 제공. 정확한 위치는 사용자가 B-1로 조정.

## C-2. 꼬리 방향 자동
- 좌측 배치 말풍선 → 꼬리 아래/우측 (화면 안쪽 향함)
- 우측 배치 말풍선 → 꼬리 아래/좌측
- 기본값일 뿐, 사용자가 B-2로 조정 가능.

## C-3. 나레이션
- 나레이션(type=narration)은 화자 배치와 무관하게 **하단 자막**으로 (기존 유지).

---

## D. 긴 대사 처리 — 문장 단위 분할 + 세로 연결

기존 문제: 긴 대사가 말풍선 2개로 어색하게 뚝 끊김.

## D-1. 문장 단위 분할
- 긴 대사는 **문장 단위(마침표·물음표·느낌표 기준)로 분할**해 여러 말풍선으로.
- 각 말풍선이 완결된 문장이라 자연스러움.

## D-2. 세로 연결 (같은 화자)
- 같은 화자의 연속된 말풍선은 **세로로 가깝게 붙여** "이어 말하는" 느낌.
- 첫 말풍선만 꼬리 있음, 이어지는 건 꼬리 없이 세로로 연결(또는 얇은 연결).

## D-3. 사용자 조정
- 이건 자동 기본값. 사용자가 편집 모드에서 각 말풍선을 개별 이동/조정 가능.

---

## E. 저장 / 데이터

## E-1. 컷 명세 확장 (Cut-Spec)
dialogue에 말풍선 위치·크기·꼬리 정보 저장:
```jsonc
"dialogue": [
  {
    "order": 1, "type": "speech", "speaker": "junho",
    "text": "고마워요, 누나.",
    "bubble_style": "round",
    "bubble_layout": {
      "x": 0.15, "y": 0.7,        // 컷 대비 상대 좌표(0~1)
      "width": 0.3,                // 상대 크기
      "tail_direction": "down-right" // 꼬리 방향
    }
  }
]
```
- 좌표는 **상대값(0~1)**으로 저장 (컷 크기 달라도 유지).
- `bubble_layout`이 없으면 자동 배치(C) 적용, 있으면 사용자 지정 위치 사용.

## E-2. 저장 = 레이어만
- 저장 시 **말풍선 레이어만 다시 렌더링**. 이미지 재생성 없음 → 과금 없음.
- 저장하면 게이트5 컷에 즉시 반영.

## E-3. Export 반영
- 세로/인스타/PNG Export 시 편집된 말풍선 위치 반영.

---

## 범위

**이번 (1단계):** 컷 편집화면 + 말풍선 편집(위치·꼬리·크기·종류·텍스트) + 화자 기반 자동배치 + 긴 대사 처리 + 저장.

**다음 (2단계, 별도 지시서):** 효과음 텍스트("쾅" 등) 얹기.

**다음 (3단계, 별도 지시서):** 배경 효과(관리자 템플릿 업로드 → 사용자 선택).

**V2:** AI 인물 위치 인식 자동배치, 실시간 미리보기.

---

## 검증

1. 컷 이미지에 [미리보기]/[컷 편집] 텍스트 버튼이 보이나?
2. 클릭 → 보기 모드로 크게 뜨나? [편집] 버튼으로 편집 모드 전환되나?
3. 편집 모드에서 말풍선을:
   - 드래그로 이동되나? (B-1)
   - 꼬리 방향 바뀌나? (B-2)
   - 크기 조정되나? (B-3)
   - 종류 교체되나? (B-4, 팔레트)
   - 텍스트 수정되나? (B-5)
4. 다인 컷(준호+민영) 진입 시 말풍선이 좌우로 나뉘어 배치되나? (C-1)
5. 긴 대사가 문장 단위로 나뉘고 같은 화자는 세로 연결되나? (D)
6. 저장 → 이미지 재생성 없이 말풍선 위치가 반영되나? (E-2)
7. 저장한 위치가 다시 열었을 때 유지되나? (E-1 상대좌표)

## 참고 (전역 원칙)

- 편집화면은 초보도 직관적으로. 드래그·핸들 등은 조작법이 명확하게(안내 툴팁 등).
- "이미지는 안 바뀌고 말풍선만 편집된다"는 걸 사용자가 이해하도록.
