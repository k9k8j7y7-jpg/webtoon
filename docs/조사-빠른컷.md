# 조사 — "빠른 한 컷" 모드 (0단계)

> 2026-10-20 · 코드 변경 없음

## 1. 에피소드 생성 최소 요건 + gate_status 자동 채움

**프로젝트:** `title` 필수. 나머지 선택.
**에피소드:** `episode_no` 필수. `title`, `idea` 선택.

**gate_status 초기값** (`workflow/gate.py:4-36`):
- `current_gate: 1`, 모든 게이트 `status: "locked"` (1만 `"draft"`)
- `aspect_ratio: "9:16"`, `page_format: "vertical"`

**게이트5 접근 조건:** `current_gate == 5` → 게이트 1~4를 순서대로 `approve_gate()` 호출해야 함 (1→2→3→4). 직통 shortcut API 없음 — **DB에서 gate_status JSON을 직접 세팅하는 것이 유일한 우회**.

**단일 컷 생성 API:**
- `POST /cuts/{cut_id}/regenerate` → `generate_cut_image()` 직접 호출, 1패킷 차감. 게이트5 체크 없음(컷 존재만 확인)
- `generate_cut_image()` (`images/service.py:279-508`) — 독립 함수, 배치의 반복 단위와 동일

**결론:** 빠른 컷에서는 DB에 gate_status를 게이트5 완료 상태로 직접 INSERT하고, Cut 1개를 수동 spec으로 INSERT한 뒤, `generate_cut_image()` 또는 `/cuts/{id}/regenerate` 호출로 1패킷 생성 가능. 별도 "빠른 컷 전용" 백엔드 엔드포인트를 1개 만드는 것이 깔끔.

## 2. 콘티 없이 컷 spec 직접 생성 → build_cut_prompt

**Cut 모델** (`storyboard/models.py:12-33`): `cut_id`, `episode_id`, `scene_id`, `cut_number`, `spec`(JSON) 필수. `status` 기본 `"pending"`. DB 스키마 강제 없음 — ORM INSERT 가능.

**최소 spec:**
```json
{
  "cut_id": "quick_c001", "scene_id": "s01", "cut_number": 1,
  "characters": [{"character_id": "hero", "emotion": "neutral", "pose": "", "outfit": "default"}],
  "shot": "full", "action": "사용자가 입력한 한 줄 장면",
  "dialogue": [], "emphasis": "normal", "has_product": false,
  "location_id": null, "prompt_override": null, "status": "pending"
}
```

**`build_cut_prompt()` 입력** (`prompts/service.py:60-278`):
- `cut_spec`: 위 구조 (action·shot·characters·emphasis 등)
- `character_descs`: `{ref_key: {name, appearance_en, is_photo_real, ref_images}}`
- `location_desc`: 장소 텍스트 (없으면 None)
- `style_prompt`: 스타일 프리셋 문자열
- `aspect_ratio`: 비율 문자열

**결론:** 콘티 생성 없이 action="사용자 한 줄" + 캐릭터 1명 + 스타일로 spec을 수동 구성 → build_cut_prompt → 이미지 생성 가능.

## 3. 캐릭터

**시스템 공용 프리셋 캐릭터: 현재 불가.**
- `Character.user_id`는 라이브러리 승급 플래그, `episode_id`는 NOT NULL FK
- `/characters/link` 가드: `character.project_id == project_id OR character.user_id == current_user.id` (403)
- `user_id=NULL` + `project_id=NULL` 캐릭터는 link 거부됨
- **추가 필요:** 시스템 유저(id=0) 또는 `is_preset=True` 플래그 + link 가드 예외

**실사 캐릭터:** 0패킷 (사진 업로드만, 시트 미생성). 빠른 컷에 재사용 가능하되, GPT 모델 전환(전 컷 OpenAI) 비용·시간 이슈.
**일반 캐릭터 시트:** 2패킷 + 생성 시간 ~40초 → 빠른 컷의 "10초 맛보기" 취지와 충돌.

**빠른 컷 추천 경로:** (A) 시트 없이 appearance_en 텍스트만으로 생성 (시트 참조 없음 = 일관성 낮지만 한 컷이라 무관) 또는 (B) 프리셋 캐릭터 사전 생성(시트 포함) → 모든 유저가 참조.

## 4. single_page + 컷 1개 동작

**pageFormats.js:** `single_page = { cols:1, rows:1, cell_ratio:null, per_page:1 }` — 컷의 실제 비율 사용.

| 영역 | 1컷 동작 |
|---|---|
| **뷰어** | 1페이지 1컷 정상 렌더 |
| **게이트5 미리보기** | `pageCount = ceil(1/1) = 1` 정상 |
| **편집기** | `hasPrev=false`, `hasNext=false`, "#1/1" 표시 정상 |
| **인스타 공유** | 1장 blob 반환 (ZIP 미생성), 정상 |
| **내보내기** | vertical 경로도 single_page 경로도 1장 정상 |

**결론:** 1컷 에피소드는 현행 뷰어·편집기·인스타·내보내기 모두 정상 동작. 추가 코드 불필요.

## 5. "이야기로 늘리기" — STEP 1 승계

**planning_draft 구조** (`story/router.py:160-188`):
```json
gate_status.planning_draft = {
  "genre": str,
  "mood": str,
  "development": str,
  "characters": [{"name": "...", "description": "...", "gender": "...", "age": "..."}]
}
```
**idea_brief:** `gate_status.idea_brief = {"raw": "사용자 한 줄"}`

**승계 방법:**
1. 빠른 컷에서 입력한 한 줄 → `idea_brief.raw`에 세팅
2. 캐릭터 이름·설명 → `planning_draft.characters` 배열에 세팅
3. `current_gate`를 1로 되돌림 (`revert` API 사용 가능: `POST .../revert?to_gate=1`)
4. 게이트1 UI에서 기획 생성 시 idea_brief + characters 주입됨 (기존 흐름)

**캐릭터 DB 연결:** 빠른 컷에서 만든 Character 레코드(episode_characters)가 있으면, `revert` 시에도 유지됨. 게이트3에서 시트 생성 시 기존 연결 캐릭터 시트를 재활용.

**결론:** revert API로 게이트1로 되돌리고, gate_status에 idea_brief·planning_draft를 미리 채워두면 자연스럽게 정식 흐름 진입 가능.

## 6. 입구 배치 + 비로그인 흐름

**현재 생성 흐름:** 랜딩 → 로그인 → /my (대시보드) → 프로젝트 생성/선택 → 에피소드 생성(단편/연작/광고) → 워크플로. **최소 3번 내비게이션.**

**입구 배치 후보:**
| 위치 | 구현 |
|---|---|
| **랜딩 Hero CTA** | 기존 "무료로 시작하기" 옆 또는 대체 — "빠른 한 컷 만들기" |
| **랜딩 결과물 아래** | "지금 바로 만들어 보세요" CTA |
| **대시보드 상단** | "빠른 한 컷" 카드/버튼 (비로그인 불가 → 로그인 후 보임) |
| **드로어 "만들기"** | "빠른 한 컷" 메뉴 항목 |

**비로그인 클릭 시:** 현재 랜딩 CTA는 `navigate('/login')` — `state.from` 미전달. 빠른 컷 버튼은 `navigate('/login', { state: { from: '/quick' } })` → `sessionStorage('login_redirect')` → OAuth 복귀 후 `/quick` 페이지로 이동. 기존 메커니즘 재사용 가능.

## 7. 환영 3패킷 + 첫 생성 비용 경로

**환영 패킷 경로:** `auth/router.py` → `grant_packets(user.id, 3, db)` → `packet_balances += 3`, `packet_transactions(reason=admin_grant)`
**컷 생성 경로:** `generate_cut_image()` → `charge_packets(user_id, 1, "generation", log.id, db)` → `packet_balances -= 1`

**동일한 `packet_balances` 테이블, 동일한 `charge_packets` 함수.** 환영 3패킷 지급 후 첫 컷 생성 시 잔량 3→2, 정상 차감. 별도 경로 분기 없음.

**결론:** 완전히 동일한 경로. 가입 직후 3패킷 보유 → 빠른 컷 1패킷 → 잔량 2패킷.
