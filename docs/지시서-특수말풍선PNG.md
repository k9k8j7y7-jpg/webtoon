## 배경

기존 말풍선은 SVG 12종(감정별 자동 매핑, 글자 길이에 맞춰 자동 확장).
모양이 얌전해서 외침·충격·생각 같은 강한 표현이 약함. 뾰족 꼬리는 SVG로
그리기 어려워 예전에 포기했던 이력.

도도가 투명 PNG 5종을 준비함 → `frontend/public/bubbles/`에 배치 완료:

| 파일 | 라벨 | 크기 | 꼬리 | 글자 영역 (x,y,w,h 비율) |
|---|---|---|---|---|
| bubble_burst.png | 외침 (폭발) | 1024×878 | 없음 | 0.24, 0.22, 0.52, 0.56 |
| bubble_shout.png | 외침 (꼬리) | 1024×885 | 아래 | 0.28, 0.22, 0.46, 0.40 |
| bubble_think.png | 생각 (구름) | 1024×972 | 왼쪽 아래 | 0.22, 0.20, 0.58, 0.50 |
| bubble_burst_wide.png | 폭발 가로 | 1024×608 | 없음 | 0.20, 0.20, 0.60, 0.60 |
| bubble_burst_tall.png | 폭발 세로 | 608×1024 | 없음 | 0.20, 0.20, 0.60, 0.60 |

같은 폴더의 `bubbles_meta.json`에 위 값이 들어 있음 — 카탈로그의 단일
소스로 사용(프론트 `bubbleCatalog.js`가 이 JSON을 import).

## 설계

- **새 레이어 `pngbubble_items`** (cuts.spec JSON 배열, effect_items 패턴):
  `{ id, bubble_id, x, y, width, rotation, flip_h, opacity, text, font_size,
  font_family, text_align }` — x,y,width는 0~1 정규화(효과와 동일), width
  0~2 허용, rotation 0~360, flip_h bool
- **글자 렌더링**: PNG 위에 text_area 안에서 글자를 그림. 줄바꿈은 영역
  폭 기준 자동, 글자 크기는 사용자 지정(font_size)이되 영역을 넘치면
  자동 축소(최소 크기까지). 폰트는 기존 말풍선 폰트 2종 + SFX 폰트 5종
  중 선택(기존 커스텀 폰트 인프라 재사용). flip_h 시 글자는 뒤집지 않음
- **레이어 순서**: 컷 → 제품 → 효과 → 말풍선(SVG) → **PNG 말풍선** →
  효과음. (PNG 말풍선은 강조용이라 SVG 말풍선보다 위)
- **기존 SVG 12종은 그대로**. 이건 "특수 말풍선" 추가일 뿐, 자동 매핑·
  대사 연결은 건드리지 않음. PNG 말풍선의 text는 대사와 별개로 사용자가
  직접 입력(대사 텍스트를 끌어오는 [대사 가져오기] 버튼은 편의 기능)
- **내보내기·공개 뷰어**: 4경로 + 뷰어 전부 렌더. Base64 인라인 시 PNG
  유지(제품 레이어 투명 보존 수정과 동일 경로 — toDataURL('image/png')).
  글자는 svg-text 렌더 모드로(기존 말풍선 내보내기와 같은 방식, canvas
  taint 회피)

## 0단계 — 조사 (코드 수정 금지)

1. effect_items 구현 위치 전수: 백엔드 검증(범위·개수), 프론트
   EffectLayer.jsx·CutEditor 배치 UI, 뷰어·내보내기 4경로 렌더 —
   파일·줄. pngbubble_items를 같은 패턴으로 복제할 때 건드릴 파일 목록
2. 기존 SVG 말풍선의 글자 렌더링: 폰트 로딩, 줄바꿈 계산(CHAR_WIDTH
   0.93 보정), svg-text 내보내기 경로 — PNG 말풍선 글자에 재사용 가능한
   함수
3. effectCatalog.js 구조 → bubbleCatalog.js로 복제 시 JSON import 방식
4. 레이어 순서가 정의된 곳(편집기·뷰어·내보내기 각각)
5. 예상 수정 파일 수

보고 후 승인.

## 1단계 — 백엔드 + 카탈로그 + 편집기 배치

- 백엔드: cuts.spec.pngbubble_items 검증(effect_items 검증 복제 + text
  최대 200자, font_size 범위, bubble_id는 카탈로그 키만)
- 프론트 bubbleCatalog.js: bubbles_meta.json import, 라벨·썸네일 경로
- 게이트5 [편집] 편집기: 효과 버튼 옆 **[특수 말풍선]** 버튼(보라 계열,
  기존 말풍선 색과 구분) → 5종 썸네일 선택 → 컷 중앙에 기본 크기(컷 폭
  35%)로 추가 → 드래그·크기·회전·좌우반전·삭제(효과와 동일 조작)
- 선택 시 우측 패널: 텍스트 입력(멀티라인), 글자 크기 슬라이더, 폰트
  선택, 정렬(가운데 기본), [대사 가져오기](이 컷 dialogue 목록에서 선택)
- 글자는 text_area 안에서 자동 줄바꿈, 넘치면 자동 축소. 편집기에서
  text_area를 옅은 점선으로 표시(선택 중일 때만)
- 저장 → F5 유지
**완료 후 배포 → 보고 → 도도 검증(ep32 또는 ep30 아무 컷, 패킷 0) → 커밋**

## 2단계 — 뷰어 + 내보내기

- 게이트5 컷 카드 썸네일, 공개 뷰어, 내보내기 4경로(ZIP·세로·인스타·A4)
  에 pngbubble_items 렌더. 레이어 순서 준수
- Base64 인라인 PNG 유지, 글자 svg-text
- 회전·반전·투명도 전부 내보내기에 반영되는지 자체 확인 후 보고
**완료 후 배포 → 보고 → 도도 검증([세로]·[인스타] 1회씩, 공개 뷰어) → 커밋**
