## 목표 (도도가 화면에서 보게 되는 것)
- 브리프 → 대본 카드에 **카피 디자인** 줄 추가: 글씨체 칩 **손글씨(기본)
  · 굵은 고딕 · 깔끔한 고딕**, 위치 칩 **자동(기본) · 상단 · 하단**, 강조
  단어(헤드카피에서 한 단어 탭해서 선택, 선택 안 하면 AI가 고름)
- 완성 단계 [생성 · 1패킷] → "모델·제품·카피를 한 장에 그려요 — 60초쯤"
  → 결과: 카피가 그림 안에 디자인돼 들어간 컷(레이어 없음). 아래 안내
  "글자가 틀리면 패킷을 돌려드려요 · [글자가 틀렸나요?]"
- [글자가 틀렸나요?] → 검사 2초 → 틀렸으면 "글자 오류 확인 — 1패킷을
  돌려드리고 다시 그려요" 자동 진행 / 맞으면 "글자는 정확해요. 다른 이유면
  [다시 그리기 · 1패킷]"
- [다시 그리기 · 1패킷]은 기존 인라인 확인 그대로. "무료"라는 말 없음
- 편집기: onecut_ad 컷은 헤드카피 레이어가 자동 삽입되지 않음(말풍선·
  효과는 그대로 쓸 수 있음)

## 1단계 — 백엔드
- **카피 디자인 옵션** 저장: cut spec(또는 idea_brief.copy_design)에
  `{font: handwritten|bold_gothic|clean_gothic, position: auto|top|bottom,
  emphasis: "단어"|null}`. 기본 handwritten·auto·null
- **프롬프트 한 곳** `app/prompts/copy_render.py` build_copy_clause(head,
  sub, design):
  - 공통: "Render the Korean headline '{head}' and the subline '{sub}' as
    part of the artwork, integrated like a professional ad poster. Spell
    every character exactly. No other text anywhere except the product's
    own label."
  - font: handwritten → "brush calligraphy style, energetic strokes" /
    bold_gothic → "bold sans-serif, high contrast" / clean_gothic →
    "clean light sans-serif"
  - position: auto → "place the text in the natural empty space away from
    the face and product" / top·bottom → 명시
  - emphasis: 있으면 "emphasize the word '{w}' with an accent color";
    없으면 "you may accent one key word"
  - 한 컷 컷 생성 시 product clause 뒤에 삽입. **onecut_ad는 모델 GPT
    고정**(카피 렌더는 Gemini 품질 낮음)
- **생성 후 글자 검사**(0패킷, gemini-2.5-flash 비전): 결과 이미지 +
  기대 head·sub → {head_ok, sub_ok, found_text}. 불일치면 **자동 재시도
  1회**(같은 프롬프트, 사용자에겐 "그리는 중" 유지) → 재시도도 불일치면
  그대로 노출(사용자가 신고 가능). generation_logs에 check 결과·retry
  기록. 검사 자체 실패(타임아웃)면 통과로 간주
- **POST /cuts/{id}/copy-report**(신고): 비전 검사 다시 → 틀림 확인 시
  1패킷 환불(admin_grant description "copy error refund cut=…") + 재생성
  job(1패킷 재차감 → 결과적으로 무료) → 202 / 맞음이면 200 {ok:true,
  message:"글자는 정확해요"}. 같은 컷 버전에 신고 1회만(중복 환불 방지),
  재생성된 새 버전엔 다시 1회
- **onecut_ad 헤드카피 레이어 비활성**: 대본의 headcopy·subcopy를 콘티
  dialogue 레이어로 자동 삽입하던 경로를 onecut_ad에서만 건너뜀(인스타툰·
  연재툰은 유지). 기존 ep102 등 이미 레이어가 있는 컷은 재생성 시 레이어
  제거
- 비용·시간 안내 상수: onecut 생성 "60초쯤"

## 2단계 — 프론트
- 대본 카드(Gate1Planning onecut) 하단 **카피 디자인** 줄: 글씨체 칩 3 ·
  위치 칩 3 · 강조 단어(헤드카피 단어들이 작은 칩으로 나열, 하나 탭 →
  선택, 다시 탭 → 해제, 안내 "비워두면 AI가 골라요"). 저장은 idea-brief/
  selection 확장
- 완성 단계(Gate5 onecut): [생성 · 1패킷] 안내 "모델·제품·카피를 한 장에
  그려요 — 60초쯤". 결과 카드 아래 한 줄 "글자가 틀리면 패킷을 돌려드려요
  · [글자가 틀렸나요?]"(작은 링크 버튼) → 검사 중 스피너 → 결과 토스트
  (틀림: "글자 오류 확인 — 패킷을 돌려드리고 다시 그려요" + 재생성 진행 /
  맞음: "글자는 정확해요 · 다른 이유면 다시 그리기(1패킷)"). 신고 완료
  버전엔 링크 숨김
- [다시 그리기 · 1패킷] 인라인 확인 유지. 재생성 드롭다운에 "카피 디자인
  바꾸기 → 대본 카드로" 링크
- 편집기: onecut 컷에 헤드카피 레이어 없음, 내레이션 탭 "헤드카피" 옵션은
  onecut에서 숨김(인스타툰은 유지)
- 인스타 공유·PNG·릴스·모션은 그대로(카피가 이미지에 포함)
- 폰 375 다크. 새 문구 사장님 말투
