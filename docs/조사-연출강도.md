## ④ 게이트5 컷별 재생성 — 옵션 수용 구조

**프론트:** `Gate5Review.jsx` (:258-279) → `api.post('/cuts/${cutId}/regenerate', { mode: 'reseed' })` — 현재 `mode: 'reseed'` 하드코딩

**백엔드:** `images/router.py` (:74) `POST /cuts/{cut_id}/regenerate`

```python
class RegenerateRequest(BaseModel):
    mode: str = "reseed"   # reseed | emotion | pose | outfit
    seed: int | None = None
    params: dict | None = None
```

**이미 지원되는 모드 (프론트 미연결):**
- `mode="emotion"` + `params={"emotion": "...", "character_id": "..."}` → spec 수정 후 재생성
- `mode="pose"` + `params={"pose": "...", "character_id": "..."}` → 동일
- `mode="reseed"` → 새 시드만

**추가 프롬프트 옵션(연출 강도 등)은 현재 불가** — `build_cut_prompt`에 추가 인자를 넘길 경로가 없음. 방법:
1. `prompt_override` 필드 활용 (전체 프롬프트 대체 — 세밀한 제어 불가)
2. `RegenerateRequest`에 `extra_prompt: str` 필드 추가 → `build_cut_prompt` 반환값에 이어붙임 (가장 단순)
3. `cut_spec`에 `effect_level` 필드 추가 → `build_cut_prompt` 내부에서 분기 (영구 저장)
