## 목표 (도도가 화면에서 보게 되는 것)
- 입구 카드 **브랜드 연재툰**: "같은 제품으로 매주 한 편 — 1화 만들면
  2화부턴 제품 정보는 그대로, 이번 화 소재만"
- 1화 브리프: 지금 인스타툰 브리프와 같음 + **"이번 화 소재"** 칸(예:
  "겨울 건조 편", 비워두면 AI가 제품 특징에서 고름). 브리프 저장 시 제품·
  브리프가 **시리즈 기본값으로 자동 저장**(토스트 "시리즈 기본값으로
  저장했어요 · 2화부터 자동으로 채워져요")
- 2화 만들기(프로젝트에서 [새 화]): 제목 기본 "2화", 브리프 화면이 **1화
  제품·특징·활용법·웹 보완 결과·타깃·톤으로 채워진 채** 열림, 위에 안내
  "시리즈 기본값에서 불러왔어요 · 이번 화 소재를 적어주세요". 제품 사진·
  분석(라벨·크기 비율·손 사진)도 그대로. 고치면 이 화만 바뀜, 고친 걸
  시리즈에도 쓰려면 [시리즈 기본값으로 저장] 버튼
- 준비 단계: 모델 자리에 **[저장된 캐릭터에서 고르기] [새로 만들기]** 둘
  다 보임(지금 "내 라이브러리" 피커를 광고 트랙 첫 화면에 노출). 연재툰은
  **모델 최대 2명**(사장님+손님 식). 장소는 화마다 새로(지금처럼)
- 대본: 컷 수 칩 **6(기본)·8·10**, 연재 구조 훅→일상 장면→제품이
  자연스럽게 등장→포인트→여운(마지막 컷 CTA는 선택, 기본 "다음 화에
  계속" 없음). 소재가 대본에 반영됨
- 에피소드 목록: "1화 · 완성", "2화 · 대본" 식 번호+단계. 완성 화면
  세로 스크롤(vertical) 그대로
- 완성·인스타·릴스·재생성·카피 렌더(1컷·마지막 컷)는 인스타툰과 동일

## 1단계 — DB + 백엔드
- **step35.sql**: `projects.series_defaults JSON NULL`. 리허설·백업·
  "실행해"
- series_defaults 구조: `{brief: {product_name, features, usage, enrich,
  target, tone, copy_direction …(idea_brief 중 선택 카피·소재 제외)},
  saved_at, source_episode_id}`. 제품은 JSON에 넣지 않고 **최근 완성 화
  (없으면 최근 화)의 products 행을 복사**
- **POST /projects/{id}/series-defaults** (brand_series만): 현재
  에피소드 idea_brief에서 소재·카피 선택 뺀 값 저장 + source_episode_id.
  브리프 저장(PUT /idea-brief/selection) 시 프로젝트에 기본값이 **없으면
  자동 호출**(1화), 있으면 호출 안 함(버튼으로만)
- **새 에피소드 생성**(brand_series 프로젝트): episode_no = 기존 화 수+1,
  title 기본 "{n}화", gate_status = create_initial_gate_status(brand_
  series) + idea_brief에 series_defaults.brief 프리필 + `prefilled_from:
  project`. products: 직전 화 products 행 복사(**이미지·holding 파일도
  storage에 복사**, 새 경로), analyze 결과·label_text·size_ratio 그대로
- idea_brief에 `episode_topic`(이번 화 소재) 키. 대본 프롬프트(get_ad_
  script_addon)에 brand_series 변형: `series=True` → 구조 훅→일상→제품
  자연 등장→포인트→여운, target_cuts 6/8/10, "이번 화 소재: {topic}"
  삽입, 비어 있으면 "제품 특징 중 하나를 골라 한 화의 소재로". 컷 수
  불일치 1회 재생성→422 규칙 동일
- **모델 수**: brand_series만 planning 모델 최대 2(기본 1, 두 번째는
  사용자가 추가). ad_brief 프롬프트·has_product refs·카피 렌더가 2명일 때
  깨지지 않는지 확인(이름 2개 전달). onecut·instatoon은 1명 그대로
- 에피소드 목록 API에 episode_no·현재 단계 이름(AD_STEP_NAMES) 포함
