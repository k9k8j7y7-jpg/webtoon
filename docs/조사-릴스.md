1. **generate_export_mp4** 재사용 가능 — 투명 RGBA 오버레이 + ffmpeg overlay 패턴. 정지 컷은 `ffmpeg -loop 1 + zoompan(1.0→1.05)` 3초 클립으로 변환, 동일 코덱·해상도로 맞춤

3. **concat** — concat demuxer가 실용적(8컷 ~10초). xfade 크로스페이드는 CPU 부하 높아 20~30초, 효과 대비 비용 과다
4. **크레딧** — Pillow로 1080×1920 검정 + 흰 `© 닉네임 · EziToon` 렌더 → ffmpeg 1초 클립. InstaShareModal 문구·폰트 재사용
5. **실사 컷** — motion(Veo) 제한만, 이미지 export 제한 없음 → 릴스에 **정지 클립으로 포함 가능**
6. **저장** — `storage/episodes/{ep}/reel/reel_v{n}.mp4`, 상태는 `gate_status.reel` JSON(마이그레이션 없음)
7. **패킷·잡** — `charge_packets(reason="generation", description="reel ep=...")`, `kind="cut"` + description 임시, jobs.py + notify() 그대로 재사용
8. **프론트** — Gate5 내보내기 그리드에 [릴스 영상] 버튼 추가, InstaShareModal에 "릴스 영상" 선택지 또는 별도 모달
9. **릴스 규격** — 1080×1920 H.264 30fps, 최대 90초, 8컷×3초=24초 적합, CRF 23이면 ~15~20MB
10. **처리 시간** — 정지 클립 zoompan 8개 ~16초 + 9:16 변환 ~8초 + concat ~2초 ≈ **총 ~30초** (영상 컷은 export_path 재사용)

## ① generate_export_mp4 구조

```
원본 이미지 크기 → 투명 RGBA 캔버스
   → compose_dialogue_on_image(return_overlay=True) → 말풍선 PNG
   → ffmpeg: [0:v]scale={w}:{h}[v];[v][1:v]overlay=0:0
   → libx264 -preset fast -crf 23 -an -movflags +faststart
```

**정지 이미지 → 3초 클립:**
```bash
ffmpeg -loop 1 -i still_with_bubbles.png \
  -vf "zoompan=z='min(zoom+0.003,1.05)':d=90:s=1024x1024:fps=30" \
  -t 3 -c:v libx264 -preset fast -crf 23 -an -movflags +faststart \
  still_clip.mp4
```
- `d=90` = 90프레임 (3초 × 30fps)
- 줌 `1.0→1.05` = 미세 줌인으로 정지 느낌 완화
- 해상도·코덱·CRF를 영상 컷 export와 동일하게 맞춤

## ② 9:16 변환 (비율별)

### 공통 ffmpeg 필터 (blurred pillarbox)
```
[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920[bg];
[bg]boxblur=20:5[blurred];
[0:v]scale=1080:1920:force_original_aspect_ratio=decrease[fg];
[blurred][fg]overlay=(W-w)/2:(H-h)/2
```

| 원본 비율 | 결과 | 비고 |
|---|---|---|
| 9:16 | 그대로 1080×1920 | 스케일만 |
| 3:4 (810×1080→1080×1440) | 상하 240px 블러 배경 | 자연스러움 |
| 1:1 (1080×1080) | 상하 420px 블러 배경 | 여백 큼 |
| 4:3 (1080×810→1080×810) | 상하 555px 블러 배경 | |
| 16:9 (1080×608) | 상하 656px 블러 배경 | 가장 많은 여백 |

### 합성 순서
1. 원본 해상도에서 말풍선 합성 (좌표계 유지)
2. 합성본을 1080×1920 blurred pillarbox로 변환
3. 9:16 클립으로 출력

## ③ concat vs xfade

| 방식 | 처리 시간 (8컷) | 메모리 | 장점 | 단점 |
|---|---|---|---|---|
| **concat demuxer** | ~2초 (copy) / ~10초 (재인코딩) | 수 MB | 간단, 빠름 | 전환 효과 없음 |
| **xfade** (0.3s) | ~20~30초 | ~200MB | 부드러운 전환 | 복잡, 느림, 해상도·fps 불일치 시 실패 |

**결론:** 1차는 concat demuxer(단순 이어붙이기). xfade는 2차 고도화로.

## ④ 엔드 크레딧 1초

```python
# Pillow 렌더
img = Image.new("RGBA", (1080, 1920), (0, 0, 0, 255))
draw = ImageDraw.Draw(img)
font = ImageFont.truetype("pretendard.ttf", 32)
text = f"© {nickname} · EziToon"
draw.text((center_x, center_y), text, fill=(255,255,255), font=font, anchor="mm")
img.save("credit.png")

# ffmpeg 1초 클립
ffmpeg -loop 1 -i credit.png -t 1 -r 30 -c:v libx264 -crf 23 credit.mp4
```

기존 InstaShareModal: `CREDIT_FONT_RATIO = 0.022` (폭의 2.2%), `© {nickname} · EziToon` 문구.

## 예상 파이프라인

```
[각 컷]
  ├─ 영상 컷(motion selected) → export_path(말풍선 합성 mp4) 재사용
  └─ 정지 컷 → 말풍선 합성(Pillow) → zoompan 3초 클립
       ↓
  9:16 blurred pillarbox 변환
       ↓
[크레딧] → 검정 1초 클립
       ↓
concat demuxer → 최종 릴스 mp4 (1080×1920 H.264 30fps)
       ↓
storage/episodes/{ep}/reel/reel_v1.mp4
```

**예상 시간:** 정지 8컷 zoompan ~16초 + 9:16 변환 ~8초 + concat ~2초 + 크레딧 ~1초 ≈ **~30초**
영상 컷이 있으면 해당 export_path 재사용으로 ~5초 절약/컷
