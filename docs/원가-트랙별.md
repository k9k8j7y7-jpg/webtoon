## 미확인·추정 사항

1. **GPT 1024×1536 output tokens:** 공식 발표 없음. 1024² = 1,756 tok 기준 비선형 추정 ~2,100 tok. 실측 필요.
2. **Gemini 이미지 해상도:** 코드에서 aspect_ratio만 지정, 출력 해상도는 모델 결정. 1K(1024²) 가정.
