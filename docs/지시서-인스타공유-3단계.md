## 2. 페이지 / 컷별 토글
- 조건: 에피소드 page_format이 grid_2x2 또는 strip_3일 때만 표시.
  세로 웹툰이면 토글 없음(항상 낱컷)
- 위치: 캡션 textarea 위. 세그먼트 2개 — "페이지로 (N장)" / "컷별로
  (M장)". **기본 페이지**. N·M은 실제 장수
- 전환 시 이미지 **다시 렌더**(진행 표시 다시) → [공유하기]는 준비
  끝나야 활성. 컷별은 기존 낱컷 1080×1080 letterbox JPEG q0.9 경로
- 20장 제한은 선택한 모드의 장수 기준. 초과 시 기존 안내
- 선택값은 localStorage `insta_share_mode`에 기억(기기당)

## 4. 크레딧 (인스타 이미지 전용)
- [근거] 도도 결정 — 출처 표기
- 대상: **인스타 경로만**(인스타 공유 + 기존 인스타 ZIP) — 세로·PNG·
  A4·뷰어 이미지는 손대지 않음
- 내용: `ⓒ {닉네임} · EziToon` (닉네임 없으면 `ⓒ EziToon`)
- 위치·스타일: 이미지 **오른쪽 아래** 모서리, 여백 폭의 2%. 글자 크기
  폭의 2.2%(1080px → 약 24px), 글꼴은 말풍선 글꼴, 흰 글씨 + 검은
  얇은 외곽선(또는 반투명 검은 배경 패드) — 밝은 배경·어두운 배경
  모두에서 읽히게. letterbox 흰 여백 위에 올라가면 검은 글씨로 자동
  전환(여백 영역 판정은 페이지 형식·컷 비율로 계산)
- 말풍선·내레이션 박스와 겹치면 안 됨 — 우선 오른쪽 아래, 그 자리에
  말풍선 bbox가 있으면 왼쪽 아래로
- 캡션 모달에 체크박스 "크레딧 표시 (ⓒ 닉네임 · EziToon)" **기본 ON**,
  끄면 빼고 렌더. localStorage `insta_credit`에 기억
- Claude Code 자체 확인: 밝은 컷·어두운 컷·letterbox 컷 각 1장 캡처
  (3장) → 도도가 크기·위치 확인(선택은 도도)
