> 근거: docs/조사-인스타공유.md
> [근거] 도도 구상 — 사용자 인스타에 바로 올리기. 공식 API(Graph)는
> 프로페셔널 계정 + 앱 심사가 필요해 오픈 후로 미루고, 지금은 **폰
> 공유창 → 인스타** 방식(심사 없음). 도도 결정: 인스타 공유부터.
> [근거] 조사 — 인스타 내보내기는 프론트 canvas(exportRenderer.js
> exportAsInstagram) 1080×1080 PNG → JSZip. navigator.share 미사용.
> 뷰어에 공유 버튼 없음(게이트5 PublishBar에 링크 복사만). 캡션용
> 데이터(title·author.nickname·shareToken)는 뷰어가 이미 보유.
> [제약] 인스타 게시물은 **최대 10장**. 공유창 텍스트는 인스타가 무시 →
> 캡션은 **복사** 방식. navigator.share는 **사용자 탭 직후**에만 허용
> (긴 비동기 작업 뒤 호출하면 거부됨) → 이미지는 모달 열릴 때 미리
> 만들고 [공유하기] 탭에서 바로 share.

## 목표 (도도가 화면에서 보게 되는 것)
- 게이트5 내보내기 줄에 **[인스타 공유]** 버튼(기존 "인스타" ZIP 옆).
  폰에서 누르면 → 캡션 모달(미리 채워진 캡션 + [캡션 복사] + [공유하기])
  → [공유하기] → OS 공유창 → 인스타 선택 → 인스타 앱이 이미지들을
  새 게시물(여러 장 = 슬라이드)로 받음 → 캡션 붙여넣기 → 게시
- PC에서 누르면 → "폰에서 열면 인스타로 바로 보낼 수 있어요" 안내 +
  [링크 복사] + 기존 ZIP 다운로드 버튼
- 뷰어 헤더(제목 옆)에 **[공유]** 아이콘 — 폰은 OS 공유창(제목+링크),
  PC는 링크 복사 + "링크를 복사했어요" 토스트. 독자 누구나

## 1단계 — 게이트5 [인스타 공유]
- 버튼: 기존 "인스타" 버튼 옆, 같은 톤. 라벨 "인스타 공유". 공개
  여부와 무관(비공개여도 이미지는 내 것)
- 클릭 → `InstaShareModal` 열림 → 즉시 **백그라운드 렌더 시작**:
  exportAsInstagram의 canvas 로직을 ZIP 없이 재사용 → 각 컷(page_format
  이면 페이지 단위) **JPEG q0.9**(인스타 권장·용량 1/3) Blob → File
  (`ezitoon_{제목}_{nn}.jpg`, type image/jpeg). 진행 표시 "이미지 준비
  중 3/8". 완료되면 [공유하기] 활성
- **10장 제한**: 컷/페이지가 10 초과면 앞 10장만 + 안내 "인스타는 한
  게시물에 10장까지 — 1~10번만 보내요. 나머지는 ZIP으로 받아 두 번째
  게시물로 올려 주세요"
- 캡션 textarea 기본값(수정 가능):
  ```
  {제목}
  by {닉네임} · EziToon으로 만든 웹툰
  {공개 링크 — is_public일 때만}
  #EziToon #이지툰 #AI웹툰
  ```
  [캡션 복사] → clipboard.writeText → 버튼 라벨 2초간 "복사됨 ✓"
- [공유하기]: `navigator.canShare && navigator.canShare({files})` 일 때만
  활성 → 탭 즉시 `navigator.share({files, title: 제목})`. 성공·취소 모두
  모달 닫기(취소는 AbortError — 조용히). 실패(NotAllowedError 등) →
  "공유창을 열지 못했어요. ZIP으로 받아 올려 주세요" + ZIP 버튼
- **PC/미지원**(canShare 없음 또는 files 거부): 모달 내용이 안내 모드 —
  "폰에서 ssagda.com/WEBTOON을 열고 같은 버튼을 누르면 인스타로 바로
  보낼 수 있어요" + [링크 복사] + [ZIP 받기](기존 함수)
- iOS Safari: files 공유 지원(15+). 비-standalone·standalone 둘 다 동일
- 다크·375px. 모달은 바텀시트(모바일)/센터(PC)

## 2단계 — 뷰어 [공유]
- ViewerPage 헤더 제목 옆 공유 아이콘(Share2). 클릭:
  - `navigator.share` 있으면 `{title: "{제목} — {닉네임} | EziToon",
    url: 현재 뷰어 URL}` (파일 없음)
  - 없으면 clipboard.writeText(url) → 토스트 "링크를 복사했어요"
- 비공개 에피소드도 버튼은 보임(소유자만 접근 가능하니 링크 자체는
  무해). 비공개일 때 소유자에게 작은 안내 "비공개 작품은 나만 볼 수
  있어요 — 공개하면 누구나" (1줄)
- 게이트5 PublishBar "링크 복사"는 그대로
