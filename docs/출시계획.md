## A. 법·결제 (1주차)
- **A1 푸터 사업자 정보** — 랜딩 푸터 + Layout 공통 푸터(로그인 후 모든
  페이지): 상호 · 대표자(실명) · 사업자등록번호 · 통신판매업 신고번호 ·
  주소 · 전화 · 이메일 · 약관 · 개인정보처리방침. **"대표: 김정신"(캐릭터
  이름) → 실제 대표자명**. 값 6개는 도도가 준비(업종 추가 후 등록증 기준).
  값이 아직 없으면 자리만 만들고 상수 한 곳(`siteInfo.js`)에 둬서 나중에
  채움
- **A2 관리자 환불 엔드포인트** — `POST /admin/orders/{id}/refund`: 토스
  취소 API(테스트 키로 구현·검증 가능) + 패킷 회수(사용분 230원 공제
  계산은 관리자가 금액 입력) + 주문 cancelled + 사용자 알림 "환불이
  처리됐어요". /admin 주문 목록에 [환불] 버튼
- **A3 문의 → 관리자 알림** — 문의 생성 시 is_admin 전원 notify + 웹푸시
  "새 문의: {제목 앞 20자}" (링크 /admin 문의). 답변 안 한 문의 24시간
  지나면 하루 1회 재알림
- A4 토스 심사 대비 체크: 비로그인에서 가격·약관·환불·사업자 정보 보임,
  결제 버튼 → 토스 위젯 정상 (현재 테스트 키로 OK)

## B. 안전 (1~2주차)
- **B1 백업** — 매일 03:00 mysqldump(gzip) → `~/backups/db/` 7일 보관 +
  storage(이미지·영상) rsync → 별도 경로/S3. **Lightsail 자동 스냅샷**은
  도도가 콘솔에서 켜기(디스크 전체, 가장 쉬움). 복원 리허설 1회(테스트 DB)
- **B2 로그** — logrotate: uvicorn.log 일일, 7일 보관, gzip. 현재 30MB
  정리. 앱 로그에 요청 id·user id 포함
- **B3 다운 알림** — UptimeRobot(무료) `/WEBTOON/health` 5분 핑 → 도도
  이메일·폰 (도도가 가입, 5분)
- **B4 500 알림** — 미들웨어에서 500 발생 시 관리자 웹푸시 "서버 오류
  N건 (최근 10분)" 10분당 최대 1회 + 로그 traceback. (Slack 없음 →
  기존 푸시 재사용)
- **B5 레이트 리밋(slowapi)** — 생성 엔드포인트(이미지·컷·모션·릴스·
  quick) 사용자당 분당 10 / 댓글 분당 5 / 문의 시간당 5 / 로그인·가입
  IP당 시간당 20. 초과 시 429 + 한국어 안내. 동시 이미지 생성은 사용자당
  2건 제한
- **B6 CORS** — `allow_origins=["https://ssagda.com"]`(+ 로컬 개발 origin
  env로)
- **B7 환영 패킷** — 같은 이메일로 소셜 3사 각각 가입해도 1회만(이메일
  기준 + provider_uid 기준 둘 다). 이메일 없는 provider는 현행
- **B8 비용 상한(도도 콘솔)** — Google Cloud 예산 알림(월 5만/10만 원),
  OpenAI 월 한도, 토스 정산 계좌 확인. 코드 쪽은 일일 생성 총량 카운터
  (예: 하루 2,000장 넘으면 관리자 푸시) 정도만
