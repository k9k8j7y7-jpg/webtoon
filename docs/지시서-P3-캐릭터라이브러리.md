## 0. 목표

Gate 3에서 캐릭터를 매번 새로 만드는 대신, 프로젝트의 기존 캐릭터를
**연결(불러오기)**할 수 있게 한다. 같은 참조 이미지 재사용 = 생성 비용 0
+ 에피소드 간 얼굴 일관성. 추가로 "내 라이브러리 승격(별표)"으로
시그니처 캐릭터를 계정 레벨에서 재사용할 기반을 만든다.

## 1단계 — 현황 조사 (수정 금지)

1. Gate3Assets.jsx 구조: 캐릭터 목록 표시/생성 UI가 어떻게 구성돼
   있는지 (컴포넌트, API 호출 흐름)
2. 캐릭터 생성 API와 "에피소드에 연결" 개념의 현재 코드 상태
   (P2의 이중 기록 경로 재확인)
3. 캐릭터 삭제 API 존재 여부와 동작 (이미지·outfit 연쇄 삭제 여부)
4. 캐릭터 시트(front/smile/angry 등) 표시 컴포넌트 위치
보고 후 멈춤.

## 2단계 — 백엔드 API

1. **프로젝트 캐릭터 목록**: GET /projects/{pid}/characters
   - 반환: 캐릭터 + 대표 이미지(front) + 어느 에피소드들에 연결돼
     있는지 (episode_characters 집계) + user_id(승격 여부)
2. **불러오기(연결)**: POST /episodes/{eid}/characters/link
   - body: { character_id } → episode_characters 1행 추가만.
     생성/복제 없음. 중복 연결 시 409 또는 무시(멱등)
   - ref_key 충돌 처리: 연결하려는 캐릭터의 ref_key가 해당
     에피소드에 이미 존재하면 에러 반환 (대본의 ref_key 참조
     무결성 보호)
3. **연결 해제**: DELETE /episodes/{eid}/characters/{cid}/link
   - episode_characters 행만 삭제. 캐릭터 본체는 유지
   - 단, 해당 에피소드에 이 캐릭터가 등장하는 컷 이미지가 이미
     생성돼 있으면 경고 응답 (프론트에서 확인 다이얼로그)
4. **라이브러리 승격/해제**: POST /characters/{cid}/promote,
   /demote — user_id 설정/해제
5. **내 라이브러리 목록**: GET /users/me/characters
6. **재생성 경고 데이터**: 기존 캐릭터 재생성 API 응답 또는 사전
   조회에 "이 캐릭터가 연결된 에피소드 수" 포함 (경고문 표시용)
보고 후 멈춤.

## 3단계 — 프론트 (Gate 3 개편)

### 캐릭터 섹션 구조
```
[이 에피소드의 캐릭터]  ← 현재 연결된 캐릭터 (기존 표시 유지)
  각 카드에: 연결 해제 버튼(휴지통과 구분되는 아이콘/문구)
[+ 캐릭터 불러오기] 버튼 → 피커 모달:
  ├ ⭐ 내 캐릭터 (user_id 있는 것, 전 프로젝트)
  └ 이 프로젝트 (project_id == 현재, 미연결된 것만)
  각 항목: front 썸네일 + 이름 + "N개 에피소드에서 사용 중"
  선택 → link API → 목록 즉시 갱신
[+ 새 캐릭터 생성] ← 기존 플로우 그대로
```

### 승격 UI
- 캐릭터 카드에 별표 토글 (☆/⭐) → promote/demote API
- 툴팁: "내 라이브러리에 등록하면 모든 프로젝트에서 사용할 수 있어요"

### 재생성 경고
- 연결 에피소드 2개 이상인 캐릭터의 재생성 버튼 클릭 시 확인
  다이얼로그: "N개 에피소드에서 사용 중입니다. 새 이미지는 이후
  생성부터 적용되며, 이미 만든 컷 이미지는 바뀌지 않습니다."

### 유의
- 피커에서 동명 캐릭터(마이그레이션 잔재) 구분 가능하게: 썸네일 +
  생성일 또는 출처 에피소드 표시
- 모바일: 피커 모달 세로 스크롤, 썸네일 그리드 2열
보고 후 멈춤.

## 4단계 — 검증

1. 불러오기 왕복: ep A에서 만든 캐릭터를 새 ep B에 연결 →
   B의 Gate 3에 표시 + B에서 컷 이미지 생성 시 참조 이미지가
   A와 동일 파일인지 (URL/해시 비교)
2. ref_key 충돌: 같은 ref_key 캐릭터 연결 시도 → 에러 확인
3. 연결 해제: 행 삭제만 되고 캐릭터 본체·이미지 무손실
4. 승격: 별표 → 다른 프로젝트의 피커에 [내 캐릭터]로 표시
5. 재생성 경고: 2개 이상 연결 캐릭터에서 다이얼로그 표시
6. 회귀: 기존 에피소드(13 등) 캐릭터 표시·생성 플로우 무변경
Playwright + API 수치 판정. 보고 후 멈춤.
