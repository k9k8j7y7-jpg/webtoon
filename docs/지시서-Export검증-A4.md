# 지시서 — Export 검증 + A4 내보내기

> **전제:** 4-A/4-B 커밋 완료 상태. 문서 7장 잔여 작업.
> **작업 방식:** 단계 순서대로. **각 단계 종료 시 멈추고 보고 → 사용자 확인 후 진행.**
> **커밋은 사용자 확인 후에만.** 파괴적 git 명령 금지. bubbleSpec.json 열지 말 것.

## 0. 확정된 방향 (변경 금지)

- Export는 **브라우저 측 미리보기 병합 방식**이다: SingleBubble/BubbleOverlay를
  renderToStaticMarkup()으로 렌더한 결과(= 미리보기와 동일 픽셀)를 캔버스에
  합성해 PNG를 만든다.
- **말풍선/텍스트/이미지를 백엔드에서 따로 조합하는 방식(구 Pillow 경로)은 폐기됐다.**
  이 방식으로 되돌아가는 코드를 작성하지 말 것.
- 검증 원칙: 화면 미리보기와 export 출력이 **픽셀 단위로 같은 렌더 경로**를
  타는지가 판정 기준. 별도 렌더 경로가 발견되면 그 자체가 문제.

## 1단계 — 현행 Export 경로 조사 (수정 금지)

1. export 종류별(PNG 개별컷 / 세로 이어붙임 / 인스타) 코드 경로 확인:

2. **구 Pillow/백엔드 조합 경로의 잔재**가 있는가? (백엔드에 export 관련
   이미지 합성 코드, 사용 안 되는 엔드포인트 등 — 있으면 목록만 보고, 삭제는 아직)
3. exportRenderer가 참조하는 데이터: bubble_layout의 min_height,
   text_offset_x/y, sfx_layout이 전달 경로에서 누락 없이 흐르는지
4. 인스타 export의 정확한 사양 확인 (1:1인지 4:5인지, 컷 배치 방식)

## 2단계 — 실출력 검증

### 준비
- 에피소드 13에서 검증용 상태 구성: #8 컷에 min_height 30% +
  text_offset_y −30% 저장, 임의 컷 하나에 shout(꼬리 없음) 지정,
  #4(효과음 "반갑!!")와 #12(나레이션 2개)는 그대로 사용

### 판정 항목 (전부 실제 export 파일로 확인)
1. PNG 개별컷: #8 출력물에서 말풍선 높이·텍스트 위치가 미리보기와 일치
   (미리보기 스크린샷과 export PNG를 나란히 비교 + boundingBox 수치)
2. 스파이크(shout) 컷: 꼬리 잔재 없음
3. 효과음(#4): SfxLayer가 export에 포함됨
4. 나레이션 2개(#12): 둘 다 위치 정확
5. 세로 이어붙임: 컷 순서·간격 정상, 각 컷 렌더가 개별 PNG와 동일
6. 인스타: 사양대로 출력
7. **#7 dialogue 재생성:** #7은 dialogue 빈 데이터 상태. 대본→콘티 재생성
   경로로 dialogue를 채우고, 채워진 상태로 export에 정상 포함되는지 확인
   (이 항목이 문서 7장 잔여의 "#7 dialogue 재생성")

판정은 수치/파일 비교로. "잘 나온다" 식 문장 판정 금지.

**보고 후 멈춤. 문제 발견 시 수리 전에 먼저 보고.**

## 3단계 — A4 내보내기 (신규 기능)

### 사양
- 용도: 사용자가 **홍보물로 바로 인쇄**할 수 있는 A4 출력
- 캔버스: A4 세로 300DPI = **2480 × 3508 px**, 흰 배경
- 페이지 여백: 상하좌우 **59px (5mm)** — 프린터 인쇄 가능 영역 고려
- 두 가지 모드:

**모드 1 — 한 컷 크게:** 사용자가 지정한 컷 1개를 페이지 중앙에 최대 크기로
(9:16 비율 유지, 여백 안에서 fit)

**모드 2 — 그리드:** 페이지당 최대 12컷, **4열 × 3행**
- 셀 크기: 여백 제외 영역을 4×3 분할, 셀 간 간격 20px
- 각 컷은 셀 안에 9:16 비율 유지 fit (4열×3행 셀 비율 ≈ 0.53이라
  9:16(0.5625)과 거의 일치 — 여백 최소)
- 배치 순서: 컷 번호 순, 좌→우, 상→하
- 13컷 이상: 다음 페이지로. 출력은 **페이지당 PNG 1장** (파일명
  `{에피소드}-A4-1.png`, `-2.png` ...) — PDF 묶음은 이번 범위 밖
- 그리드 열/행 수는 상수로 정의 (GRID_COLS=4, GRID_ROWS=3) — 추후 변경 대비

### 구현 원칙
- **기존 병합 파이프라인 재사용.** 세로/인스타 export가 쓰는 것과 동일한
  컷 합성 결과물을 A4 캔버스에 배치하는 것. 새 렌더 경로 만들지 말 것
- UI: Gate5Review의 기존 export 버튼 그룹에 "A4 인쇄용" 추가 →
  모드 선택(한 컷/그리드), 한 컷 모드면 컷 선택

### 검증
- 12컷 에피소드(13) 그리드 모드: 1페이지, 12컷 전부, 순서 정확,
  셀 내 잘림 없음 — 출력 px 실측 (2480×3508 확인)
- 한 컷 모드: #8 지정 → 중앙 배치, 비율 유지 확인
- 페이지 분할: 그리드 모드에서 컷 일부만 선택하거나 13컷 이상 상황을
  시뮬레이션해 2페이지 출력 확인 (테스트 방법은 재량, 방법 보고할 것)
- 300DPI 인쇄 시인성: 그리드 셀 하나를 100% 확대해 말풍선 텍스트가
  읽히는지 스크린샷 첨부
