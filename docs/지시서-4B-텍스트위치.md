## 0. 목표와 핵심 설계

말풍선 내부 텍스트는 현재 항상 중앙 정렬이다. 이를 사용자가
가로/세로로 옮길 수 있게 한다. 단, **텍스트가 말풍선 밖으로 나가는
것이 수학적으로 불가능한 구조**로 만든다.

### 필드 정의 (bubble_layout에 추가)
- `text_offset_x`: number, **-0.5 ~ 0.5**, 기본 **0**
- `text_offset_y`: number, **-0.5 ~ 0.5**, 기본 **0**
- 기본 0 = 현재 동작(정중앙)과 완전 동일. 기존 저장 컷 무변경 렌더. 마이그레이션 없음.

### 위치 계산 (핵심 수식)

```
가용 영역 = 스타일별 텍스트 배치 가능 영역 (아래 스타일별 정의)
needX = max(0, (가용 너비 − 텍스트 블록 너비)) / 2
needY = max(0, (가용 높이 − 줄수 × lineHeight)) / 2
텍스트 중심 X = 말풍선 중심 X + text_offset_x × 2 × needX
텍스트 중심 Y = 말풍선 중심 Y + text_offset_y × 2 × needY
```

- 텍스트 블록 너비 = wrapText 결과 줄들 중 최대 줄 너비 (measureText 기준, CHAR_WIDTH 0.93 체계)
- offset ±0.5일 때 텍스트 가장자리가 정확히 가용 영역 경계에 닿는다
- **need가 0이면 offset은 자동 무력화** (여유 없음 = 이동 불가). 별도 클램프 코드 불필요 — 수식 자체가 보장
- 좌표는 비율 기반이므로 scale 곱셈 체계와 자동 호환 (썸네일-미리보기 동일 위치)

### 스타일별 "가용 영역" 정의

| 계열 | 가용 영역 |
|---|---|
| 타원 (round, whisper, thought, happy, sad, realize) | 기존 safeRatio(0.85) 내접 사각형: 너비 rx×2×0.85 − 패딩, 높이 ry×2×0.85 − 패딩 (기존 텍스트 맞춤 계산이 쓰는 영역과 동일 기준을 재사용할 것) |
| 사각 (narration, flustered, shy) | 본체 사각 − PADDING_X/Y×2 (shy는 사다리꼴 기울기만큼 좌우 추가 여유 확보 — 기존 텍스트 배치가 쓰는 안전 영역 재사용) |
| 스파이크 (shout, angry, surprised) | 골(inner) 타원 기준 내접 사각형 (타원과 동일 방식, innerRatio 적용 후) |

⚠️ 새 영역 계산을 발명하지 말 것. **기존 코드가 텍스트 맞춤(폭·높이 역산)에
이미 사용하는 안전 영역을 그대로 need 계산에 재사용**한다. 새로 정의하면
기존 맞춤 로직과 어긋나서 경계 케이스에서 텍스트가 삐져나온다.

### wrapText와의 관계 (순환 금지)
- offset은 **줄바꿈에 영향을 주지 않는다.** wrapText → 크기 확정 → need 계산 → offset 적용. 이 순서 고정.
- min_height로 커진 높이는 needY를 키운다 (커진 만큼 세로 이동 여유 증가) — 이것이 정상 동작.

## 1단계 — 렌더 반영 (computeSingleBubbleGeo / SingleBubble)

1. 텍스트 블록 배치 코드에서 현재 중앙 정렬 기준점을 찾아 위 수식으로 교체
2. ⚠️ **두 함수(computeSingleBubbleGeo / SingleBubble) 동일 수정 필수.**
   수정 후 두 함수의 해당 부분을 나란히 보고에 첨부
3. 줄단위 div + whiteSpace:nowrap 구조는 유지. 블록 전체를 옮기는 것이지
   줄별로 옮기는 게 아님. text-align 등 CSS 정렬 속성으로 흉내내지 말 것
   (가로 이동은 블록 위치 이동으로 — 줄들의 상대 정렬은 현재 그대로)

### 검증 (bubble-test)
- /bubble-test에 text_offset 섹션 추가: round / narration / shout 3종 ×
  offset (0,0) / (−0.5,−0.5) / (0.5,0.5) / (0.5,0) / (0,−0.5) 그리드
- npm run bubble-shot 수치 판정:
  - **모든 케이스에서 텍스트 boundingBox ⊂ 말풍선 boundingBox** (1px 허용, 스파이크 ±2px)
  - offset (0,0)은 기존 렌더와 동일 (±1px)
  - offset 0.5일 때 텍스트 가장자리와 경계의 간격 ≤ 패딩 + 2px
  - 긴 텍스트(여유 0 케이스): offset을 줘도 위치 불변인지
- 눈대중 금지. 수치 표 출력.

**멈추고 보고. 확인 대기.**
