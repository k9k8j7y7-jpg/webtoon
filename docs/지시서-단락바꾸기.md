# 지시서 — 아이디어 정리 단락 바꾸기 (도입·전개·전환·결말 개별 재생성)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> 없는 것 확인. DB 마이그레이션 없음(idea_brief JSON). 패킷 0(텍스트).
> 근거: docs/조사-단락바꾸기.md
> [근거] 도도 — 아이디어 정리의 도입·전개·전환·결말 중 마음에 안 드는
> 단락만 버튼으로 바꾸고 싶다. 지금은 [다시 정리]가 네 단락을 전부 다시
> 굴려서 마음에 들던 단락까지 바뀜.
> [근거] 도도 결정 — 게이트1 "이야기 전개" 전체 칩은 **그대로**(기획
> 생성 뼈대용) / 단락 칩은 단락별 맞춤 세트 / 앞뒤 맞추기는 일단 없음.
> [근거] 조사 — story 키 ki·seung·jeon·gyeol. [다시 정리] = POST
> .../idea-brief + hint → revise_idea_brief() 전체 재생성, 0패킷.
> target_section·direction 인자 추가로 충분. **stale 배너가 story 변경을
> 감지 못함**(characters/genre/mood/development만 비교) → 함께 보완.

## 목표 (도도가 화면에서 보게 되는 것)
```
이야기
 도입                                   [✨ 바꾸기]
 ┌──────────────────────────────────────────────┐
 │ 추운 겨울날, 갈색 포메라니안 도도는 …          │
 └──────────────────────────────────────────────┘
   (바꾸기 누르면 아래 펼침)
   [초반 후킹] [잔잔하게] [더 짧게] [직접 입력…]
```
- 칩 클릭 → 그 상자만 "바꾸는 중…" → 새 문장 → 상자 오른쪽 위에
  **[↶ 되돌리기]** (한 번 전 문장으로, 1단계만)
- 다른 세 단락은 **그대로**. 모델은 다른 단락을 읽고 흐름만 맞춤
- 기존 "이렇게 바꿔줘 + [다시 정리]"는 전체 재정리용으로 그대로
- 단락을 바꾸면 **기획 생성 stale 배너**가 떠야 함("아이디어가 바뀌었어요
  — 기획 생성을 다시 하면 반영돼요")

## 1단계 — 백엔드
- POST .../idea-brief 요청에 선택 필드 추가: `target_section`
  (ki|seung|jeon|gyeol) + `direction`(문자열, 칩 값 또는 직접 입력).
  둘 다 있으면 **단락 모드**, 없으면 기존 전체 재정리(변경 없음)
- revise_idea_brief(brief, hint, target_section=None, direction=None):
  단락 모드 프롬프트 — "다음은 4단락 이야기다. **{target} 단락만** 아래
  방향으로 다시 써라. 다른 단락은 그대로 두고 앞뒤 흐름·등장인물·톤과
  어긋나지 않게. 길이는 원래 단락과 비슷하게(더 짧게 지시면 절반).
  출력은 해당 단락 텍스트만." → 응답을 brief.story[target]에만 덮어씀,
  나머지 키 보존 → 저장 → 전체 brief 반환(기존 응답 형식 유지)
- 방향 값 → 프롬프트 문구 매핑 상수(한 곳): 초반 후킹 "첫 문장부터
  사건·궁금증으로 시작", 잔잔하게 "감정선·일상 디테일 중심, 사건 작게",
  극적으로 "갈등·긴장 고조, 뚜렷한 사건", 반전 있게 "예상과 다른
  방향으로 꺾이되 앞 단락과 모순 없이", 성장·역전 "인물이 한 단계
  성장하거나 상황이 뒤집힘", 미스터리·떡밥 "의문·단서를 남김", 해피엔딩
  "따뜻하게 해결", 여운 남게 "다 말하지 않고 여운", 클리프행어 "다음 화가
  궁금해지는 끝", 더 짧게 "핵심만 절반 길이". 직접 입력은 그대로 전달
- 0패킷 유지(기존 재정리와 동일 과금 없음). 실패 시 400/500 메시지
  한국어
- **stale 시그니처 보완**: last_gen_input 비교 항목에 idea_brief.story
  (4키) + 한 줄 소개 + 톤 추가 → 단락 변경 시 배너 노출. 기존 planning_
  draft 자동 저장(800ms 디바운스) 그대로

## 2단계 — 프론트 (Gate1Planning 아이디어 정리 카드)
- 단락 상자(도입·전개·전환·결말) 라벨 오른쪽에 **[✨ 바꾸기]** 작은
  텍스트 버튼. 클릭 → 그 상자 바로 아래 칩 줄 토글(한 번에 한 단락만
  펼침)
- 칩 세트(단락별):
  - ki 도입: 초반 후킹 · 잔잔하게 · 더 짧게
  - seung 전개: 극적으로 · 잔잔하게 · 성장·역전 · 미스터리·떡밥
  - jeon 전환: 극적으로 · 반전 있게 · 잔잔하게
  - gyeol 결말: 반전 있게 · 해피엔딩 · 여운 남게 · 클리프행어
  - 공통 마지막: **[직접 입력…]** → 한 줄 input + [적용] (예: "엄마가
    먼저 안아주게")
- 칩 클릭 → 해당 상자 비활성 + 스피너 "바꾸는 중…" → 응답 → 상자 텍스트
  교체(살짝 하이라이트 1초) → **[↶ 되돌리기]** 표시(이전 텍스트 1단계
  보관, 다시 바꾸면 갱신). 다른 상자는 손대지 않음
- 응답으로 온 전체 brief로 state 갱신하되, 사용자가 다른 상자를 직접
  타이핑 중이면 그 상자는 덮어쓰지 않음(현재 포커스 상자 보호)
- 자동 저장은 기존 planning_draft 경로 그대로(바뀐 story 포함)
- 모바일: 칩 줄 가로 스크롤, 터치 영역 36px+. 다크
- stale 배너 문구에 단락 변경 케이스 포함: "아이디어가 바뀌었어요 —
  [기획 생성]을 다시 하면 반영돼요"
