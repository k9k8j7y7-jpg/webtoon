> **버전:** v1.0
> **작성일:** 2026-08-01
> **대상:** Claude Code
> **참조 문서:** docs/ 의 Cut-Spec-Schema-v1.0, Character-Consistency-Korean-Text-Revision(B파트), Gate4-5-Speech-Product-Revision(말풍선), 전역 원칙(사용자 편의)
> **범위:** (A) 그림 속 한글 텍스트 처리 + (B) 말풍선 조판 시스템(12종 자동 선택 + 수동 교체).
> **묶은 이유:** 그림 속 텍스트를 줄이고(A), 그 정보를 말풍선으로 얹는다(B). 한 몸이므로 통합.

---

## 배경

캐릭터 일관성(앵커링)은 테스트 통과. 남은 두 문제를 함께 해결:

1. **그림 속 한글 텍스트 깨짐** — 예: 컷 배경에 캐릭터 설명이 통째로 박혀 깨짐("차분하오 슴데드티..."), 카드/간판 글자 깨짐.
2. **말풍선 시스템 미구현** — dialogue 데이터는 있으나 이미지 위에 얹는 조판이 없음. 말풍선 종류·자동선택·수동교체 전부 필요.

**핵심 방침:** 이미지 모델(Nano Banana)에 텍스트를 그리게 하지 않는다. 말풍선·대사는 **코드로 이미지 위에 얹는다**(SVG/Canvas). 텍스트 안 깨지고, 수정 시 이미지 재생성 불필요(과금 없음).

---

# A. 그림 속 한글 텍스트 처리 (절충)

## A-1. 원칙

| 텍스트 종류 | 처리 |
|---|---|
| **긴 문장** (캐릭터 설명, 신문 기사, 화면 문구) | 그림에 **그리지 않음**. 사물로만 묘사 |
| **짧은 핵심 단어** ("폭락", "매수" 등) | 그림에 두되 정확한 문구 + 한글 명시. 깨지면 재생성 |
| **정보성 텍스트** | 말풍선/나레이션으로 유도 (코드로 얹음) |

## A-2. 프롬프트 처리

- **캐릭터 description이 이미지 프롬프트에 흘러들지 않게 차단.** (현재 #4에서 캐릭터 설명 텍스트가 배경에 통째로 그려지는 버그 → description은 캐릭터 시트 생성에만 쓰고, 컷 배경 프롬프트에는 넣지 않음)
- 긴 텍스트는 사물로: "신문에 '노후 대비 투자법'이라 쓰여있다" → "김준이 경제면 신문을 읽는다"
- 짧은 단어만 명시: "화면에 붉은 글씨로 '폭락'(Korean word) 표시"

# B. 말풍선 시스템

## B-0. 핵심 구조

- 말풍선은 **이미지 파일이 아니라 코드로 그린다**(SVG/Canvas). 텍스트 길이에 맞춰 자동 확장 + 꼬리 렌더링.
- 이미지(캐릭터·배경) 위에 **말풍선 레이어**를 합성. 원본 이미지는 그대로 두고 레이어만 얹음.
- 말풍선 교체·대사 수정 시 **레이어만 다시 그림 → 이미지 재생성 없음 → 과금 없음.**

## B-1. 말풍선 12종 (디자인 명세)

**기본 4종 (dialogue.type 기반)**

| 이름 | key | 디자인 | 매핑 |
|---|---|---|---|
| 라운드 | round | 둥근 타원 + 꼬리, 흰 배경 검정 테두리 | type=speech (기본) |
| 나레이션 | narration | 직사각형 박스, 꼬리 없음 | type=narration |
| 생각 | thought | 구름 모양 + 작은 원 꼬리 | type=thought |
| 속삭임 | whisper | 타원 + **점선** 테두리 + 꼬리 | 작은 목소리(옵션) |

**감정 8종 (dialogue.emotion 기반)**

| 이름 | key | 디자인 | 매핑 emotion |
|---|---|---|---|
| 외침 | shout | 뾰족한 폭발형(스파이크) 테두리 | (강조/큰소리) |
| 화남 | angry | 빨강 뾰족 폭발형 + 번개 아이콘 | angry |
| 기쁨 | happy | 핑크 구름/타원 + 밝은 톤 | happy |
| 슬픔 | sad | 파랑 타원 + 물방울 아이콘 | sad |
| 놀람 | surprised | 뾰족형 + 별 아이콘 | surprised |
| 부끄 | shy | 분홍 타원 | shy/embarrassed |
| 당황 | flustered | 타원 + 소용돌이 아이콘 | flustered/confused |
| 깨달음 | realize | 타원 + 전구 아이콘 | realization |

> 디자인은 일반 웹툰 말풍선 관례를 따름. 색·테두리·아이콘은 위 명세 기준으로 SVG 구현.

## B-2. 자동 선택 (기본)

컷 생성 시 dialogue마다 말풍선을 **자동 매핑**. 사용자 개입 불필요(초보 친화).

**매핑 규칙 (우선순위):**
```
1. type=narration → narration
2. type=thought   → thought
3. type=speech 이고 emotion이 명확한 감정이면:
     angry→angry, sad→sad, happy→happy, surprised→surprised,
     shy→shy, flustered→flustered, realization→realize
4. 그 외(serene, thoughtful, content 등 잔잔한 감정 포함) → round (기본)
```

- **애매한 감정은 억지로 매핑하지 않고 round(기본)로.** (예: content를 happy로 과하게 매핑하지 않음)
- 이번 지우 웹툰처럼 잔잔한 감정이 대부분이면 대부분 round로 자연스럽게 처리됨.

## B-3. 수동 교체 (아이콘 팔레트)

자동 선택이 마음에 안 들면 사용자가 교체. **게이트5 컷 수정(연필 ✎) 안에서.**

**UI:**
- 컷 수정 모달에 대사 목록 표시. 각 대사 옆에 **현재 말풍선 아이콘** 표시.
- 아이콘 클릭 → **12종 말풍선 아이콘 팔레트** 펼쳐짐(모양이 보이는 미니 아이콘).
  ```
  [라운드][나레이션][생각][속삭임]
  [외침][화남][기쁨][슬픔][놀람][부끄][당황][깨달음]
  ```
- 원하는 말풍선 클릭 → 그 대사의 말풍선 교체 → 저장.
- 팔레트 아이콘은 별도 파일 없이 **말풍선 SVG의 미니 버전**으로 렌더(같은 코드 재사용).

**전역 원칙:** 텍스트 이름만이 아니라 **모양이 보이는 아이콘**으로 표시(초보가 모양을 바로 인지).

## B-4. 데이터 (Cut-Spec 확장)

dialogue에 `bubble_style` 필드 추가:
```jsonc
"dialogue": [
  { "order": 1, "type": "speech", "emotion": "content", "speaker": "jiwoo",
    "text": "따뜻하게 드세요.",
    "bubble_style": null }   // null이면 자동 매핑, 값 있으면 사용자 지정으로 고정
]
```
- `bubble_style: null` → B-2 자동 매핑 적용.
- 사용자가 팔레트에서 고르면 → 그 key로 채워져 고정.

## B-5. 조판 규칙 (기존 방침 유지)

- type별 위치 고정 규칙(MVP): speech/thought=컷 상단, narration=컷 하단. (얼굴 회피 등 정교한 배치는 이후)
- 한 컷에 dialogue 여러 개면 order 순서로 배치.
- 텍스트 길면 말풍선 자동 확장 + 줄바꿈.
- 한글 가독성 폰트 사용.

## B-6. 대사 없는 컷 — 효과음 강제 안 함 (그대로)

- 대사·나레이션이 없는 컷(예: 커피 내리는 장면, 클로즈업)은 **말풍선 없이 그대로** 둔다.
- 잔잔한 일상 웹툰에서 "여백 컷"은 자연스러운 연출이므로 효과음을 강제하지 않음.
- (효과음 레이어는 V1에서 옵션으로 검토 — 지금은 미포함.)

## MVP 범위 / V1

**MVP:** 12종 말풍선(코드 SVG) + 자동 매핑 + 아이콘 팔레트 수동 교체 + 한글 텍스트 억제.

**V1:**
- 말풍선 30종 풀세트(텔레파시·기계음·노래 등 특수형)
- 효과음 레이어(대사 없는 컷 옵션)
- 실시간 미리보기(말풍선 고르면 이미지 위에서 즉시 변경)
- 말풍선 위치 얼굴 회피 등 정교한 조판

---

## 검증

1. 컷 생성 시 dialogue에 자동으로 적절한 말풍선이 붙는지(잔잔한 감정→round, 명확한 감정→해당 말풍선).
2. 긴 한글 텍스트가 그림 배경에 안 그려지는지(특히 캐릭터 설명 박히던 버그 해결).
3. 컷 수정에서 아이콘 팔레트로 말풍선 교체 → 이미지 재생성 없이 즉시 바뀌는지(과금 없음).
4. 텍스트 길이에 따라 말풍선이 자동 확장되는지.
5. 대사 없는 컷은 말풍선 없이 깔끔하게 유지되는지.
