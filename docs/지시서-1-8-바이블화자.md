# 지시서 1-8 — 바이블 인라인 수정 + 화자/시점 명시

> **배경:** 도도 시리즈에서 바이블의 '나'가 아내로 정의된 채 대본이
> 생성돼, 실제 화자(남편)와 시점이 어긋남. 바이블 텍스트를 직접
> 수정할 수단이 없어(전체 재생성만) 정정이 불가했음.
> **목표:** ① 바이블 시놉시스/세계관/인물을 인라인 수정 ② 화자(시점)를
> 바이블 필수 항목으로 두고 대본 생성에 주입 ③ 인물 수정이 캐릭터
> 시트·appearance_en과 어긋나지 않게 연결.
> **작업 방식:** 단계별 멈춤·보고. 커밋은 사용자 확인 후.

---

## 1단계 — 조사 (수정 금지)

1. series.bible JSON 현재 구조 (synopsis/world/characters[] 필드,
   characters 항목의 키: name/role/description/ref_key)
2. 바이블이 대본 생성 컨텍스트에 주입되는 지점 (P5 series_context
   블록) — 인물 요약이 어떤 형식으로 들어가는지
3. 시리즈 홈 바이블 섹션 UI 구조 (접이식 표시, 전체 재생성 버튼)
4. 바이블 인물과 캐릭터 테이블의 관계: 바이블 characters[].ref_key ↔
   characters.ref_key 매칭으로 시트를 찾는지, 이름으로 찾는지
보고 후 멈춤.

## 2단계 — 백엔드

1. **화자 필드**: bible에 `narrator` 추가
   - 구조: {ref_key, name, perspective} — perspective는
     "first_person" | "third_person"
   - 바이블 생성 프롬프트에 "화자(narrator)를 반드시 지정. 1인칭이면
     '나'가 누구인지 ref_key로 명시" 추가 + JSON 스키마 필수
   - 구 바이블 폴백: narrator 없으면 characters[0]을 3인칭 화자로
     간주 (경고 플래그 `narrator_missing: true` 응답에 포함)
2. **인라인 수정 API**: PUT /series/{sid}/bible
   - body: {synopsis?, world?, narrator?, characters?}
   - characters 수정 시: ref_key는 변경 불가(컷 spec 참조 보호),
     name/role/description만 수정. 항목 추가/삭제 허용
     (삭제는 해당 ref_key가 어느 회차 대본에도 미등장일 때만 — 아니면 409)
   - 수정 후 파생 planning(episode_id 있는 회차)은 건드리지 않음 —
     대신 응답에 "대본 생성된 회차 N개는 이전 바이블 기준" 안내 플래그
3. **대본 생성 주입**: series_context 블록에 화자 명시
   - "[화자] 이 이야기는 {name}({ref_key})의 {1인칭/3인칭} 시점.
     대본의 '나'는 {name}을 가리킨다. 나레이션은 {name}의 목소리"
   - 조각 상수로 분리
4. **캐릭터 시트 연동**: 바이블 인물 description 수정 시 해당 ref_key
   캐릭터의 description을 갱신하지 **않는다** (시트 외형은 appearance_en이
   담당 — 역할 혼동 방지). 대신 시리즈 홈 인물 항목에 "캐릭터 시트
   보기" 링크만
보고 후 멈춤.

## 3단계 — 프론트 (시리즈 홈 바이블 섹션)

1. 바이블 섹션에 [수정] 버튼 → 인라인 편집 모드:
   - 시놉시스 textarea, 세계관 textarea
   - **화자 선택**: 인물 목록에서 라디오 + 1인칭/3인칭 토글.
     설명 문구: "1인칭이면 대본의 '나'가 이 인물이 됩니다"
   - 인물 카드별: 이름/역할/설명 편집, [+ 인물 추가], [삭제]
     (삭제 불가 시 이유 표시)
   - [저장] / [취소]. 저장 후 "대본 생성된 회차 N개는 이전 바이블
     기준입니다 — 필요 시 [수정 후 재생성]" 안내 배너
2. narrator_missing이면 바이블 섹션 상단에 ⚠ "화자가 지정되지
   않았습니다. 대본 시점이 흔들릴 수 있어요 — [수정]에서 지정하세요"
3. 회차 대본 생성 확인 다이얼로그에 화자 한 줄 표시
   ("화자: 남편(1인칭)") — 생성 전 마지막 확인
4. 모바일 대응 (P4 수정 모드 패턴 재사용)
보고 후 멈춤 (스크린샷).

## 4단계 — 검증

1. 도도 시리즈(10): narrator_missing 경고 표시 → [수정] → 화자를
   남편(husband, 1인칭)으로, 인물 '나(주인공)'를 "남편, 이야기의
   화자"로, '남편' 항목을 '아내'로 정정, 도도 description을
   "갈색 털의 포메라니안"으로 → 저장 → GET 반영 확인
2. 대본 생성 주입: 테스트 시리즈에서 화자 지정 후 1화 generate →
   프롬프트 로그에 [화자] 블록 + 생성 대본의 '나'가 화자 인물로
   일관되는지 육안 1회 (텍스트 비용만)
3. ref_key 보호: 바이블 인물 ref_key 변경 시도 → 거부.
   대본 등장 인물 삭제 시도 → 409
4. 신규 시리즈 바이블 생성 → narrator 필드 존재 (필수 스키마)
5. 회귀: 단편 무변경, 시리즈 홈 아웃라인 편집 무변경
보고 후 멈춤.

## 5단계 — 배포 + 사용자 확인 + 커밋

- 배포 후 사용자: 도도 시리즈 바이블 화자·인물 정정 확인 →
  2화 대본을 [수정 후 재생성]으로 화자 기준 재생성 (2화는 이미지
  전이라 비용 없음) → '나'=남편 서술로 나오는지
- 커밋: `feat(series): 바이블 인라인 수정 + 화자/시점 명시 (1-8)`

## 범위 제한
- 바이블 인물 수정이 캐릭터 시트·appearance_en을 자동 갱신하지 않음
- 대본 생성된 회차의 자동 재생성 없음 (안내만)
- ref_key 변경 기능 없음
