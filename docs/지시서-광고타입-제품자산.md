# 지시서 — 광고 타입 + 제품 자산

> Claude Code에게: EziToon에 "광고 웹툰" 제작 기능을 추가하는 지시서다.
> 광고 = 단편과 같은 파이프라인 + 제품 자산 + 광고 플래그. B2B 방향의
> 핵심 기능이며, 완성 후 도도가 자기 제품으로 광고 샘플을 만들어 갤러리
> 광고 탭을 연다. **지금은 1단계만 진행. 각 단계는 완료 보고 + 도도
> 승인 후 다음으로.**

## 공통 규칙
- 단계별 멈춤·보고, 커밋은 도도 확인 후, 파괴적 git 금지
- 마이그레이션 필요 시 project_t_test 리허설 → 백업 → "실행해" 승인
- 관리자/변경 API는 POST 통일
- 기존 단편·연작 흐름 회귀 금지 (특히 ep26 등 기존 에피소드 무영향)

## 설계 요약 (도도와 합의 완료)
- 에피소드 타입 3종: 단편 / 연작 / **광고**
  - 광고 = 단편과 동일 파이프라인(기획→대본→자산→콘티→이미지) +
    is_ad 성격의 플래그. 코드 분기는 최소화(플래그 기반)
  - 갤러리 노출 시 카테고리 기본값 '광고'
- 게이트3에 **"제품" 자산 섹션** 추가 (광고 타입에서 노출.
  구현이 단순해진다면 전 타입 노출도 허용 — 판단 후 보고)
  - 제품 사진 업로드(기존 업로드 검증 재사용: Pillow·20MB·리사이즈)
  - **[스타일 변환 생성 (1패킷)]**: 제품 사진을 참조로 에피소드
    스타일의 제품 일러스트 시트 생성 → 컷 생성 시 참조 이미지로 첨부
    (캐릭터 시트와 같은 원리, 비율은 1:1)
  - 제품명·특징 메모 필드 (컷 프롬프트에 반영)
- 게이트5에 **"제품 레이어"**: 업로드한 실사 이미지를 컷 위에 배치
  - EffectLayer/SfxLayer 인프라 재사용: product_items 배열
    ({image_ref, x, y, width, rotation, opacity}, 0~1 정규화)
  - 레이어 순서: 컷 이미지 → 제품(실사) → 효과 → 말풍선 → 효과음
  - 내보내기 4경로 전부 포함 (효과처럼 Base64 인라인)
- 광고 대본: 광고 타입의 대본 생성 프롬프트에 지침 추가 —
  "제품/브랜드를 자연스럽게 녹인 완결 스토리, 과장 광고 문구 지양,
  마지막 씬에서 제품이 자연스럽게 어필되게". 단편 완결 원칙 유지

---

## 1단계 — 조사 + 광고 타입 (지금 할 작업)
1. 조사(간단히): 에피소드 타입이 저장·분기되는 위치(단편/연작 구분
   방식), 에피소드 생성 UI, 대본 프롬프트 분기 지점, 자산 JSON 구조
   — 제품 자산·플래그를 어디에 얹을지 확정해 보고에 포함
2. 구현: 에피소드 생성 시 타입 3종 선택([+ 단편] [연작] 옆 [광고]
   — 기존 UI 패턴에 맞게), is_ad 저장(마이그레이션 없이 가능하면
   JSON), 광고 대본 프롬프트 지침 적용
3. 갤러리 연동: 광고 에피소드를 showcase 지정할 때 카테고리 기본값
   '광고' (관리자 갤러리 화면에서)
4. 보고 후 대기. 도도가 광고 에피소드 생성 + 대본(제품이 녹은
   완결 스토리) 확인

## 2단계 — 제품 자산 (게이트3) (승인 후)
1. 제품 섹션 UI: 제품 사진 업로드 + 제품명·특징 메모 +
   [스타일 변환 생성 (1패킷)] + 재생성
2. 백엔드: 제품 시트 생성(스타일+사진 참조, 1:1), 패킷 차감 훅
   연결(부족 시 402), 생성물 저장
3. 컷 생성 연동: 해당 씬에 제품이 등장하면 제품 시트를 참조로 첨부
   + 프롬프트에 제품 설명 포함 (콘티/대본에서 제품 등장 표시 방식은
   조사 결과에 맞게 설계해 보고)
4. 보고 후 대기. 도도가 실제 제품 사진으로 시트 생성 + 컷 반영 확인

## 3단계 — 제품 레이어 (게이트5) + 내보내기 (승인 후)
1. product_items 스키마 + 백엔드 검증 (effect_items 패턴)
2. 게이트5 편집기: 제품 실사 배치 UI (업로드 이미지 선택 → 드래그
   배치·크기·회전·투명도 — EffectLayer 조작 UI 재사용)
3. 공개 뷰어·내보내기 4경로에 제품 레이어 반영 (Base64 인라인)
4. 보고 후 대기. 도도가 배치·내보내기 확인 → 전체 완료 커밋

## 완료 후 (지시서 범위 외, 참고)
- 도도가 자기 제품(카페24 상품)으로 광고 샘플 웹툰 1편 제작
- 갤러리 광고 탭에 노출 → "준비 중" 탈출
