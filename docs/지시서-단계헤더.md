# 지시서 — 단계 헤더 (스테퍼 → STEP 헤더 + 단계 이동 메뉴)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> 없는 것 확인. 백엔드·DB 변경 없음. 패킷 0.
> 근거: docs/조사-단계헤더.md
> [근거] 도도 — 스테퍼가 PC에서 폭이 안 맞고(스테퍼 1280px vs 콘텐츠
> 672px), 폰에서 잘림(가로 스크롤). 다섯 개가 늘 다 보여 "지금 단계"가
> 약함 → 현재 단계를 STEP N 형태로 크게, 완료된 단계는 이동 메뉴로.
> [근거] 도도 결정 — 이동 메뉴는 **드롭다운(PC) / 바텀시트(폰)**.
> [근거] 조사 — GateProgress.jsx, gateStatus.gates[key].status
> (approved/draft/invalidated/locked), current_gate, setViewingGate(N)
> state 전환(URL 없음). locked만 클릭 불가. 되돌리기는 각 게이트의
> "수정하기" → POST revert(뒤 단계 invalidated) — **이 흐름은 그대로**,
> 헤더 메뉴는 "보기 이동"만 담당.

## 목표 (도도가 화면에서 보게 되는 것)
```
┌──────────────────────────────────────────────────────────┐
│ STEP 3 / 5                                   [단계 이동 ▾]│
│ 자산 준비                                                 │
│ 캐릭터 시트·장소·스타일을 정해요                           │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │ ← 진행 바 (완료 2/5)
└──────────────────────────────────────────────────────────┘
```
- 헤더 폭 = 게이트 콘텐츠 폭(같은 래퍼 안). PC·폰 동일 구조, 잘림 없음
- [단계 이동 ▾] → PC 드롭다운 / 폰 바텀시트:
  ```
  ✓ STEP 1  기획            완료
  ✓ STEP 2  대본            완료
  ● STEP 3  자산 준비       진행 중   ← 현재(강조)
  🔒 STEP 4  콘티·장소       잠김 — 3단계를 먼저 완료하세요
  🔒 STEP 5  이미지 검수     잠김
  ```
  invalidated는 `⚠ 다시 확인 필요 — 앞 단계가 바뀌었어요`(클릭 가능)
- 완료·진행중·다시확인은 클릭 → 그 게이트로 이동(지금 스테퍼 클릭과
  동일, setViewingGate). 잠김은 비활성 + 이유 텍스트
- "보는 중" 표시: 현재 게이트가 아닌 완료 단계를 보고 있을 때 헤더에
  작은 배지 `보기 모드 · 수정하려면 아래 [수정하기]` + [현재 단계로
  돌아가기] 링크(현재 current_gate로)

## 1단계 — StepHeader 컴포넌트 (GateProgress.jsx 교체)
- 파일: components/StepHeader.jsx 신규, GateProgress.jsx 사용처 전부
  교체 후 GateProgress는 삭제(또는 deprecated 주석)
- 단계 정의 상수(한 곳): 
  | N | key | 이름 | 설명 |
  |---|---|---|---|
  | 1 | planning | 기획 | 아이디어와 등장인물을 정리해요 |
  | 2 | script | 대본 | 컷별 대사와 장면을 만들어요 |
  | 3 | assets | 자산 준비 | 캐릭터 시트·장소·스타일을 정해요 |
  | 4 | storyboard | 콘티·장소 | 컷 구성과 말풍선 배치를 확인해요 |
  | 5 | images | 이미지 검수 | 생성된 컷을 확인하고 공개·내보내요 |
  (key는 실제 gateStatus.gates 키에 맞출 것 — 조사 파일 참고)
- 표시 로직: displayGate = viewingGate || current_gate. 헤더의 STEP·
  이름·설명은 displayGate 기준. 진행 바 = approved 개수 / 5
- 상태 아이콘: approved ✓(초록) / draft·current ●(보라) / invalidated
  ⚠(amber) / locked 🔒(회색). 현재 단계 행은 배경 강조
- 드롭다운: PC(sm 이상) 버튼 아래 absolute 메뉴(z-50, 바깥 클릭·Esc
  닫힘). 폰 바텀시트(반투명 배경 + 라운드 카드, 항목에 설명 한 줄).
  인스타 공유 모달·재생성 바텀시트와 같은 스타일
- 접근성: 버튼 aria-expanded, 메뉴 role=menu, 항목 aria-disabled
- 폭: 게이트 콘텐츠와 같은 max-width 래퍼 안에 배치(게이트5처럼 넓은
  화면이면 그 폭을 따라감) — "스테퍼가 혼자 1280px" 문제 해결
- 다크·375px. 헤더 높이 폰 기준 ~110px 이내

## 2단계 — 흐름 통일·폴리싱
- 게이트 1~4 하단 "승인 → 다음 단계"/"콘티 승인 → 이미지 생성 시작"
  버튼은 유지, 문구만 통일: `승인하고 STEP {N+1} {이름}으로 →`(게이트4는
  `콘티 승인 → 이미지 생성 시작` 유지 — 패킷 소모가 시작되는 지점이라
  문구가 달라야 함)
- 보기 모드에서 상단 [현재 단계로 돌아가기] 동작
- 에피소드 목록으로 가는 "← 에피소드 목록"은 헤더 위 그대로
- mobile-check: 헤더·바텀시트 375/412, 게이트 1·3·5 각 1장

## 3단계 — docs

## 검증
- Claude Code(Playwright, 배포 전): PC 1280·폰 375에서 게이트 1·3·5
  헤더 캡처 / 메뉴 열고 완료 단계 클릭 → 이동 / 잠김 클릭 → 무시 /
  보기 모드 배지·돌아가기 / invalidated 표시(revert 후 상태) → 캡처
- 도도(PC, 패킷 0): "캐릭터 테스트" 열어서 헤더 모양·폭, [단계 이동 ▾]
  → STEP 1 기획으로 이동 → "보기 모드" 배지 → [현재 단계로 돌아가기].
  폰으로 같은 화면 한 번(바텀시트)
