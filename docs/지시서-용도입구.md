# 지시서 — 용도별 입구 + 광고 브리프 + 참고 광고 (한 컷 광고 트랙)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> 없는 것 확인. **DB 마이그레이션 없음**(gate_status JSON 키·idea_brief
> JSON 확장·bubble_style 값 추가). 테스트는 테스트 프로젝트 새 에피소드만.
> 근거: docs/조사-용도입구.md, docs/조사-제품자산.md, 첨부 시안(ONE CUT
> STUDIO 폼: 목적 6 · 전달 내용 · 분위기 6 · 추가 설정)
> [근거] 도도 — 기존 파이프라인은 "이야기"를 전제로 해서 한 컷 광고엔
> 기승전결·씬·대사가 군더더기. 광고주는 "뭘 광고할지 → 뭘 말할지 → 어떤
> 분위기"로 생각한다. 단편·연작 메뉴를 용도형으로 바꾼다. 참고 광고 이미지
> (남이 만든 광고 캡처)로 분위기·레이아웃을 따라가고 싶다.
> [근거] Claude — 새 파이프라인을 만들지 않는다. **브리프 질문은 컷 수와
> 무관한 "광고 브리프"**이므로 STEP 1 입력 방식만 purpose로 분기하고, 한
> 컷은 컷 수=1인 경우. STEP 3~5(스타일 16종·실사 캐릭터·참조·제품·연출·
> 모션·릴스·공유)는 그대로. 한 컷 트랙은 헤더를 "브리프 → 자산 → 완성"
> 3단계로 보여주되 속은 5게이트.
> [근거] 조사 — purpose 키 신설 가능, idea_brief에 ad 키 4개 추가, 1컷
> 대본은 기존 스키마로 표현 가능(최소 6컷·씬당 2컷은 프롬프트일 뿐 코드
> 가드 없음), 콘티 1컷 OK(readjust 건너뜀), StepHeader purpose 분기 가능,
> bubble_style "headcopy"로 헤드카피, reference_ads JSON 2장 + 참조 슬롯
> 3순위(시트→제품→참고→표정→장소), 저작권 안내는 모달+약관.
> [근거] 도도 확인 — 기존 자산 기능(스타일·실사·참조·제품·장소)은 전부
> 그대로 쓴다.

## 목표 (도도가 화면에서 보게 되는 것)
- **새 에피소드 만들기**: "무엇을 만들까요?" 카드 3개 + 작은 링크 1
  (**도도 확정**)
  - **한 컷 광고** — "제품·가게 홍보 한 장. 피드·스토리용" → 한 컷 페이지
    ·1:1·광고 ON·컷 1 (purpose `onecut_ad`)
  - **인스타툰 광고** — "4~8컷 캐러셀 + 릴스" → 2×2 또는 세로·컷 4~8·
    광고 ON·브리프 (purpose `instatoon_ad`)
  - **브랜드 연재툰** — "매주 이어지는 우리 가게 이야기" → 연작·광고 ON·
    브리프(1화 브리프 + 화별 소재) (purpose `brand_series`)
  - 아래 작은 글씨 *"광고가 아니에요 → 일상툰·이야기로 만들기"* → 지금
    이야기 폼 그대로(단편/연작 선택, 광고 OFF) (purpose `story`)
  - 세 카드는 광고 ON 기본·브리프로 시작, 네 번째만 현행 폼. "광고용
    토글"은 없음(카드가 곧 광고)
- **한 컷 광고 트랙 헤더**: `브리프 → 자산 → 완성` 3단계(속은 게이트
  1~5, 1·2가 "브리프", 3이 "자산", 4·5가 "완성")
- **브리프(STEP 1)**: ① 목적 칩 6(상품 광고 · 브랜드 홍보 · SNS 콘텐츠 ·
  이벤트 홍보 · 정보 전달 · 밈·패러디) ② "어떤 내용을 전달하고 싶나요?"
  텍스트(예시 플레이스홀더) ③ 분위기 라디오 6(프리미엄 · 웹툰·캐릭터 ·
  유머·병맛 · 감성·무드 · 실사 광고 · AI 추천) ④ 추가 설정 접힘(타깃 ·
  CTA 문구 · 제품 선택/업로드 · 브랜드 색 · 넣지 말 것) → [광고 기획안
  만들기] → 같은 화면 아래에 **기획안**: 핵심 메시지 1줄 · 타깃 · **카피
  후보 3**(하나 선택, [✨ 다시 쓰기] 칩: 더 짧게·임팩트·감성·유머·신뢰) ·
  **장면 아이디어 3**(하나 선택) · 추천 스타일(분위기 매핑, 바꿀 수 있음)
  → [이대로 진행]
- **대본(STEP 2, 한 컷)**: 장면 1 · 헤드카피 · 서브카피(선택) · 말풍선 한
  줄(선택) · 샷/앵글 칩 — 브리프 화면 아래 이어서 보임(한 컷 트랙은 1·2가
  한 화면). 인스타툰·광고 ON은 지금 대본 생성 + AD_ADDON(브리프 주입)
- **자산(STEP 3)**: 광고 purpose면 **제품 섹션 맨 위** → 캐릭터(모델) →
  장소 → **참고 광고**(새 섹션, 최대 2장: 올리면 분석 칩 "따뜻한 · 크림
  골드 · 인물 좌/제품 우 · 상단 헤드카피 · 자연광" 편집 가능, 토글
  "레이아웃 따라가기"(기본 OFF: 텍스트로만 참고 / ON: 이미지도 참조로),
  안내 "분위기·구도만 참고해요. 글자·로고·실제 인물은 재현하지 않아요")
- **완성(STEP 4·5)**: 콘티 1컷 → 생성 1패킷 → 컷 위에 **헤드카피 레이어**
  (내레이션 박스의 큰 글씨 버전, 상단/하단, 폰트·크기·색) → 인스타 공유·
  PNG·(모션·릴스는 그대로)
- **빠른 한 컷** 결과 버튼 "이 컷으로 이야기 만들기" → **"한 컷 광고로
  제대로 만들기 →"** (새 프로젝트 purpose=onecut_ad, 장면·캐릭터·제품
  승계, 브리프 전달 내용에 장면 문장 미리 채움)
- 안내 문구: 새로 만드는 화면(입구·브리프·기획안·한 컷 대본·참고 광고·
  헤더)은 처음부터 "사장님 말투"로. 나머지 페이지 문구 정리는 별도 작업

## 1단계 — 백엔드
- **purpose**: gate_status.purpose = `onecut_ad` | `instatoon_ad` |
  `brand_series` | `story`. create_initial_gate_status(purpose) → 프리셋:
  onecut_ad = single_page·1:1·is_ad true·target_cuts 1 / instatoon_ad =
  grid_2x2(기본, 세로 선택 가능)·cuts 4~8·is_ad true / brand_series =
  연작·is_ad true·1화 브리프 + 화별 "이번 화 소재" 한 줄 / story = 현행
  (단편/연작, is_ad false). 기존 에피소드는 purpose 없음 → `story`(is_ad
  현행값 유지)로 읽기 호환. 브리프는 광고 purpose 3개 공통, 컷 수만 다름
- **idea_brief 확장**: `ad_purpose`(6 중 1), `key_message`, `target_
  audience`, `cta`, `mood`(6 중 1), `extras`{brand_colors, avoid},
  `copy_candidates[3]`, `copy_selected`, `scene_ideas[3]`, `scene_selected`,
  `recommended_style`. story 4단 라벨은 광고면 "상황→문제→해결→CTA"로
  (키는 ki/seung/jeon/gyeol 유지)
- **광고 기획안 프롬프트**(app/prompts/ad_brief.py 한 곳): 입력(목적·전달
  내용·분위기·타깃·CTA·제품 정보·참고 광고 분석 텍스트) → 핵심 메시지·
  타깃·카피 후보 3(헤드 12자 내외·서브)·장면 아이디어 3(한 줄 + 샷)·추천
  스타일. 0패킷. 카피 다시 쓰기 = 기존 SECTION_DIRECTION_PROMPTS 패턴으로
  COPY_DIRECTION_PROMPTS(더 짧게·임팩트·감성·유머·신뢰)
- **1컷 대본 프롬프트**: purpose=onecut_ad면 "씬 1·컷 1. 장면 = 선택한
  장면 아이디어. dialogue = [{type speech, 말풍선 한 줄(있으면)}],
  headcopy·subcopy 필드 별도. 최소 컷·씬당 2컷 규칙 적용 안 함". 기존
  스키마(scenes>cuts) 유지. readjust 호출 건너뜀. 콘티 1컷 생성 확인
- **mood_mapping.py**: 분위기 → {style preset, drama_level, photo_real
  권장, 색감 힌트} — 프리미엄: 깔끔 톤(emotional/clean 계열)+light / 웹툰·
  캐릭터: korean_webtoon+normal / 유머·병맛: korean_webtoon+strong / 감성·
  무드: emotional_romance+light / 실사 광고: 실사 캐릭터 권장+실사 제품
  오버레이 권장 / AI 추천: 기획안에서 모델이 고름. 사용자는 STEP 3에서
  변경 가능(매핑은 기본값)
- **헤드카피 레이어**: dialogue type narration + bubble_style `headcopy`
  (큰 글씨, 기본 상단 띠 없이 텍스트+그림자 또는 반투명 박스, 위치 top/
  bottom). BubbleOverlay·Pillow compose·exportRenderer 세 곳 동일 렌더
  (RENDERER_VERSION 올림). 1컷 생성 후 대본의 headcopy를 자동으로 레이어로
  넣음(사용자가 편집기에서 수정·삭제)
- **참고 광고**: gate_status.reference_ads = [{url, analysis:{mood,
  colors, composition, text_layout, lighting, note}, follow_layout:bool}]
  최대 2. POST /episodes/{id}/reference-ads(업로드+비전 분석, 0패킷) /
  PUT(칩 수정·토글) / DELETE. build_cut_prompt에 분석 텍스트를 **제품
  절 뒤**에 삽입("Match the mood/colors/composition described; do not
  reproduce any text, logo, or real person from references"). follow_
  layout ON이면 참조 슬롯 3순위로 이미지 첨부(시트→제품→참고→표정→장소).
  광고 기획안 프롬프트에도 분석 텍스트 전달
- **expand → onecut_ad**: 빠른 컷 expand가 purpose=onecut_ad 새 프로젝트
  생성 + is_ad + products 행 승계 + idea_brief.raw(장면 문장) + 캐릭터
  복사. 기존 "이야기 만들기" 경로는 유지(버튼 문구만 바뀜)
- 약관 1줄: "참고 이미지는 분위기·구도 참고에만 사용되며 타인의 저작물을
  그대로 재현하지 않습니다. 업로드한 이미지의 권리 문제는 이용자 책임"

## 2단계 — 프론트
- **에피소드 생성 모달**: 카드 3(한 컷 광고 · 인스타툰 광고 · 브랜드
  연재툰, 아이콘·제목·한 줄) + 아래 작은 링크 "광고가 아니에요 → 일상툰·
  이야기로 만들기"(현행 단편/연작 폼). 인스타툰 광고는 형식(2×2/세로)
  선택 유지. 메인 카드에서 단편/연작 문구 제거
- **StepHeader**: purpose=onecut_ad면 STEPS 3개(브리프·자산·완성), 게이트
  1·2 → 1, 3 → 2, 4·5 → 3. 단계 이동 메뉴도 3개. 프로그레스 동적
- **Gate1 AdBriefForm**(purpose 광고일 때): 목적 칩 6 · 전달 내용
  textarea(플레이스홀더 예시 로테이션) · 분위기 라디오 6(설명 한 줄) ·
  추가 설정 접힘(타깃·CTA·제품 선택/업로드(STEP 3 제품 모달 재사용)·브랜드
  색·넣지 말 것) · [광고 기획안 만들기] → 기획안 카드(핵심 메시지·타깃·
  카피 후보 3 라디오 + [✨ 다시 쓰기] 칩 + 직접 입력·장면 아이디어 3 라디오·
  추천 스타일 미리보기) → [이대로 진행]. planning_draft 자동 저장·stale
  시그니처에 브리프 키 포함
- **한 컷 대본**(onecut_ad): 같은 페이지 아래 "대본" 카드 — 장면 문장 ·
  헤드카피 · 서브카피 · 말풍선 한 줄 · 샷/앵글 칩 · [승인하고 자산으로 →].
  인스타툰·광고 ON은 기존 Gate2 그대로(브리프가 주입된 대본)
- **Gate3**: 광고 purpose면 섹션 순서 제품 → 캐릭터(라벨 "모델") → 장소 →
  **참고 광고**. 참고 광고 카드(썸네일·분석 칩·[레이아웃 따라가기] 토글)·
  [참고 광고 추가] 모달(업로드 + 안내 문구 + 분석 결과 칩 편집). 분위기
  매핑된 스타일이 기본 선택돼 있고 바꿀 수 있음
- **Gate4·5**: 1컷 콘티 카드, 생성 후 헤드카피 레이어 자동 삽입, 편집기
  내레이션 탭에 "헤드카피" 스타일(크기 L/XL·상단/하단·색·그림자). 인스타
  공유는 그대로
- **빠른 한 컷** 결과: "한 컷 광고로 제대로 만들기 →"(토스트 "브리프부터
  차근차근 만들어요") + 작은 링크 "이야기로 만들기"
- 폰 375·412 다크. 새 화면 문구는 사장님 말투(예: "등장인물" 대신 "모델",
  "이야기" 대신 "전달 내용")
