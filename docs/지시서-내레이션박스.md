## 목표 (도도가 화면에서 보게 되는 것)
- 새로 만드는 컷의 내레이션은 기본이 **박스**: 흰 바탕, 검은 얇은
  테두리, 검은 글씨, 글자 가운데 정렬, 꼬리 없음. 처음 위치는 컷
  왼쪽 위, 한 컷에 두 개째면 오른쪽 아래(레퍼런스처럼 대각선)
- 편집기에서 박스를 **드래그로 이동**, 모서리 핸들로 **폭 조절**(높이는
  글자에 맞춰 자동 — 말풍선과 동일), **글자 크기 3단**, 텍스트 수정,
  삭제, [내레이션 추가] — 전부 말풍선과 같은 손맛
- 내레이션마다 **[박스 ↔ 띠] 전환** 버튼. 기존 작품은 띠 그대로(건드리지
  않음), 편집기에서 바꾸고 싶을 때만 전환. [이 화 전체 박스로] 한 번에
- 게이트5 미리보기·편집기·뷰어·내보내기·최종 합성 이미지 **5곳이 똑같이**
  보임

## 1단계 — 데이터 + 렌더 (프론트 BubbleOverlay + 백엔드 Pillow)
- 데이터: narration 항목의 `bubble_style`에 `"box"` | `"bar"` 두 값.
  **없으면 `"bar"`**(기존 126컷 호환 — 데이터 수정 없음). 스토리보드
  생성·컷 복제 등 **새로 만들어지는 narration은 `"box"`** + 기본 layout
  (아래). 생성 코드에서 narration 만드는 지점 전부 찾아 적용(조사
  10번: bubble_style 수동 지정 5건뿐이라 narration엔 지금 거의 비어
  있음 — 빈 값 = bar로 안전)
- 기본 layout(box): 컷 내 narration 순서 n=0 → x 0.04·y 0.04·w 0.44,
  n=1 → x 0.52·y 0.70·w 0.44, n≥2 → 직전 아래로 y+0.14(겹치면 그대로,
  사용자가 옮김). bar는 기존 y=0.82 전폭 유지
- BubbleOverlay.jsx narration 분기를 둘로: `bar`(기존 코드 그대로) /
  `box`: 흰 배경(#FFFFFF) + 검은 테두리(이미지 폭 기준 0.3%, 최소 1.5px,
  모서리 반경 0) + 검은 글씨 + 안쪽 여백(글자 크기의 0.6배) + 가운데
  정렬 + 폭 w 안에서 자동 줄바꿈 + 높이 자동. 글꼴·font_scale 3단은
  말풍선과 **같은 값** 재사용
- 백엔드 compose_dialogue_on_image에 동일 분기(Pillow). 줄바꿈·여백·
  테두리 두께가 프론트와 눈으로 구분 안 될 정도로 맞을 것(말풍선 때
  쓴 측정 방식 그대로). **RENDERER_VERSION 올리기**(기존 합성 이미지는
  bar라 재합성돼도 결과 동일 — 버전 올리는 건 box 컷이 재합성되게)
- Claude Code 자체 확인: 가짜 spec으로 box 2개·bar 1개 섞인 컷을
  프론트 4곳 + Pillow 결과 캡처해서 보고(5장)

## 2단계 — 편집기 (CutEditor.jsx)
- narration이 `box`일 때: 드래그 이동(:414)·폭 리사이즈(:471) **잠금
  해제**, 꼬리 컨트롤은 계속 숨김, font_scale 3단(:1399)·삭제(:407)
  그대로. `bar`일 때는 지금처럼 전폭 고정(이동 X)
- 항목마다 [박스 ↔ 띠] 토글(아이콘 버튼, 현재 상태 표시). 띠→박스
  전환 시 기본 layout 부여, 박스→띠는 y=0.82 전폭
- 툴바 [이 화 전체 박스로] / [이 화 전체 띠로] — 확인창 "이 화의 모든
  컷 내레이션을 바꿀까요?" → 전 컷 narration bubble_style 일괄 변경 +
  layout 기본값(이미 box인 건 layout 유지)
- [내레이션 추가] — 말풍선 추가와 같은 자리, type narration·style
  box·빈 텍스트 → 바로 텍스트 입력 포커스. (이미 있으면 위치만 확인)
- 저장은 기존 spec 저장 경로 그대로(필드 추가뿐). 모바일 터치(Pointer)
  동일 동작
- → 배포 → 도도 확인 → 커밋 "feat: 내레이션 박스 — 띠/박스 전환·이동·
  폭·글자 크기"
