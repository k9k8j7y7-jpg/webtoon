# 인스타 공유 현황 조사 (2026-10-14)

## 1. Gate5 "인스타" 내보내기 파이프라인

| 항목 | 값 |
|---|---|
| 경로 | **프론트 Canvas** (`exportRenderer.js:474 exportAsInstagram`) |
| 렌더 | `renderCutToCanvas` (이미지 → Canvas → 제품·효과·SVG말풍선·PNG말풍선·효과음 오버레이) → 1080×1080 letterbox |
| letterbox | `scale = Math.min(1080/W, 1080/H)`, 흰 배경(`#fff`) 중앙 배치, crop 없음 |
| 포맷 | **PNG** (`canvas.toBlob('image/png')`, quality 인자 없음 = 무손실) |
| 출력 | **ZIP** (`JSZip`, `compression: 'STORE'`). 파일명 `instagram_001.png`, `instagram_002.png`, … |
| 크기 | 항상 **1080×1080 px** (`INSTA_SIZE = 1080`, line 472) |
| 장수 | `image_url` 있는 컷 전부 (상한 없음) |
| page_format 분기 | `grid_2x2`·`strip_3`면 `composePageGrid` 후 페이지 단위 ZIP. 여전히 1080px PNG |

### 레거시 백엔드 경로 (미사용)
`export/service.py:145 export_instagram_carousel` — Pillow 1080×1080, **JPEG q=95**, `slide_001.jpg`. 말풍선 미포함. Gate5 UI가 호출하지 않음.

### 예상 용량
- PNG 1080×1080 (웹툰 컷): 장당 **300~900 KB** (콘텐츠 밀도에 따라)
- 레거시 JPEG q95: 장당 ~100~300 KB

## 2. 뷰어 `/view/{token}` 공유 버튼

| 항목 | 상태 |
|---|---|
| 공유 버튼 | **없음** — 헤더에 EziToon 로고 + 에피소드 제목만 |
| 링크 복사 | **없음** (뷰어에는 없음. Gate5 `PublishBar.jsx`에만 있음) |
| `is_public` 판정 | **서버** — `showcase/router.py:108` `if not episode.is_public` → 소유자 외 403 |

### Gate5 PublishBar (작가 전용)
- "링크 복사" 버튼: `navigator.clipboard.writeText(shareUrl)` + fallback `window.prompt()`
- "보기" 외부 링크
- URL 조립: `${window.location.origin}/WEBTOON/view/${share_token}` (line 55)

## 4. 캡션 조립용 데이터 가용성

### 뷰어 (`ViewerPage.jsx`)
| 데이터 | 소스 | 변수 |
|---|---|---|
| 에피소드 제목 | `GET /showcase/view/{token}` 응답 | `data.title` |
| 작가 닉네임 | 〃 | `data.author.nickname` |
| 공개 링크 | URL params | `${origin}/WEBTOON/view/${shareToken}` |
| `is_public` | 〃 | `data.is_public` (있지만 미렌더) |

**→ 제목·닉네임·링크 3개 모두 뷰어에서 즉시 사용 가능**

|---|---|

| 닉네임 | `useAuth()` → `user.nickname` |
