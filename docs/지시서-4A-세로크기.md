# 지시서 4-A — 말풍선 세로 크기 조절 (최소 높이)

> **전제:** 스파이크 3종 꼬리 제거 + 3단계 완료 커밋이 끝난 상태에서 시작한다.
> **작업 방식:** 아래 단계 순서대로 진행. **각 단계 종료 시 멈추고 보고 → 사용자 확인 후 다음 단계.**
> **커밋은 사용자 확인 후에만.** 파괴적 git 명령 금지. bubbleSpec.json 열지 말 것.

---

## 0. 목표와 핵심 규칙

- 말풍선의 **세로 크기를 사용자가 키울 수 있게** 한다. 단, 의미는 "고정 높이"가 아니라 **"최소 높이"**다.
- **최종 높이 = max(텍스트 요구 높이, 사용자 지정 높이)**
  - 텍스트가 요구하는 높이보다 작게는 절대 만들 수 없다. 텍스트 잘림/삐져나옴은 어떤 경우에도 실패다.
- 계산 순서 고정 (순환 참조 금지):
  ```
  ① 너비 확정 (기존 너비 슬라이더)
  ② wrapText로 줄수 확정
  ③ 텍스트 요구 높이 계산 (줄수 × fontSize × 1.45 + 패딩)
  ④ 최종 높이 = max(③, 사용자 지정 높이)
  ```
  높이가 줄바꿈에 영향을 주는 코드를 만들지 말 것.
- 모든 px 값은 기존 규칙대로 `scale = width / REF_WIDTH` 곱셈 체계를 따른다.

## 2단계 — 데이터 필드 확정 + 계산 로직

> 1단계 조사 결과 기존 필드가 있으면 그것을 재사용하고, 정의만 아래에 맞춘다.
> 없으면 신규 추가한다.

### 필드 정의
- `bubble_layout.min_height_ratio` (number, 기본 **0**)
- 의미: **텍스트 요구 높이 대비 추가 비율.** 최종 높이 = 텍스트 요구 높이 × (1 + min_height_ratio)를 하한으로 사용
- 범위: 0 ~ 1.0 (0% ~ +100%)
- **기본값 0 = 현재 동작과 완전 동일.** 기존 저장 컷은 무변경 렌더여야 한다 (마이그레이션 없음)

### 계산 로직 (스타일별)

**공통:** 0장의 계산 순서를 따른다. 사용자 지정 높이는 ④에서만 개입한다.

**타원 계열 (round, whisper, thought, happy, sad, realize):**
- fixedWidth=true 경로: 기존 `ry = b/√(1-(a/rx)²)` 역산값을 `ryText`라 할 때
  `ry = max(ryText, ryText × (1 + min_height_ratio))` → 즉 ryText × (1 + ratio)
- safeRatio 0.85 상한 등 기존 안전장치는 그대로 유지
- ⚠️ **computeSingleBubbleGeo와 SingleBubble 두 곳을 반드시 동일하게 수정.**
  한 곳만 고치면 썸네일-미리보기 불일치 사고. 수정 후 두 함수의 해당 부분을 나란히 보고에 첨부할 것.

**사각 계열 (narration, flustered, shy):**
- 기존 높이 계산 결과에 × (1 + min_height_ratio)
- flustered의 radius 상한(H × 0.35)은 **최종 높이 기준**으로 계산 (커진 높이에 비례)

**스파이크 계열 (shout, angry, surprised):**
- 골 타원(inner) 높이에 동일 배율 적용. 돌기 길이는 기존 비율 유지 (본체가 커지면 돌기도 비례)

### 이 단계 검증
- `/bubble-test`에 min_height_ratio 0% / 30% / 60% 비교 섹션 추가 (스타일 드롭다운 연동)
- `npm run bubble-shot` 후 **수치 판정:**
  - ratio=0일 때 boundingBox 높이가 기존과 동일 (±1px)
  - ratio=0.3일 때 높이가 정확히 ×1.3 (±2px) — 타원/사각/스파이크 각 1종씩 3종 확인
  - 텍스트 boundingBox가 말풍선 boundingBox 내부 (모든 케이스)
- 눈대중 판정 금지. 수치 출력 필수.

**여기서 멈추고 수치 표 + 스크린샷 보고. 확인 대기.**

## 3단계 — 편집기 UI 연결
