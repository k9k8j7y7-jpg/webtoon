## 2. 결제 [선택하기] 현재 동작

**파일:** `frontend/src/pages/PacketsPage.jsx`

1. 카드 [선택하기] 클릭 → `POST /payments/orders` (상품 code·금액)
2. 서버가 `orders` 테이블에 `pending` 생성 + `client_key`(토스 클라이언트 키) 반환
3. `window.TossPayments(client_key).widgets()` → 인라인 결제 위젯 렌더
4. [결제하기] → `requestPayment()` → 토스 결제창
5. 성공 리다이렉트 → `POST /payments/confirm` → 토스 승인 API → 패킷 지급

**토스 키 상태:** `config.py`에 `TOSS_CLIENT_KEY`·`TOSS_SECRET_KEY` 환경변수. CLAUDE.md "라이브 키 전환(가맹 심사 후)" 미완료 → **테스트 키 상태**. 테스트 카드로 결제 가능, 실카드 불가.
