## 1. 스타일 카탈로그

### 위치
- **단일 소스:** `backend/app/styles/models.py:6` — `STYLE_PRESETS` dict (코드 상수, DB 아님)
- 조회 API: `GET /styles/presets` (`backend/app/styles/router.py:21`) → `{core: [{key,label,tier}], beta: [...]}`. **prompt는 응답에 포함되지 않음**
- 선택 API: `PUT /projects/{pid}/episodes/{eid}/style` (`router.py:36`) → `styles` 테이블에 `preset_key`, `tier`, `prompt_snippet`(프롬프트 **복사본**) 저장
  - 즉 컷 생성은 `STYLE_PRESETS`가 아니라 **선택 시점에 복사된 `styles.prompt_snippet`** 을 사용 → 프리셋 문구를 바꿔도 기존 에피소드에는 반영 안 됨
- 프론트에는 별도 카탈로그 없음 (Gate3가 API 응답만 사용)

## 4. 로컬 단독 실행 시 재사용 함수·환경 키

### 재사용 후보
| 용도 | 함수 | 위치 | DB 필요 |
|---|---|---|---|
| 이미지 생성 (재시도 2회·aspect_ratio 전달·ImageResult 반환) | `get_image_adapter().generate_image(prompt, reference_images=None, reference_labels=None, seed=None, aspect_ratio="9:16")` (async) | `backend/app/adapters/gemini_image.py:31`, 싱글턴 `:161` | ❌ |
| 컷 프롬프트 조립 | `build_cut_prompt(cut_spec, character_descs, location_desc, style_prompt, project_rules=None, loc_is_photo=False, aspect_ratio="9:16", product_desc="")` | `backend/app/prompts/service.py:60` | ❌ (순수 함수) |
| 스타일 문구 | `STYLE_PRESETS[key]["prompt"]` | `backend/app/styles/models.py:6` | ❌ (import 시 `app.database` 로드됨 — 연결은 쿼리 시점) |
| 결과 객체 | `ImageResult(image_bytes, seed, model, mime_type)` | `backend/app/adapters/base.py` | — |

- 썸네일은 캐릭터 참조 없이도 `build_cut_prompt`에 가짜 `cut_spec`(characters 빈 배열 + action + shot)을 넘겨 **실제 컷과 동일한 프롬프트 골격**을 얻을 수 있음. `character_descs={}`이면 앵커링 블록은 생략됨
- `app.images.service`는 DB·스토리지 의존이 커서 단독 실행엔 부적합 (`generate_cut_image`는 Cut ORM 객체 필요)
- 기존 선례: `scripts/gpt_image_test.py` — `sys.path`에 `backend/` 추가 + `load_dotenv(BACKEND_DIR / ".env")` 후 app 모듈 import하는 패턴
- 출력 포맷 주의: 3.1 모델은 JPEG 반환(`result.mime_type` 확인), 참조 이미지 첨부 시 어댑터는 mime을 `image/png`로 고정 표기

### .env 키 이름 (값 미기재)
- 사용 키: **`GEMINI_API_KEY`**, **`IMAGE_MODEL`** (`backend/app/config.py:56-57`, pydantic-settings, `env_file=".env"` — CWD 기준 상대경로)
- ⚠ **로컬 `backend/.env`에 `IMAGE_MODEL` 키가 없음** (GEMINI_API_KEY는 있음). 그대로 실행하면 config 기본값 `gemini-2.5-flash-image`(2026-10-02 종료 예정, 서버와 다른 모델)로 생성됨 → 실행 시 환경변수로 `IMAGE_MODEL=gemini-3.1-flash-image` 지정하거나 로컬 .env에 한 줄 추가 필요
- `IMAGE_MODEL`은 `gemini_image.py:24`에서 **import 시점에 모듈 상수로 고정** → import 전에 환경변수 설정해야 반영
- `env_file=".env"`는 CWD 상대 → `backend/`에서 실행하거나 스크립트에서 `load_dotenv(backend/.env)` 선행 필요
- 비용: 이미지당 ~$0.067 (3.1 Flash) → 15종 × 1장 ≈ $1, 후보 여러 장 뽑으면 배수
