## 문제 유형별 정리

### A. "(준비 중)" 플레이스홀더 (5건)
- `siteInfo.js` — 상호·대표·사업자번호·통신판매·주소·전화 → 출시 전 **필수** 교체

### B. 개발 용어·영문 키 노출 (8건)
- "게이트 1 — 기획" → "STEP 1"
- "바이블" → "시리즈 기본 설정"
- "아웃라인" → "회차 목록"
- "파생 기획" → "시리즈에서 가져온 기획"
- "로그라인" → "한 줄 소개"
- ref_key 직접 노출 (Gate1 읽기전용, SeriesPage)
- 추천 스타일 영문 키 (korean_webtoon 등)
- "자산 준비" → "준비"

### C. 말투 불일치 — "~했습니다" vs "~했어요" (10건)
- "대본 생성에 실패했습니다." → "~못했어요"
- "저장에 실패했습니다." → "~못했어요"
- "승인에 실패했습니다." → "~못했어요"
- "기획 생성에 실패했습니다." → "~못했어요"
- "프로젝트를 삭제하시겠습니까?" → "~지울까요?"
- "재정리에 실패했습니다." → "~못했어요"
- "저장된 기획 데이터가 없습니다." → "아직 ~없어요"
- "저장된 대본 데이터가 없습니다." → "아직 ~없어요"
- "{n}패킷이 충전되었습니다!" → "충전 완료!"
- "기획이 수정되어 대본을 다시 생성해야 합니다" → "~해야 해요"

### D. 길거나 어색한 문구 (6건)
- 보여줄 특징 라벨 너무 김
- 비용 비교 "125장" 근거 불명확
- Footer 슬로건 개발자 시점
- "버스트" vs "바스트샷" 불일치
- "지문 재작성 실패" → "장면 설명 다시 쓰기"
- 연재툰 desc "같은 제품으로" → 이야기 연재에 맞지 않음

### E. 오래된·정확하지 않은 내용 (5건)
- FAQ 문의 이메일 직접 노출
- 제품명 placeholder 영문만
- 402 에러 변수명 느낌
- "새 에피소드" / "새 화" / "새 화 만들기" 3가지 혼재
- "생성" 버튼 맥락 부족 → "만들기"
