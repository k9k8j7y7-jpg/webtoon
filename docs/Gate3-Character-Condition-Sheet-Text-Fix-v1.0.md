# Project T — 게이트 3 캐릭터 조건편집·시트 텍스트 수정 지시서

> **버전:** v1.0
> **작성일:** 2026-08-01
> **대상:** Claude Code
> **참조 문서:** docs/ 의 Gate3-Asset-Revision, Korean-Text-Speech-Bubble-System(A파트 텍스트 억제), Data-Model
> **범위:** 게이트 3 캐릭터 조건 편집 버튼 노출 문제 + 캐릭터 시트에 텍스트 깨져 박히는 문제.

---

## 배경

Gate3 Bundle B(캐릭터 조건 편집) 구현 후 테스트 결과 두 문제 발견:

1. **조건 편집 버튼이 화면에 안 보임** — "[조건 편집] 버튼을 각 캐릭터 카드에 추가했다"고 보고됐으나, 실제 게이트3 화면의 캐릭터 카드(김준호, 이민영)에 버튼이 표시되지 않음.
2. **캐릭터 시트에 텍스트가 깨져서 박힘** — 캐릭터 시트 이미지(정면/smile/angry)에 캐릭터 설명이 그려지는데 완전히 깨짐. 예: "외묘: 차분하오 섬새루입산...", "조옹하고 센형적 꿈마암...".

---

## 수정 1. 조건 편집 버튼 노출

**현재:** 캐릭터 카드에 [조건 편집] 버튼이 안 보임(코드는 추가했다고 하나 화면 미표시).

**확인·수정:**
- 캐릭터 카드에 **[조건 편집] 버튼이 항상 보이도록** 함.
- 배포/캐시 문제인지 확인(빌드가 반영됐는지). 반영됐는데도 안 보이면 조건부 렌더링 로직 점검(예: 특정 status에서만 표시되게 돼 있는지).
- 버튼은 각 캐릭터 카드(김준호, 이민영 등)마다 명확히 보여야 함.

> 전역 원칙: 사용자가 조건 편집 기능을 바로 발견할 수 있어야 함.

---

## 수정 2. 캐릭터 시트 텍스트 억제 (★핵심)

**현재:** 캐릭터 시트 생성 시 캐릭터 description이 이미지 프롬프트에 들어가, 그림에 텍스트가 깨져서 박힘.

**원인:** 말풍선 지시서 A파트("그림 속 텍스트 억제")가 **게이트5 컷 이미지에만 적용되고, 게이트3 캐릭터 시트 생성에는 적용 안 됨.** 캐릭터 시트는 여전히 옛날 방식으로 description을 프롬프트에 포함.

**수정:** 게이트5 컷에 적용한 텍스트 억제를 **캐릭터 시트 생성에도 동일하게 적용.**

- 캐릭터 시트 생성 프롬프트에서 **캐릭터 description(성격·설명 등 긴 텍스트)을 이미지에 그리라는 지시 제거.**
- "DO NOT render any text, letters, words, labels, or descriptions in the image. Pure character illustration only" 같은 텍스트 금지 지시 추가(게이트5와 동일 방식).
- 캐릭터 시트는 **순수 캐릭터 그림**만 나오게(정면/표정). 설명 텍스트가 그림에 박히지 않도록.

> 참고: 캐릭터 이름 라벨(예: "김준호")이나 표정 구분이 시트에 필요하면, 그건 이미지 생성이 아니라 **UI에서 코드로 표시**(게이트5 라벨 한글화와 동일 원리). 이미지 안에 텍스트를 그리지 않음.

---

## 수정 3. (연관 확인) 조건이 시트 생성에 반영되는지

수정 1(버튼 노출)이 되면 조건 편집이 가능해지므로, 조건이 실제 생성에 반영되는지도 확인:

- 조건 편집에서 입력한 값(성별·나이대·헤어·체형·분위기 + 자유서술)이 **캐릭터 시트 생성 프롬프트에 반영**되는지.
- 예: 자유서술에 "은테 안경" 입력 → 재생성 시 안경 낀 캐릭터가 나오는지.
- 조건을 바꿔 재생성하면 결과가 달라지는지.

---

## 검증

1. 게이트3 캐릭터 카드에 [조건 편집] 버튼이 바로 보이는지.
2. 캐릭터 시트(정면/smile/angry)에 깨진 텍스트가 안 나오는지 → 순수 그림만.
3. 조건 편집에서 특징(안경 등) 입력 후 재생성 → 그 특징이 반영되는지.
4. 조건 바꿔 재생성 → 결과가 달라지는지.
