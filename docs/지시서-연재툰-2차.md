## 목표 (도도가 화면에서 보게 되는 것)
- **프로젝트 목록 → [새 프로젝트]**에 종류 선택: **이야기 / 광고(한 컷·
  인스타툰) / 브랜드 연재툰(시리즈)**. 연재툰 선택 → 시리즈 이름(예:
  "자연바람 헤어팩 연재툰") + 컷 수 6·8·10(기본 6) + 비율 9:16(기본)·
  1:1·4:5 → [시작] → 1화가 만들어지고 바로 1화 브리프로
- 시리즈 프로젝트 카드: **"연재" 배지 · 이름 · "3화까지 · 최근 2화 대본"**
- 시리즈 안 에피소드 목록: **"1화 · 완성", "2화 · 대본"**(제목은 "N화"
  기본, 부제 편집 가능 "1화 · 겨울 건조 편"), 맨 위 **[새 화 만들기]**
  버튼(시리즈에서만)
- [새 화 만들기] → 바로 N화 브리프: 직전 화의 제품·특징·사용법·웹 보완·
  광고 목적·전달 내용·분위기·보여줄 특징 체크·제품 사진/분석·비율·컷 수
  가 **그대로**, "이번 화 소재"만 비어 있음. 안내 **"1화 설정을
  가져왔어요 · 이번 화 소재만 적어주세요"**(직전 화 번호). [시리즈
  기본값으로 저장] 버튼 **제거**. 고치면 그 화부터 다음 화들에 반영
- 준비: 모델 [저장된 캐릭터에서 고르기]·[새로 만들기]·[+ 모델 추가]
  그대로. 직전 화 모델이 있으면 **"지난 화 모델 그대로 쓰기"** 칩 하나
  (탭하면 link, 0패킷)
- 섞인 프로젝트의 용도 모달에서 **"브랜드 연재툰" 카드 제거**(한 컷·
  인스타툰·이야기만). 랜딩·입구 카드의 연재툰은 "새 프로젝트 → 연재툰"
  으로 연결

## 1단계 — DB + 백엔드
- **step36.sql**: `projects.kind ENUM('story','ad','series') NOT NULL
  DEFAULT 'story'` + 기존 프로젝트는 story(광고 에피소드가 있어도 섞인
  프로젝트는 그대로 두고 kind='story' 또는 'ad' 자동 판별: 광고 purpose
  에피소드만 있으면 'ad'). 리허설·백업·"실행해"
- **POST /projects** 확장: kind, series 옵션(cut_count 6/8/10, ratio)
  → kind='series'면 1화 에피소드 자동 생성(purpose brand_series, title
  "1화", episode_no 1, target_cuts, ratio)
- **POST /projects/{id}/episodes/next**(시리즈만): episode_no = 시리즈
  내 max+1, title "{n}화", gate_status = create_initial_gate_status(brand_
  series) + **직전 화** idea_brief(소재·카피 선택 제외) + visual_points_
  selected + target_cuts + ratio 복사, products 행+파일 복사(1단계 로직
  재사용, **직전 brand_series 화 기준**), `prefilled_from: episode {n-1}`
- 기존 "새 에피소드 생성 시 brand_series 프리필" 로직은 **시리즈
  프로젝트에서만** 동작(섞인 프로젝트에선 복사 없음 → 39화·제품 따라옴
  해결). series_defaults 자동 저장·POST series-defaults는 호출 중단
  (코드는 남겨도 됨)
- 에피소드 목록 API: 시리즈면 episode_no·subtitle·단계 이름. 프로젝트
  목록 API: kind·화 수·최근 화 단계
- 직전 화 모델 link 재사용: POST .../characters/link-previous(0패킷)
- 용도 모달 purpose 목록에서 brand_series 제외(kind != series)

## 2단계 — 프론트
- ProjectsPage(프로젝트 목록): [새 프로젝트] 모달에 종류 3택(이야기 /
  광고 / 브랜드 연재툰), 연재툰이면 시리즈 이름·컷 수·비율 → 생성 후
  1화 브리프로 이동. 카드 "연재" 배지 + "N화까지 · 최근 상태"
- ProjectPage(시리즈): 헤더 [새 화 만들기], 카드 "N화 · 단계"(부제
  있으면 "N화 · 부제"), 용도 모달 없음. 섞인 프로젝트: 용도 모달에서
  연재툰 카드 제거
- AdBriefForm(brand_series): 안내 "{n-1}화 설정을 가져왔어요 · 이번 화
  소재만 적어주세요", [시리즈 기본값으로 저장] 제거, 1화는 안내 없음.
  **컷 수 칩 6·8·10 + [직접 입력]을 브리프 상단(소재 칸 아래)에** —
  직접 입력은 숫자 칸 **4~20**, 안내 "10컷 넘게 하려면 직접 입력 · 컷
  수만큼 패킷이 들어가요", 12 이상이면 "대본이 길어져요 — 훅·문제·해결·
  CTA 구조는 유지돼요". 기본값은 직전 화(1화는 시리즈 생성 시 값).
  [이대로 진행] 시 target_cuts로 저장되어 대본이 그 컷 수로 생성됨(연재
  addon은 임의 N 지원 — 구조 자리를 N에 비례 배분). 대본 단계 칩은
  "다시 만들기"용으로만 유지. 콘티·완성·"N컷 전부 생성"은 N 동적.
  [근거] 도도 — 컷 수는 대본 전에 정해져야 분량이 맞음. 6·8·10 외에
  더 많이 원할 수 있으니 직접 입력
- Gate3Assets(brand_series): 직전 화 모델 있으면 "지난 화 모델 그대로
  쓰기" 칩
- 에피소드 제목 편집: "N화" 고정 + 부제 입력
- 랜딩·입구 카드 연재툰 링크 → 새 프로젝트(연재툰) 모달
