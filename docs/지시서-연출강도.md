# 지시서 — 연출 강도 (감정·행동 기반 만화 효과를 모델이 직접 그리기)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> 없는 것 확인. **마이그레이션 없음**(gate_status JSON·cut spec JSON).
> 근거: docs/조사-연출강도.md, scratch/effects/out/{A,B,C}.png
> [근거] 도도 관찰 — 나노바나나로 만든 타인 웹툰이 표정·효과(땀·먼지·
> 집중선·과장 포즈)가 풍부. 실험 결과 B(보통)·C(과장) 모두 쓸모 있고,
> 모델이 그린 효과가 기존 PNG 효과 레이어보다 자연스러움.
> [근거] 도도 결정 — 3단계 담백/보통/과장, 기본 **보통**, 광고형(is_ad)
> 기본 **담백**, 컷별 덮어쓰기 O, 실사·흑백도 동일 적용. 효과음 글자는
> 모델이 그리지 않음(기존 효과음 PNG 유지).
> [근거] 조사 — build_cut_prompt()에 감정 "Currently {emotion}
> expression"·행동 "Scene: {action}" 원문 삽입, 효과 문구 인자 없음 →
> extra_prompt 추가. 감정은 AI 자유 생성이라 종류 분산 큼(happy 34·
> neutral 22·curious 21…). 옵션은 episodes.gate_status JSON(aspect_ratio·
> page_format·is_ad). POST /cuts/{id}/regenerate mode+params 지원.
> 실사 분기 prompts/service.py 4곳, 흑백은 style_prompt 문자열.
> [근거] 실험 — C는 배경 집중선이 정보를 먹음 → 과장 단계에 보호 문구.

## 목표 (도도가 화면에서 보게 되는 것)
- 에피소드 생성 옵션(비율·형식 고르는 자리)에 **"연출 강도" 담백 /
  보통 / 과장** 3단 선택. 기본 보통, 광고형이면 기본 담백. 설명 한 줄:
  "담백: 효과 없이 깔끔 · 보통: 감정에 맞는 효과 2~3개 · 과장: 집중선·
  과장 포즈까지"
- 게이트5 컷 카드의 **재생성 메뉴에 강도 선택**(이 컷만 담백/보통/과장).
  덮어쓴 컷은 카드에 작은 배지("과장"). 8컷 일괄 생성은 에피소드 기본값
- 효과는 컷의 감정·행동에서 **자동 선택** — 사용자가 고를 건 강도뿐
- 콘티·대본·말풍선엔 영향 없음. 효과음 글자 없음. 실사 인물은 실사
  유지한 채 주변에 2D 효과, 흑백은 흑백 효과(스크린톤·선)

## 1단계 — 백엔드 (효과 매핑 + 프롬프트 + API)
- 새 모듈 `app/prompts/drama.py`
  - `resolve_level(episode, cut)`: cut.spec.drama_level → 없으면
    episode.gate_status.drama_level → 없으면 is_ad ? "light" : "normal".
    값 `light | normal | strong`
  - `normalize_emotion(emotion_str, action_str) → category`: 키워드
    매핑(소문자 포함 검색). joy(happy·joy·excited·delighted·cheerful·
    love·affection) / sad(sad·crying·tears·lonely·grief) / anger(angry·
    furious·annoyed·irritated) / shock(surprised·shocked·astonished·
    startled) / flustered(nervous·embarrassed·anxious·worried·panicked·
    confused·awkward) / fear(scared·afraid·terrified) / tired(tired·
    exhausted·sleepy·bored) / calm(neutral·calm·curious·thoughtful·
    serious·기타). action 키워드 보조: fall·trip·slip → +motion_fall,
    run·chase·jump → +motion_fast, hit·bump·crash → +impact. 매핑 표는
    모듈 상단 dict로(나중에 도도가 손볼 수 있게)
  - `build_drama_prompt(level, category, motions, is_photo_real,
    is_bw) → str`:
    - light: "" (효과 없음 — 현재와 동일). 단 표정은 category 반영해
      "clear {category} expression" 한 줄만
    - normal: category별 효과 2~3개. 예) joy: sparkles around character,
      small hearts or stars, bright eyes / sad: tear drops, downcast
      shading, drooping lines / anger: anger vein mark, sharp short
      emphasis lines, gritted teeth / shock: vertical shock lines,
      wide eyes, small sweat drop / flustered: sweat drops, wobble
      lines, blush / fear: trembling lines, pale shading / tired:
      drooping posture, small spiral, sigh puff / calm: 없음(표정만).
      motion_fall: dust puff, dizzy spiral + stars / motion_fast: speed
      lines behind, motion blur on limbs / impact: impact burst lines.
      공통 꼬리: "effects drawn in the same line style as the
      illustration, modest size, must not cover faces or speech
      bubble space"
    - strong: normal + 과장 — "exaggerated pose and expression",
      category에 맞춰 focus lines(집중선)·dramatic spotlight·larger
      effects·more sweat/tears/hearts, motion은 더 크게. **보호 문구
      필수**: "focus lines only in the outer 30% of the frame,
      background and faces stay legible, no text or onomatopoeia".
      **일관성 강화**: "character design, face, hair, outfit identical
      to reference sheet despite exaggeration"
    - is_photo_real: 앞에 "effects are 2D webtoon overlays drawn
      around the real person; the person stays photoreal" 추가
    - is_bw: "effects in monochrome ink and screentone" 추가
  - 금지 공통: "no written sound effects, no letters" (모든 단계)
- `build_cut_prompt(..., extra_prompt="")`: 기존 감정·행동 줄 **뒤**에
  extra_prompt 삽입(스타일·실사 문장 순서는 유지). 호출부(8컷 일괄·
  컷 재생성·실사 GPT 경로) 전부에서 resolve_level → build_drama_prompt
  → extra_prompt 전달. GPT 실사 경로도 동일 문구 전달
- POST /cuts/{id}/regenerate: params.drama_level(light|normal|strong)
  받으면 cut.spec.drama_level에 **저장**(이후 재생성에도 유지) 후 생성.
  params 없으면 기존 resolve 그대로
- 에피소드 옵션 저장: gate_status.drama_level — 기존 aspect_ratio·
  page_format 저장 경로와 동일 엔드포인트. 광고형 토글 시 drama_level이
  아직 없으면 light로 세팅(이미 있으면 유지)
- generation_logs(있으면) 또는 prompt 로그에 level·category 기록
  (디버그용)
- Claude Code 자체 확인: "캐릭터 테스트" 컷 3개(감정 다른 것) × 3단계로
  **프롬프트 텍스트만** 생성해서 docs/조사-연출강도.md 하단에 붙이기
  (이미지 생성 X, 패킷 0) → 도도가 문구 확인
