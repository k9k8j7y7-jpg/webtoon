## ① 하단 검은 띠 자막 — 데이터 원천 + 렌더 위치

### 데이터 원천

- DB 컬럼: `cuts.spec` (JSON)
- 핵심 키: `spec.dialogue[]` 배열 안 **`type: "narration"`** 항목
- 예시:
  ```json
  {
    "dialogue": [
      { "order": 1, "type": "narration", "speaker": null, "text": "어느 평범한 오후였다." },
      { "order": 2, "type": "speech", "speaker": "husband", "text": "뭐 먹을까?" }
    ]
  }
  ```
- `action` 필드는 이미지 생성 프롬프트용 지문(화면 표시 X)
- `narration`은 콘티 생성 시 AI가 배분 → dialogue 배열에 type으로 구분

## ② 말풍선 저장 구조

### 컷별 JSON 키

`cuts.spec.dialogue` — 배열, 항목별 필드:

| 필드 | 타입 | 설명 |
|---|---|---|
| `order` | int | 렌더 순서 |
| `type` | string | **`speech`** / **`narration`** / **`thought`** (+ `sfx` 레거시) |
| `speaker` | string\|null | 캐릭터 ref_key, narration은 null |
| `text` | string | 표시 텍스트 |
| `bubble_style` | string\|null | 수동 스타일 오버라이드 |
| `bubble_layout` | object\|null | 사용자 배치 좌표(없으면 자동 배치) |

**`bubble_layout` 서브 필드:**

| 필드 | 타입 | 설명 |
|---|---|---|
| `x`, `y` | float 0–1 | 좌상단 상대 좌표 |
| `width` | float 0–1 | 폭 비율 |
| `tail_direction` | string | up/down/left/right/none |
| `tail_flip` | bool | 꼬리 좌우 반전 |
| `font_scale` | float | 글자 크기 배율 (기본 1.0) |
| `min_height` | float 0–1 | 최소 높이 비율 |
| `font` | string | 폰트 ID (pretendard 등) |
| `text_offset_x`, `text_offset_y` | float | 텍스트 위치 미세 조정 |

**`bubble_style` 가능값 (12종):**
`round`(기본) · `narration` · `thought` · `whisper` · `shout` · `angry` · `happy` · `sad` · `surprised` · `shy` · `flustered` · `realize`

**스타일 결정 순서** (`bubbleMapping.js`):
1. `bubble_style` 명시 → 그대로
2. `type=narration` → narration
3. `type=thought` → thought
4. `type=speech` + 감정 매핑 → emotion 기반
5. 폴백 → round

## ③ 말풍선 렌더 코드 공유 여부

**프론트 4곳은 `BubbleOverlay.jsx` 공유:**
- Gate5Review, CutEditor(view), ViewerPage → `<BubbleOverlay>` (foreignObject)
- CutEditor(edit) → `<SingleBubble>` (BubbleOverlay에서 export)
- exportRenderer → `<BubbleOverlay renderMode="svg-text">` (SVG text/tspan)

**백엔드(Pillow)는 별도 구현:** `composition/service.py` — PIL ImageDraw로 사각형+텍스트 직접 렌더. 프론트와 로직은 대응하지만 코드 공유 없음. `RENDERER_VERSION` 올려야 하는 이유.
