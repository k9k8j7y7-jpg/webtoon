# 지시서 — 재포지셔닝 1차 (가격 페이지 + 랜딩 메시지)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> (이미지·motion·reel job) 없는 것 확인. **DB 마이그레이션 없음**(팩 정의가
> DB면 행 추가만, 코드 상수면 상수). 패킷 0(랜딩 릴스 예시 1패킷만 도도
> 확인 후).
> [근거] 도도 — 시장 조사 결론: "AI 웹툰 플랫폼" 포지션은 독자(AI 거부)와
> 작가(AI 거부) 양쪽에 안 팔림. 돈 낼 사람은 소상공인·브랜드(광고툰)와
> 감정형 소비자(반려동물·가족). 결과물이 소비되는 곳은 ssagda.com이
> 아니라 인스타·릴스.
> [근거] 꿈잉(만화제면소) 가격 조사 — 1장 160~260원, 고품질 400~650원.
> EziToon 230/199/183원으로 **가격 차별화 없음**. 대신 꿈잉은 "한 편 연재
> 분량 = 125장 = 24,900원"이라 써놓음 → EziToon은 글 작업 0패킷이라 8컷
> 한 편 = 8패킷 ≈ 1,600원. **"한 편에 얼마"로 싸운다.**
> [근거] 꿈잉 UX에서 가져올 것 — 팩마다 "약 N장", 1회 결제·유효기간
> 없음·자동결제 없음 3줄, 3,900원 맛보기 팩(첫 결제 허들), 환불 규정
> 명시(7일 내 미사용분, 사용분 공제).
> [근거] 현재 가격 페이지 — 베이직/프로/프리미엄 이름이 월 구독처럼
> 읽힘, 1회 결제 표시 없음, 약 N컷 없음, 맛보기 없음, 환불 문구 없음.
> [근거] 경쟁 툴 10종 비교표에서 영상·모션 0개, 인스타 내보내기 0개 →
> 모션·릴스·인스타 공유가 EziToon의 보이는 차별점. 랜딩에 **먼저** 보여야.

## 목표 (도도가 화면에서 보게 되는 것)
- **가격 페이지**: 팩 4개 — 맛보기 3,900원/15패킷 · 시작 6,900원/30 ·
  꾸준히(인기) 19,900원/100 · 넉넉히 54,900원/300. 각 카드에 "약 N컷 ·
  8컷 에피소드 약 N편". 카드 위에 한 줄 "**1회 결제 · 유효기간 없음 ·
  자동결제 없음**". 아래 "패킷은 어디에 쓰나요" 표(이미지 1 · 재생성 1 ·
  컷 영상 4 · 릴스 1 · 기획·대본·콘티·말풍선 0 · 실패 시 차감 없음).
  환불 한 줄 + FAQ 항목
- **랜딩**: 첫 화면이 "웹툰 플랫폼"이 아니라 **"만들어서 인스타·릴스에
  올리는 도구"**로 읽힘. 헤드라인 + 한 줄 "기획·대본·콘티는 무료, 그림
  1장 = 1패킷 — **8컷 한 편이 패킷 8개**". 바로 아래 **결과물 3종**(광고툰
  4컷 캐러셀 · 릴스 영상 자동재생 · 반려동물 일상툰) → 3단계 흐름(이야기
  입력 → 그림·말풍선 → 인스타/릴스) → 용도 탭(가게·제품 홍보 / 반려동물·
  가족 / 이야기 연재) → 비용 비교 한 블록 → 갤러리 → FAQ → CTA
- 폰 375에서 첫 화면에 헤드라인·한 줄·CTA·결과물 첫 장이 한 번에 보임
