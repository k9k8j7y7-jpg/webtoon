## 1단계 — 백엔드
- idea_brief에 `onecut_device: {device, labels[], compare?} | null`
  (PUT /idea-brief/selection 확장). ad_brief(onecut)에 visual_points
  **1개** 제안(mechanism·elements 포함) — 기존 프롬프트 재사용, 한 컷은
  max 1
- 콘티(onecut 1컷) spec에 kind=explain·device·labels 전달 **device가
  있을 때만**; 없으면 기존 spec 그대로
- 이미지(images/service.py onecut 경로): device 있으면 build_copy_clause
  + build_explain_clause(device, labels, mechanism, elements, palette) 둘
  다, 글자 허용 문구 = "Render ONLY the headline '…', the subline '…'
  and these labels, spelled exactly: … No other text"(generate.py 문구
  그대로). 캐릭터 포즈 힌트 "guide gesture toward the panel"(generate.py
  지문 참조). device 없으면 기존 문구
- prompts/explain.py: `steps`·`process` 라벨 **최대 4**로 확장(현재 3
  제한). 인스타툰·연재툰도 4 허용(기획안 제안은 3 기본)
- 글자 검사: head·sub + labels 각각(0패킷, 자동 재시도 1회), copy-report
  도 라벨 포함. 손 검사 동일
- 재생성: user_note·device 변경 지원(PUT /cuts/{id}/device onecut 허용)
