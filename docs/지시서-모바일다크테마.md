## 목표 (도도가 화면에서 보게 되는 것)
- 폰(640px 미만)으로 열면 앱 안(프로젝트·에피소드 목록, 게이트 화면)이
  랜딩과 같은 딥 네이비 다크 톤. 헤더에 ☀/🌙 토글이 있고 누르면 라이트로,
  다시 누르면 다크로. 선택은 기억됨(localStorage)
- PC(640px 이상)는 지금처럼 라이트. 토글도 헤더에 있으니 PC에서 다크로
  바꿔볼 수는 있음(품질은 2차에서 보정 — 이번엔 "깨지지만 않으면 OK")
- 카드는 유리 느낌(반투명+블러+얇은 테두리), 주요 버튼·현재 게이트에
  보라→시안 그라데이션 포인트. 랜딩·뷰어는 지금 그대로(이미 다크)

## 0단계 — 기반 (토큰·스위치)
- tailwind.config.js: `darkMode: 'class'`. 색 토큰 추가(랜딩 값과 맞춤):
  `night: {bg:'#0A0F1D', card:'#111827'/…, border:'rgba(255,255,255,.10)'}`,
  `neon: {from:'#a855f7'(purple-500), to:'#22d3ee'(cyan-400)}`. 정확한
  값은 LandingPage.jsx에서 쓰는 것을 그대로 복사(조사 2번 결과)
- 공용 유틸 클래스(index.css @layer components):
  `.glass-card`(dark: bg-white/5 backdrop-blur border-white/10 rounded-2xl,
  light: 기존 흰 카드 스타일), `.neon-btn`(bg-gradient-to-r from-neon-from
  to-neon-to text-white), `.neon-ring`(현재 단계 강조용 ring)
- ThemeProvider(또는 useTheme 훅) 신규: 초기값 = localStorage 'theme'
  있으면 그 값, 없으면 `window.innerWidth < 640 ? 'dark' : 'light'`.
  `<html>`에 `dark` 클래스 토글. 폭이 바뀌어도(회전) 사용자가 정한 값
  우선, 정한 적 없으면 폭 기준 재판정
- 헤더(Layout)에 토글 버튼(Sun/Moon 아이콘, lucide). 모바일·PC 둘 다 표시
- **기존 `@media (prefers-color-scheme)` 의존은 제거** — class 방식으로
  일원화(조사에서 media만 동작 중이라고 했으므로 충돌 확인)
- 배포 → 보고 → 도도 확인: 폰 모드에서 열면 다크, 토글 두 번 왕복,
  F5 후 유지, PC는 라이트 유지. **여기서 "이미 있는 dark: 클래스"만으로
  어떻게 보이는지 스크린샷** → 1단계 범위 조정

## 1단계 — 에피소드 목록 + 헤더 (ProjectPage·Layout)
- 헤더: 다크에서 bg-night-bg/80 backdrop-blur, 로고 그라데이션 텍스트
  (랜딩과 동일), 패킷 뱃지·알림·프로필 아이콘 대비 확인
- 프로젝트/에피소드 카드: `.glass-card`. 제목·부제 대비(text-white /
  text-gray-400), 게이트 상태 배지는 현행 색 유지하되 다크 배경에서
  읽히는지(필요 시 채도 조정), 공개 배지·좋아요 수 등 현행 정보 그대로
- "새 에피소드" 버튼: `.neon-btn`. 모달(제목·이야기 입력)도 다크 대응
- 빈 상태·로딩 스켈레톤 다크 대응
- 배포 → 도도 확인(폰 모드 목록 화면 스크린샷 + 토글 왕복) → **커밋**

## 2단계 — 게이트 프레임 (WorkflowPage·GateProgress·읽기 전용 배너)
- 스텝바: 완료 = 초록 유지, 현재 = `.neon-ring` + 그라데이션 배경, 잠김
  = 회색 낮은 대비(조사에서 "잠긴 탭 잘 안 보임" 지적 — 다크에서
  text-gray-500 이상으로)
- 게이트 카드 컨테이너 `.glass-card`
- **읽기 전용 배너**: 375px에서 "수정하기 / 현재 단계로 돌아가기" 버튼이
  3줄로 깨짐(1차 때 발견) → 모바일에서 배너를 2줄 스택(문구 1줄, 버튼
  2개 grid-cols-2)으로, 다크 색 대응
- 게이트1~4 내부 폼·textarea·드롭다운·[저장] 버튼 다크 대응(이미 dark:
  있는 것은 확인만). 게이트3 스타일 카드(썸네일)는 테두리·선택 링만
- 배포 → 도도 확인("장소 테스트2" 게이트1→4 훑기) → 커밋
