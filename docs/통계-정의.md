# 관리자 통계 — 숫자 정의

> `/admin/stats` 4탭(돈·사람·품질·상태)의 각 숫자 정의, SQL 요지, 실측/추정 구분, 체크 임계값.

## 돈 탭

| 숫자 | 정의 | SQL 요지 | 출처 |
|------|------|---------|------|
| 매출 | 기간 내 `orders.status='paid'` 합계 | `SUM(amount) WHERE paid_at BETWEEN` | 실측 |
| 사용 패킷 | `packet_transactions.reason='generation'` 절대값 합 | `SUM(ABS(delta))` | 실측 |
| API 원가 (실측) | `api_calls.cost_krw` 합 (기록 시작 2026-11-19 이후) | `SUM(cost_krw) WHERE created_at >=` | 실측 |
| API 원가 (추정) | `generation_logs` × `_LEGACY_COST` 단가표 (기록 이전) | kind·model_tier별 건수 × 단건 추정 USD → 환율 | 추정 |
| 패킷당 원가 | (실측+추정 원가) / 사용 패킷 | — | 혼합 |
| 마진율 | `(1 − 패킷당 원가 / 평균 판매 단가) × 100` | 매출 0이면 인기 팩 ₩299 기준 | 혼합 |
| 패킷 부채 | `SUM(packet_balances.balance) × 평균 판매 단가` | — | 실측 |

### 실측/추정 구분
- **실측**: `api_calls` 테이블 기록 (2026-11-19~). 어댑터에서 호출마다 자동 INSERT.
- **추정**: `generation_logs` 1행당 고정 단가 적용. `_LEGACY_COST` (recorder.py):
  - cut/gpt $0.068, cut/flash $0.034, character $0.072, location $0.037, product $0.001
- **혼합**: 기간이 기록 시작일을 걸칠 때. "실측만" 토글로 기록 이후만 볼 수 있음.
