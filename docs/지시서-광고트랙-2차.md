# 지시서 — 광고 트랙 2차 (한 컷 20~24 + 인스타툰 25~32)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 확인 후. 배포 전 생성 작업
> 없는 것 확인. **DB 마이그레이션 없음**(gate_status·idea_brief JSON).
> 테스트는 테스트 계정 또는 도도툰 "테스트" 프로젝트 새 에피소드.
> 근거: docs/흐름-용도별.md, docs/flow-instatoon-ad.png(10-29), 도도 폰
> 테스트 "두피오일 3차"(ep, 한 컷 완주), Claude Code 흐름도 지적 7건
> [근거] 도도 — 한 컷: 재생성 때 "수건 없애줘" 같은 요청을 말로 넣고 싶다
> / 카피 디자인 칩 작아 안 보임 / 한 컷에서 형식·비율·장소는 못 바꾸니
> 보여줄 필요 없음 / 크기 칩(손바닥·한 손…) 뜻이 안 보임. 인스타툰:
> STEP 0 레이아웃은 STEP 3 형식과 중복 / 브리프에 **제품 특징·활용법**
> 칸 + 웹 검색 보완(Gemini 채팅에서 하던 상세페이지 대본 흐름을 안에) /
> 컷 수 정하는 곳이 없음.
> [근거] 흐름도 — 대본 7컷 생성 → 콘티가 4컷으로 조용히 자름(target_cuts
> 미강제, **버그**) / 장소 코드명 노출 / 완성 헤더 "STEP 5/5" 없음·부제
> "웹툰 만들기" / 시트 버튼 순서.
> [근거] 도도 결정 — STEP 4 콘티·장소는 **자동으로 넘기고 완성에서 고침**
> (한 컷과 동일, 단 [N컷 생성]은 자동 시작 X) / 대본 편집은 **대사만** +
> [다시 만들기]·톤 칩 / 컷 수 4·6·8 STEP 0에서 선택 / 광고 대본 구조 =
> 훅→문제→해결(제품)→포인트→사용법→CTA 를 컷 수별 고정.

## 목표 (도도가 화면에서 보게 되는 것)
**한 컷 광고**
- 재생성 ▾ 에 **"이렇게 고쳐서 다시"** 입력칸: "머리에 쓴 수건 빼줘"
  → [다시 그리기 · 1패킷] → 그 요청이 반영된 새 컷. (모든 트랙 컷 공통)
- 대본 카드의 카피 디자인 칩·라벨이 한 단계 커서 폰에서 바로 읽힘
- 보기 모드(승인 후 브리프 화면)가 로그라인·시놉시스 대신 **브리프 요약**
  (목적 · 전달 내용 · 분위기 · 선택 카피 · 장면 · 모델)
- 준비 단계에 **형식·컷 비율·장소 카드가 안 보임**(스타일·제품·캐릭터·
  참고 광고만). 완성 화면 위에 "장소: 욕실 [바꾸기]" 한 줄
- 제품 크기 칩이 뜻이 보이게: "손바닥 크기 · 한 손에 쥐는 · 두 손으로
  드는 · 탁자 위에 놓는 · 사람만 한"

**인스타툰 광고**
- STEP 0 제목 모달: 레이아웃 대신 **"몇 컷으로 만들까요? 4컷 · 6컷 ·
  8컷"**(기본 4). 형식·비율은 STEP 3에서(4컷 → 2×2 추천, 6·8컷 → 세로
  추천, 변경 가능)
- STEP 1 브리프: "어떤 내용을 전달하고 싶나요?" 아래 **제품명**(기존
  제품 선택 또는 입력) + **제품 특징·활용법**(텍스트박스, 상세페이지
  문구 붙여넣기 OK) + **[웹에서 보완]** → 검색해서 특징·성분·활용법
  요약을 보여주고 [반영] → 기획안·대본에 들어감
- STEP 2 대본: **선택한 컷 수 그대로**(4컷 = 훅·문제·해결·CTA / 6컷 =
  +포인트·사용법 / 8컷 = 포인트 2·사용법 2). 컷 카드는 지문 읽기 + **대사
  만 편집**. 상단 [다시 만들기] + 톤 칩(더 짧게·임팩트·감성·유머·신뢰)
  + 안내 "AI가 만든 대본이에요 — 마음에 안 들면 다시 만들어 보세요"
- STEP 3 준비 승인 → **콘티·장소 자동**(사용자 화면 없음) → STEP 4 완성
  으로. 헤더 **4단계: 브리프 → 대본 → 준비 → 완성**
- 완성: 컷 카드 N개가 생성 전 상태로 보이고 위에 "장소: 미용실 [바꾸기]"
  → 사용자가 [N컷 생성 · N패킷] 누름(자동 시작 X). 카드 [콘티]로 샷·
  제품 토글 조정은 지금처럼
- 헤더 "STEP 4/4 완성", 에피소드 목록 부제 "STEP 4 완성"(광고 purpose는
  "웹툰 만들기" 문구 없음)

## 1단계 — 백엔드
- **(24) 재생성 요청 문구**: POST /cuts/{id}/regenerate params에
  `user_note`(최대 200자) → build_cut_prompt 끝에 "Additional instruction
  from the user: {note}" 삽입. 금지어 필터 없음, generation_logs에 기록.
  한 컷 카피 렌더 컷도 동일(카피 절 유지)
- **(26) 컷 수 강제**: instatoon_ad target_cuts ∈ {4,6,8}(STEP 0에서
  저장). AD_SCRIPT_INSTRUCTION_ADDON을 컷 수별 구조로 — 4: [훅, 문제,
  해결(제품 등장), CTA] / 6: [훅, 문제, 해결, 포인트, 사용법, CTA] / 8:
  [훅, 문제, 해결, 포인트1, 포인트2, 사용법1, 사용법2, CTA]. 대본 컷 수
  ≠ target_cuts면 **서버에서 1회 재생성**, 그래도 다르면 자르지 말고
  422 "대본 컷 수가 맞지 않아요 — 다시 만들어 주세요". 콘티는 대본 컷
  수 그대로(잘라내기 금지). brand_series는 현행(자유)
- **(27) 제품 정보 + 웹 보완**: idea_brief에 `product_name`,
  `product_info`(사용자 입력), `product_info_web`(보완 결과, 사용자
  [반영] 후). POST /episodes/{id}/ad-brief/enrich-product {name, info}
  → Gemini 검색 그라운딩(0패킷)으로 특징·핵심 성분·활용법·주의 요약
  (각 2~3줄, 출처 URL 2~3개) 반환 — 저장은 프론트 [반영] 시. 기획안
  프롬프트(ad_brief.py)와 대본 프롬프트에 product_info(+web) 주입. 기존
  products 행이 있으면 name·label_text·description도 함께. 검색 실패 시
  "지금은 보완하지 못했어요 — 입력한 내용으로 진행해요"
- **(31) 인스타툰 콘티 자동**: approve_assets에서 instatoon_ad(+brand_
  series)도 onecut처럼 콘티 자동 생성 + gate4 자동 승인 → gate 5. 장소는
  AI 제안 1개 자동 채택(바꾸기 API는 기존). Gate5 마운트 시 cuts 0이면
  자동 콘티(빈 화면 방지). **이미지 생성 자동 시작 금지**
- **(32) 대본 대사만 편집**: PUT /script 컷 단위 — 광고 purpose면
  dialogue만 갱신(action·shot은 무시 또는 별도 플래그). POST /script
  재생성에 `tone`(5종, COPY_DIRECTION_PROMPTS 재사용) 파라미터
- **(29) 부제·헤더**: 광고 purpose 단계 이름 상수 — instatoon_ad·brand_
  series: 브리프·대본·준비·완성(4단계, 게이트 1→1, 2→2, 3→3, 4·5→4).
  에피소드 목록 gateLabel 동일 상수 사용
- **(28) 장소 코드명**: 대본 응답의 location ref_key → 한글 이름 매핑
  (대본 생성 시 장소 이름을 함께 생성해 `location_name` 저장, 프론트는
  이름만 표시)
- (21) 광고 purpose 보기 모드용 GET: 기존 idea_brief로 충분(프론트 작업)

## ⚠️ 한 컷 광고 보호 (도도 명시)
인스타툰 작업이 **한 컷 광고(onecut_ad)의 완성된 흐름을 바꾸거나 깨면
안 됨**. 공통 코드(approve_assets·Gate5Review·StepHeader·WorkflowPage·
대본 프롬프트·RegenDropdown)를 건드릴 때 purpose 분기로 격리하고, 아래
회귀를 **매 단계 보고 때마다** 통과시킬 것:
- onecut_ad 3단계 헤더(브리프·준비·완성) 그대로
- 브리프 → 기획안 → 대본 카드(카피 디자인) → 준비 승인 → 콘티 1컷 자동
  → 완성 컷 카드 → [생성 · 1패킷] → 카피 그림 안 렌더(GPT) → 글자 검사 →
  [글자가 틀렸나요?] 동작 그대로
- 한 컷 대본은 ONECUT_AD_SYSTEM_INSTRUCTION 경로 유지(인스타툰 컷 수
  구조 addon이 섞이면 안 됨)
- "두피오일 3차"(도도툰, 완성본)를 열어 화면·버튼 변화 없음 확인
