## 목표 (도도가 화면에서 보게 되는 것)
- **모바일**: 헤더 왼쪽 ☰ → 왼쪽에서 슬라이드 드로어. 그룹: 홈 /
  만들기(내 작품) / 둘러보기(갤러리) / 계정(패킷 충전 — 잔량 표시,
  알림) / 도움말(FAQ, **문의하기**, 이용약관, 개인정보) / 하단(테마
  토글, 로그아웃). 헤더엔 로고·패킷·🔔·프로필만
- **PC**: 헤더 ? 아이콘 클릭 → 드롭다운(FAQ / 문의하기 / 내 문의 내역)
- **문의 작성**(/inquiries/new, 로그인 필요): 카테고리 선택(버그·오류 /
  사용법 / 결제·패킷 / 기능 제안 / 기타), 제목, 내용, 스크린샷 최대
  3장, 관련 에피소드(선택, 내 에피소드 드롭다운 — 제목으로). 등록 시
  브라우저·기기·화면 폭 자동 첨부(사용자에게 "문제 해결을 위해 기기
  정보가 함께 전송돼요" 한 줄)
- **내 문의**(/inquiries): 기간(최근 1주/1달/3달/전체)·카테고리·상태
  필터, 목록(날짜·카테고리·제목·상태 배지), 클릭 → 대화형 상세(내 글 /
  관리자 답변 / 추가 댓글 입력). 상태 "답변 완료"면 👍👎 한 번
- **관리자** /admin 문의 탭: 기간·카테고리·상태 필터, 미답변 건수
  상단 표시, 상세에서 답변 작성 + 상태 변경(접수 → 확인 중 → 답변 완료
  → 종료), 자동 수집 정보·관련 에피소드 링크(게이트5로 바로)
- FAQ 페이지 하단: "원하는 답이 없나요? → 문의하기"

## 1단계 — 백엔드
- `inquiries/` 모듈: POST /inquiries(FormData multipart — 첨부는 기존
  storage.py·image_util.py로 inquiries/{id}/attachments/), GET
  /inquiries(본인, 기간·카테고리·상태 쿼리), GET /inquiries/{id}
  (본인 또는 관리자), POST /inquiries/{id}/messages(본인 댓글 / 관리자
  답변 → is_admin, 관리자 답변 시 status 'answered'·answered_at),
  POST /inquiries/{id}/status(관리자, Apache PATCH 불가 → POST), POST
  /inquiries/{id}/satisfaction(본인, 1회)
- 관리자: GET /admin/inquiries(필터 + 미답변 count), 권한은 기존 admin
  가드 재사용
- device_info는 프론트가 UA·innerWidth·platform 보내면 서버가 저장
- 배포·health → 보고 → **커밋**(DB+백엔드)
