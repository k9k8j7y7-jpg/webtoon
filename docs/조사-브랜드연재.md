## ① `create_initial_gate_status` 프리셋 값

파일: `backend/app/workflow/gate.py` L4–9

```python
PURPOSE_PRESETS = {
    "onecut_ad":    {"is_ad": True,  "aspect_ratio": "1:1",  "page_format": "single_page", "target_cuts": 1},
    "instatoon_ad": {"is_ad": True,  "aspect_ratio": "1:1",  "page_format": "grid_2x2",    "target_cuts": 4},
    "brand_series": {"is_ad": True,  "aspect_ratio": "9:16", "page_format": "vertical",     "target_cuts": None},
    "story":        {"is_ad": False, "aspect_ratio": "9:16", "page_format": "vertical",     "target_cuts": None},

```

| 항목 | instatoon_ad | brand_series |
|---|---|---|
| `is_ad` | `True` | `True` |
| `aspect_ratio` | `1:1` | `9:16` |
| `page_format` | `grid_2x2` | `vertical` |
| `target_cuts` | `4` (초기값; 6/8 변경 가능) | `None` (자유) |

`target_cuts`가 None이면 `gate_status`에 키 자체가 삽입되지 않는다 (L53: `if preset["target_cuts"]:`).

단계 구조 (`AD_STEP_NAMES`, L85–95):
- `instatoon_ad`: total=4, 브리프(1)→대본(2)→준비(3)→완성(4/5)
- `brand_series`: total=4, **동일** — 브리프(1)→대본(2)→준비(3)→완성(4/5)

## ③ `get_ad_script_addon` — brand_series 대본 구조

파일: `backend/app/script/prompt_fragments.py` L139–155

```python
def get_ad_script_addon(target_cuts: int | None = None) -> str:
    if target_cuts and target_cuts in _AD_CUT_STRUCTURES:
        # instatoon_ad 전용 경로: 4/6/8컷 구조 강제
        return f"... 반드시 정확히 {target_cuts}컷 ..."
    return AD_SCRIPT_INSTRUCTION_ADDON   # ← brand_series 폴백
```

**brand_series 실제 수신 addon = `AD_SCRIPT_INSTRUCTION_ADDON`** (L98–128 부근):
- 광고 웹툰 완결 필수 + 제품 자연 노출 원칙
- 컷 수 지정 없음 — AI 자유 결정
- 모델 1명 원칙 · 헤드카피·서브카피 dialogue 삽입 지시

instatoon_ad(target_cuts=4)와의 차이:
- `_AD_CUT_STRUCTURES[4]` = `[훅, 문제, 해결, CTA]` 4컷 강제 구조 **없음**
- 컷 수 불일치 재시도 로직 **없음** (service.py L221–236 미적용)

## ④ 에피소드 2화 이상 — 캐릭터·제품·브리프 인계

### 캐릭터
`backend/app/characters/models.py` L24–25:
- `Character` 모델: `project_id` + `episode_id` 컬럼 모두 존재
- 캐릭터는 **프로젝트 범위**로 저장되나 에피소드에는 `link` 엔드포인트로 연결
- `GET /projects/{project_id}/characters` (router.py L568): 프로젝트 전체 캐릭터 조회 가능
- **자동 인계 없음** — 새 에피소드 생성 시 캐릭터는 연결 안 된 상태. Gate3에서 프로젝트 라이브러리 피커를 통해 수동으로 link 필요

### 제품
`backend/app/products/models.py` L13:
- `Product` 모델: `episode_id`만 있고 `project_id` 없음 → **에피소드 단위 격리**
- **자동 인계 없음** — 2화 생성 시 제품을 처음부터 다시 등록해야 함

### 아이디어 브리프
`backend/app/projects/router.py` L112–134 (`create_episode`):
- 새 에피소드 생성 시 `create_initial_gate_status(idea=body.idea, ...)` 호출
- `idea`는 POST body에서 직접 받음 (`EpisodeCreate` 스키마)
- 이전 에피소드의 `idea_brief`를 읽어 복사하는 로직 **없음**
- brand_series 2화: AdBriefForm 처음부터 새로 작성 필요

### 결론 ④
brand_series 2화+ 에피소드는 1화와 **캐릭터·제품·브리프 모두 인계 없음**. 캐릭터만 프로젝트 라이브러리에 저장되어 수동 link 가능; 제품·브리프는 에피소드마다 재입력.

## 종합 결론

**brand_series는 instatoon_ad와 거의 동일하나 아래 3가지가 다르다:**

| 차이점 | instatoon_ad | brand_series |
|---|---|---|
| 비율 | `1:1` | `9:16` |
| 페이지 형식 | `grid_2x2` | `vertical` |
| 컷 수 | 4/6/8 선택 + 구조 강제 | 자유 (제한 없음) |

나머지 — 브리프 폼, 대본 생성 흐름, Gate3 자산, Gate4 콘티 자동, Gate5 이미지, GPT 기본 전환, 캐릭터·제품·브리프 인계 없음 — 은 **인스타툰과 완전 동일**.
