# 지시서 — 형식/레이아웃 선택 (세로 웹툰 · 2x2 페이지 · 3단 페이지)

> 원칙: 단계마다 멈추고 보고. 커밋은 도도 검증 후. 마이그레이션 없음
> (gate_status JSON). 이미지 생성 검증은 **새 단편 1개, 컷 4장**까지만.
> 근거: docs/조사-형식레이아웃.md (2026-10-01)
> [근거] 도도 결정 — 인스타툰처럼 한 페이지에 여러 컷을 배열하는 형식.
> 템플릿은 **2x2·3단 두 개로 픽스**(확장 가능 구조만 남김). 형식이 컷
> 비율을 결정. 뷰어·내보내기는 페이지 단위. 컷 내용은 콘티가 이미
> 컷마다 다르므로 "같은 그림 쪼개기"가 아님.

## 목표 (도도가 화면에서 보게 되는 것)
- 게이트3 "컷 비율" 위에 **"형식"** 선택 카드 3개: 세로 웹툰 / 2x2 페이지 /
  3단 페이지 (그림 아이콘 + 한 줄 설명). 2x2·3단을 고르면 비율이 자동으로
  1:1·16:9로 잠기고 비율 카드는 비활성 표시. 세로 웹툰이면 지금처럼 5종
- 첫 이미지 생성 후 형식 잠금(비율과 동일 규칙)
- 게이트4 콘티: 형식에 맞는 샷 구성(2x2 = 클로즈업·바스트 위주, 3단 =
  가로 구도·인물 좌우 배치). 컷 수는 지금처럼 대본 기준이되 2x2는 4의
  배수, 3단은 3의 배수로 맞추도록 유도(마지막 페이지 빈 칸 허용)
- 게이트5: 컷 카드는 그대로. 상단에 **[페이지 미리보기]** 토글 → 페이지
  단위로 합성된 모습(칸 사이 흰 여백·얇은 테두리)
- 공개 뷰어: 형식대로 표시 — 세로는 현행, 2x2·3단은 페이지 단위 세로
  스크롤(페이지 사이 간격 48px)
- 내보내기: [인스타]·[A4]는 페이지 이미지, [세로]는 페이지를 세로로 이어
  붙임, [PNG ZIP]은 컷 원본 그대로 + 페이지 이미지도 함께
- 기존 에피소드는 전부 세로 웹툰(변화 없음)

## 0단계 — 형식 정의 (단일 소스)
- `frontend/src/utils/pageFormats.js` + 백엔드 `workflow/page_formats.py`
  (동일 내용, 나중에 API 한 곳으로 합쳐도 됨):
  ```
  vertical: { label:'세로 웹툰', cols:1, rows:null, cell_ratio:null(자유), per_page:null }
  grid_2x2: { label:'2x2 페이지', cols:2, rows:2, cell_ratio:'1:1',  per_page:4, page_ratio:'1:1' }
  strip_3:  { label:'3단 페이지', cols:1, rows:3, cell_ratio:'16:9', per_page:3, page_ratio:'3:4' 근사(16:9×3+여백) }
  ```
  gap·테두리·배경색 상수 포함. 템플릿 추가 = 여기 한 줄
- gate_status.page_format (기본 'vertical'), 잠금은 aspect_ratio 잠금
  로직에 함께 태움. 백엔드 승인·이미지 생성 시 형식↔비율 정합성 검증
  (2x2인데 비율 9:16이면 400)

## 1단계 — 백엔드
- Gate3 승인 API: page_format 저장 + cell_ratio를 aspect_ratio로 강제
- 콘티 생성(storyboard) 프롬프트: 형식별 가이드 문단 주입 — 2x2 "small
  square panels: prefer close-up/bust, one subject per panel", 3단
  "wide horizontal panels: side-by-side characters, environment visible".
  컷 수 유도(4·3의 배수) — 강제 아님
- 컷 생성(images): aspect_ratio는 이미 컷 프롬프트에 들어가므로 변경
  없음. 형식 정합성 검증만
- 기존 에피소드 폴백 'vertical' 전수 확인

## 2단계 — 프론트: 게이트3 형식 선택 + 게이트4 안내
- Gate3Assets: "형식" 카드 3개(글리프는 CSS로 그린 격자 미니 아이콘 —
  이미지 생성 아님). 선택 시 비율 카드 자동 설정·비활성. 읽기 전용에도
  현재 형식 표시. 다크 대응(.glass-card 톤)
- Gate4Storyboard: 상단에 "이 에피소드는 2x2 페이지 형식 — 4컷마다 한
  페이지" 안내 한 줄. 컷 카드에 페이지 번호·칸 위치 배지(P1-③)
- 배포 → 도도 확인(새 단편 "형식 테스트": 2x2 선택 → 비율 1:1 자동 →
  콘티 생성 → 카드에 P1-①… 배지) → 커밋

## 3단계 — 페이지 합성 (프론트 Canvas) + 게이트5 미리보기 + 뷰어
- `composePageGrid(cuts, format)` — exportAsA4Grid 일반화. 각 컷은
  renderCutToCanvas(원본 크기, 오버레이 포함) → 셀 크기로 축소 배치.
  셀 간 gap, 페이지 배경 흰색, 셀 테두리 1px 옅은 회색
- Gate5Review: [페이지 미리보기] 토글 → 페이지 이미지들을 세로 나열
  (읽기 전용, 클릭 시 해당 컷 카드로 스크롤). 세로 웹툰이면 토글 숨김
- ViewerPage: page_format 읽어서 vertical은 현행, 그 외는 페이지 단위
  표시(CSS Grid로 실시간 렌더 — Canvas 아님, 말풍선 오버레이 그대로).
  페이지 간 48px
- 배포 → 도도 확인(컷 4장 생성 → 미리보기 → 공개 뷰어) → 커밋

## 4단계 — 내보내기
- exportRenderer: page_format 분기 — 인스타 = 페이지 1장씩 1080×1080
  (3단은 1080×1350), A4 = 페이지를 A4에 맞춰(2x2는 1페이지/A4, 3단은
  1페이지/A4), 세로 = 페이지를 세로로 이어 붙임(간격 CUT_GAP_PX), ZIP =
  컷 원본 + pages/ 폴더
- 세로 웹툰 에피소드는 현행 경로 그대로(회귀 없음 확인)
- 배포 → 도도 확인([인스타]·[세로] 1회씩) → 커밋
