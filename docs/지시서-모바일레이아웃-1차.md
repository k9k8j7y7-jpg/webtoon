지시서 — 모바일 레이아웃 정리 1차 (뷰어·스텝바·게이트5)

원칙: 단계마다 멈추고 보고. 커밋은 도도 검증 후. 백엔드 변경 없음. 기준: 폭 640px 미만 = 모바일(Tailwind sm: 경계). PC 레이아웃은 아래 "PC도 적용" 표시된 항목 외에는 건드리지 않음. 검증: 도도가 크롬 F12 → Ctrl+Shift+M → Galaxy S20 Ultra / iPhone 14 Pro 두 기기로 확인. Claude Code는 배포 전 Playwright로 375px·412px 스크린샷 자체 확인(예전 frontend/scripts의 mobile-375 방식 재사용). [근거] 도도가 폰에서 직접 겪은 문제 4건 + Claude 제안(게이트4 카드 1열)

목표 (도도가 화면에서 보게 되는 것)
공개 뷰어: 컷과 컷 사이가 확실히 벌어져 "다음 컷"으로 읽힘
게이트 스텝바: 5개 게이트가 겹치지 않고, 현재 게이트가 항상 보임
게이트5 상단: "게이트5 — 이미지 검수" 제목이 가로로 정상, 내보내기 버튼 4개가 그 아래 한 줄
게이트5 컷 카드: 모바일에서 한 줄에 1개, 버튼이 한 줄에 정리
게이트4 콘티 카드도 모바일 1열 (Claude 제안 — 같은 원칙)
0단계 — 조사 (수정 금지, 보고 후 진행)
공개 뷰어 컷 간 간격이 정의된 곳(컴포넌트·클래스·현재 px). PC/모바일 동일 값인지
GateProgress.jsx 스텝바 구조(flex? 고정 폭?)와 모바일에서 겹치는 원인
Gate5Review.jsx 상단 헤더: 제목이 세로로 깨지는 원인(flex-nowrap + 버튼 min-width 추정), 내보내기 버튼 4개 컨테이너
Gate5·Gate4 컷 카드 그리드 클래스(grid-cols-2? md:grid-cols-3?)와 카드 내 버튼 컨테이너
기존 모바일 스크린샷 스크립트(frontend/scripts/mobile·p*-screenshot) 재사용 가능 여부
예상 수정 파일 목록
1단계 — 뷰어 컷 간격 (PC도 적용)
컷 사이 세로 간격을 현재의 약 5배(예: 8px → 40px)로. 값은 상수 하나로 (예: CUT_GAP_PX) 뷰어 컴포넌트 상단에 두고 내보내기 [세로]도 같은 값을 쓰는지 확인 — 내보내기 이미지 간격은 이번엔 건드리지 않음 (내보내기는 별도 판단), 화면 뷰어만
간격 배경은 지금 뷰어 배경색 그대로(검정/짙은 색)
컷 하나뿐인 에피소드·마지막 컷 아래 여백은 기존 유지
2단계 — 게이트 스텝바 (모바일만)
640px 미만: 컨테이너 overflow-x-auto + flex-nowrap + 각 스텝 shrink-0, 스크롤바 숨김(scrollbar-hide 유틸 또는 CSS)
현재 게이트가 화면 밖이면 마운트 시 scrollIntoView({inline:'center', block:'nearest'})로 자동 스크롤 (게이트 바뀔 때도)
라벨은 자르지 않고 전체 표시("콘티&장소"). 스텝 사이 연결선 유지
PC(640px 이상)는 지금 그대로
3단계 — 게이트5 상단 헤더 + 내보내기 버튼 (모바일만)
640px 미만: 헤더를 세로 스택 — 1줄 제목("게이트5 — 이미지 검수", 가로, 줄바꿈 허용), 2줄 내보내기 버튼 4개를 grid grid-cols-4 gap-2 로 균등 배치. 각 버튼은 아이콘 + 라벨(세로·인스타·PNG·A4) 한 줄, 글자 세로 깨짐 방지(whitespace-nowrap, 필요 시 text-xs)
제목이 세로로 깨진 원인(폭 0으로 눌린 flex 아이템 등)을 근본 수정 — 단순히 min-width만 늘리는 방식 금지
PC는 지금 그대로
4단계 — 컷 카드 1열 (모바일만, 게이트5 + 게이트4)
640px 미만: 카드 그리드 grid-cols-1. 카드 폭 = 화면 폭 − 좌우 여백
게이트5 카드 버튼 줄: 재생성·되돌리기·편집·콘티·대사를 한 줄에 (flex flex-wrap gap-2, 1열이면 대부분 한 줄에 들어감. 안 들어가면 아이콘+짧은 라벨로 축약). 터치 타깃 높이 최소 40px
게이트4 콘티 카드도 grid-cols-1, 카드 내부 텍스트 줄바꿈 정상 확인
썸네일은 카드 폭에 맞춰 커짐(9:16·1:1 비율 유지, object-contain)
PC(md 이상) 열 수는 지금 그대로
5단계 — 자체 확인 → 배포 → 도도 검증
Playwright 375px·412px에서 뷰어·게이트4·게이트5 스크린샷 찍어 frontend/scripts/mobile-check/ 에 저장(gitignore), 겹침·세로 글자· 가로 스크롤 튀어나옴 없음 육안 확인 후 보고
프론트 빌드·배포 → 도도가 크롬 모바일 모드로 확인:
 공개 뷰어 "자연바람 아로마 헤어팩 광고": 컷 사이 확실히 벌어짐
 "장소 테스트2" 게이트5: 스텝바 5개 겹침 없음, 좌우 스크롤로 "콘티&장소" 전체 보임, 현재 게이트가 보이는 위치
 게이트5 제목 가로, 버튼 4개 한 줄
 컷 카드 1열, 버튼 한 줄, 썸네일 커짐
 게이트4 콘티 카드 1열
