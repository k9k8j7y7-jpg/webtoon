> 도도가 11-18~19 직접 점검한 결과. **광고 트랙(한 컷·인스타툰·연재·상세페이지)만** 손댄다. 이야기 트랙(story)·생성 로직·프롬프트·explain.py·패킷 차감 규칙은 건드리지 않는다.
> 순서: 전부 구현 → 빌드·배포 → 검증(값·캡처) → 보고 → 도도 확인 후 커밋.

## A. 캐릭터 피커 (Gate3Assets · DetailPrepare)

**(101) 교체 토스트** — 지금은 이름이 같으면 "모델 → 모델(으)로 바꿨어요"가 된다.
- 새 캐릭터 이름 뒤에 **출처 작품 제목**을 붙인다: `모델 → 모델(자연바람 헤어팩 연재툰)로 바꿨어요`. 출처가 없으면(프리셋·같은 작품) 그림체 한글 라벨: `모델(애니메이션풍)`.
- 토스트가 **모달 위에**, 3초 이상 보이는지 확인(z-index·duration). 도도가 교체 후 토스트를 본 기억이 없음.

**(102) 그림체 영문 키 노출** — 주황 안내문 "현재 스타일과 다른 그림체(anime)로 만든 캐릭터입니다"의 `anime` 등 → 기존 한글 매핑(한국 웹툰체·애니메이션풍·SD 개그 등) 재사용. 피커 카드의 태그(`sd gag`·`korean webtoon`)도 같은 매핑.

**(103) 카드 이미지 순서** — 캐릭터 카드는 항상 **정면 → 표정 시트** 순. 지금 복원된 "모델" 카드는 표정이 먼저 옴(이미지 id 순 정렬 때문). label 기준 정렬(front 먼저).

## B. 광고 완성 화면 (Gate5Review 광고 분기)

**(109) 한 컷 광고 버튼 4개로** — 한 컷(onecut_ad)은 결과물이 그림 1장이라 세로·인스타·PNG·A4가 같은 그림을 4번 준다. onecut_ad일 때만 상단 버튼을 **[이미지 저장] [인스타 공유] [움직이게/MP4] [릴스 영상]** 4개로.
- [이미지 저장] = 기존 PNG 1장 다운로드(zip 아님, 파일 1개).
- [움직이게/MP4]: 모션 없으면 "움직이게 · 4패킷"(기존 동작), 완료되면 "MP4 저장".
- "페이지 미리보기" 토글은 한 컷에서 제거(컷 1장이 곧 페이지). 인스타툰·연재·상세는 기존 그대로.

**(104) 크게 보기 진입 표시** — 컷을 클릭하면 전체화면 뷰어(#1/1)가 열리지만 도도가 못 찾음. 컷 썸네일 오른쪽 아래에 **돋보기 아이콘**(hover/항상) + 전체화면 뷰어는 그대로.

**(105) PC 인스타 공유** — `navigator.share` 없는 환경에서 [공유하기]가 아무 반응 없음.
- 모달 열 때 share 미지원이면 버튼을 **[이미지 저장 + 캡션 복사]** 로 바꾸고 아래 한 줄: "PC에서는 공유창이 안 떠요. 저장한 이미지를 인스타 앱에서 올리고 캡션을 붙여 넣어요."
- 누르면 이미지 다운로드 + 클립보드 복사 + 토스트 "이미지 저장·캡션 복사 완료".

**(106) 내보내기 모달 내부 키** — "a4_grid 내보내기 / 총 1컷이 a4_grid으로 저장되었어요" → 포맷 한글 라벨 맵(세로 1장·인스타 정사각·PNG 묶음·A4 인쇄용·움직인 컷 MP4). 모든 내보내기 모달 제목·본문에 적용.

**(107) 다운로드 파일명** — `episode_162_vertical_single.png`, `cut_1.mp4` → **작품 제목 기준**: `{작품제목}_{포맷}.{ext}` 예 `정보전달_세로.png`, `정보전달_컷1.mp4`, `정보전달_인스타.zip`. 제목은 파일명 안전 처리(공백→_, 특수문자 제거, 40자 제한), 없으면 "이지툰_작품{id}". 백엔드 Content-Disposition과 프론트 a[download] 둘 다.

**(108) 인스타 공유 캡션** — 광고 4종은 "EziToon으로 만든 웹툰" → **"EziToon으로 만든 광고툰"**. 제목 줄은 그대로(작품 제목). 이야기 트랙은 "웹툰" 유지.

**(110) [편집] 두 번 누름** — 컷 카드 [편집]을 누르면 "보기 모드"로 열리고 상단 [편집]을 또 눌러야 함 → 카드의 [편집]은 **바로 편집 모드**로 진입. 컷 클릭(크게 보기)은 보기 모드 유지.

**(114) 글자 신고 alert** — "글자가 틀렸나요?" 결과가 브라우저 `alert("이 버전은 이미 신고했습니다")` → 토스트로(성공 "신고 완료, 패킷을 돌려드렸어요" / 중복 "이 버전은 이미 신고했어요"). 코드 전체에서 사용자 화면 `alert(`·`confirm(` grep → 목록 보고(이번엔 이것만 고치고 나머지는 목록만).
