# 조사 — 에피소드 형식/레이아웃 (2026-09-30)

> 수정 금지 — 조사 결과만 기록

## 배경

에피소드 형식을 게이트3에서 선택:
- **세로 웹툰** (현행) — 컷 비율 자유(1:1/9:16/16:9/3:4/4:3), 세로 스크롤 뷰어
- **2×2 페이지** — 컷 1:1, 페이지당 4칸, 만화책 느낌
- **3단 페이지** — 컷 16:9, 페이지당 3칸, 시네마틱

형식이 컷 비율을 결정하고, 뷰어·내보내기는 페이지 단위 합성. 템플릿 추가 확장 가능 구조.

## (1) 현재 aspect_ratio 저장·잠금·UI

### 저장 위치

`episodes.gate_status` JSON 컬럼 (MariaDB JSON, step24 마이그레이션):

```json
{
  "current_gate": 5,
  "aspect_ratio": "9:16",
  "aspect_ratio_locked": true,
  ...
}
```

### 헬퍼 함수 (`backend/app/workflow/gate.py` 110-124행)

- `get_aspect_ratio(gate_status)` → "1:1" | "9:16" | ... (레거시 없으면 "1:1")
- `is_aspect_ratio_locked(gate_status)` → bool (레거시 없으면 True)
- `lock_aspect_ratio(gate_status)` → 새 gate_status (locked=True)

### 잠금 시점 (`backend/app/images/service.py` 342-343행)

첫 이미지 생성 시 잠금:
```python
if not is_aspect_ratio_locked(episode.gate_status):
    episode.gate_status = lock_aspect_ratio(episode.gate_status)
```

### 비율 선택 UI (`Gate3Assets.jsx` 827-860행)

5개 버튼(1:1 / 9:16 / 3:4 / 16:9 / 4:3), 잠금 시 비활성. 선택 → POST `/aspect-ratio`.

### 백엔드 검증 (`workflow/router.py` 78-108행)

```python
ALLOWED_ASPECT_RATIOS = ("1:1", "9:16", "16:9", "3:4", "4:3")
```
잠금 상태이면 거부(400).

## (2) 뷰어·내보내기 합성 방식

### 뷰어 (`ViewerPage.jsx`)

컷을 세로 스택으로 렌더 (135-137행):
```jsx
<main className="max-w-2xl mx-auto flex flex-col pb-12" style={{ gap: CUT_GAP_PX }}>
  {data.cuts.map((cut, i) => <CutViewer key={i} cut={cut} products={data.products} />)}
</main>
```
각 `CutViewer`는 이미지 + ProductLayer + EffectLayer + BubbleOverlay + PngBubbleLayer + SfxLayer 오버레이.

### 내보내기 4경로 (`frontend/src/utils/exportRenderer.js`)

#### 공통 핵심: `renderCutToCanvas()` (52-262행)

이미지 로드 → Canvas에 그림 → SVG 오버레이(제품·효과·말풍선·PNG말풍선·효과음) 합성 → Canvas 반환.

**오버레이 합성 방식:** SVG viewBox를 REF_WIDTH(400) 기준으로 스케일 → serialize → Blob → Image → drawImage. 좌표는 **상대 비율(0~100%)**로 저장되어 있으므로 **viewBox 재설정만으로 임의 크기 셀에 맞출 수 있음**.

#### ZIP (`exportAsPNGZip` 318-341행)
개별 컷 PNG를 ZIP으로 묶음.

#### 세로 (`exportAsVertical` 345-390행)
모든 컷을 세로로 이어붙인 하나의 긴 PNG.

#### 인스타 (`exportAsInstagram` 396-443행)
각 컷 → 1080×1080 정사각에 레터박스.

#### A4 그리드 (`exportAsA4Grid` 503-576행) — **재사용 선례**

```javascript
A4_WIDTH = 2480, A4_HEIGHT = 3508  // 300 DPI
A4_MARGIN = 59
GRID_COLS = 4, GRID_ROWS = 3      // 4×3 = 12칸/페이지
GRID_GAP = 20

cellW = Math.floor((contentW - GRID_GAP * (COLS-1)) / COLS)  // ~576px
cellH = Math.floor((contentH - GRID_GAP * (ROWS-1)) / ROWS)  // ~1113px
```

12칸 초과 시 다중 페이지 → ZIP. 각 셀에 `renderCutToCanvas()` 결과를 aspect-fit 센터 정렬.

### 재사용 가능성

A4 그리드 로직을 **페이지 합성 함수로 일반화** 가능:
```javascript
composePageGrid(cuts, { cols, rows, pageW, pageH, margin, gap })
```
- 2×2 페이지: `{ cols: 2, rows: 2, pageW: 2480, pageH: 2480 }`
- 3단 페이지: `{ cols: 1, rows: 3, pageW: 2480, pageH: 3508 }`

### 말풍선·효과 좌표 변환

**불필요.** 좌표는 이미지 기준 상대 비율이므로 `renderCutToCanvas()`가 원본 이미지 크기로 합성 후 셀 크기로 축소. 개별 컷 Canvas가 올바른 좌표로 이미 합성되어 있으므로 페이지 합성 시 추가 좌표 변환 없음.

## (4) 페이지 합성: 프론트 vs 백엔드

| 항목 | 프론트 (Canvas) | 백엔드 (Pillow) |
|---|---|---|
| 현재 사용처 | 내보내기 4경로 + A4 그리드 | 말풍선 합성만 |
| 뷰어 실시간 | **가능** — 4컷 로드 후 Canvas 합성 | 불가 — 서버 요청 필요 |
| 오버레이 | SVG → Canvas 이미 구현 | 별도 구현 필요 |
| 성능 | 클라이언트 GPU 활용 | 서버 부하 |
| A4 선례 | ✅ `exportAsA4Grid` 있음 | ❌ 없음 |

**추천: 프론트** — 뷰어 실시간 표시 필수이고, A4 그리드 선례 재사용. 내보내기도 프론트 통합.

뷰어 구현:
```jsx
// 세로 웹툰: 기존대로 컷 세로 스택
// 2×2 페이지: 4컷씩 그룹 → <PageComposer cuts={4칸} cols={2} rows={2} />
// 3단 페이지: 3컷씩 그룹 → <PageComposer cuts={3칸} cols={1} rows={3} />
```

`PageComposer`는 CSS Grid 또는 Canvas로 구현 가능. CSS Grid가 뷰어에 더 적합(반응형·오버레이 자연스러움). 내보내기는 Canvas.

## (5) 기존 에피소드 호환

`gate_status`에 `page_format` 필드 없으면 → **세로 웹툰(현행)** 으로 동작.

헬퍼:
```python
def get_page_format(gate_status):
    return (gate_status or {}).get("page_format", "vertical")
```

프론트:
```javascript
const format = gateStatus?.page_format || 'vertical';
```

기존 16+ 에피소드 모두 `page_format` 없음 → 자동으로 `"vertical"` → 현행과 동일.

## (6) 마이그레이션 필요 여부

**불요.** `gate_status`가 JSON 컬럼이므로 새 필드(`page_format`, `page_format_locked`) 추가는 코드 변경만으로 가능. 기존 행은 필드 없음 → 헬퍼가 기본값 반환.

단, `ALLOWED_ASPECT_RATIOS` 검증과 형식↔비율 매핑 로직 추가 필요:
```python
FORMAT_ASPECT = {
    "vertical": None,        # 자유 선택 (기존 5종)
    "2x2_page": "1:1",      # 강제 1:1
    "3row_page": "16:9",    # 강제 16:9
}
```
