## 개념
- **컷 종류** cut.kind: `scene`(기본, 지금 모든 컷) / `explain`(설명 컷)
- **시각 장치** cut.device (explain일 때): `zoom_inset` 확대 단면 /
  `icon_badges` 아이콘 배지 3 / `before_after` 전·후 반반 / `steps` 단계
  미니 패널 3 / `size_compare` 크기 비교
- 장치마다 **라벨**(한글, 짧게): zoom_inset 1개(예 "쿨링 · 각질 제거"),
  icon_badges 3개, before_after "사용 전 / 사용 후" 고정, steps 3개
  (예 "① 도포 ② 마사지 3분 ③ 헹굼"), size_compare 1개(예 "1000g 대용량")
  + 비교 대상(예 "300g")
- 캐릭터는 항상 등장(가이드 역할: 들고·가리키고), 제품 참조 필수

## 목표 (도도가 화면에서 보게 되는 것)
- **기획안**(광고 브리프 결과)에 **"보여줄 특징"** 섹션: 입력한 특징을
  AI가 장치로 매핑해 칩으로 제안(예 "쿨링·각질 제거 → 확대 단면",
  "그린티·보습·쿨링 → 아이콘 배지", "사용 전후 → 전·후 반반", "Step
  1~5 → 단계 패널", "1000g → 크기 비교"). 기본 체크: 8컷 3개, 6컷 2개,
  4컷 1개(가장 강한 것). 사용자가 끄고 켬. 0패킷
- **대본**: 체크된 장치가 구조의 포인트·사용법·해결 자리에 **설명 컷**
  으로 들어감. 카드에 **"설명 · 확대 단면"** 배지(보라), 라벨 텍스트가
  대사 자리에 보이고 "대사만 편집"에서 라벨 수정 가능. 1컷 훅·마지막 컷
  카피는 그대로 scene
- **완성**: 빈 카드 요약에 "설명 · 아이콘 배지" 머리말, 생성하면 scratch
  처럼 나옴. [콘티]에서 장치 변경(5종 칩) 가능 → 다시 그리기 1패킷
- **(59)** 빈 카드 콘티 요약 글자 한 단계 밝게(text-gray-300급)

## 1단계 — 백엔드
- **ad_brief**(prompts/ad_brief.py): 결과 JSON에 `visual_points: [{
  feature, device, labels[], compare?}]` 추가(제품 특징·활용법·웹 보완
  결과에서 추출, 최대 5, 장치 중복 허용). 프롬프트에 장치 5종 정의와
  라벨 규칙(한글·6자 이내·3개까지) 명시. idea_brief에 저장 + 사용자
  선택 `visual_points_selected`(PUT /idea-brief/selection 확장)
- **대본**(script/prompt_fragments get_ad_script_addon·brand addon):
  선택된 visual_points를 받아 구조의 포인트·사용법·해결 자리에
  `kind: explain, device, labels` 컷으로 배치하도록 지시. 컷 수·구조
  검증은 그대로(explain도 컷 1개로 셈). 대본 JSON cut에 kind·device·
  labels 필드. 기본값 scene
- **콘티**(storyboard): cut spec에 kind·device·labels 전달. explain 컷은
  shot=bust 고정, has_product=true 강제
- **이미지 프롬프트**(prompts/explain.py 신규, 한 곳): build_explain_
  clause(device, labels, product) — scratch 10장 프롬프트를 장치별
  템플릿으로 그대로 옮김(문구 변경 금지). 공통 머리 "advertising
  explainer panel in the same webtoon style; the character is the guide
  …; all text in Korean, spell exactly; no other text". 캐릭터 참조·
  제품 참조·스타일은 기존 경로. 모델 GPT 고정
- **글자 검사**: 기존 check_copy_text에 기대 텍스트 = labels 전달 →
  불일치 자동 재시도 1회(0패킷). 손 검사(check_anatomy) 그대로 적용
- PUT /cuts/{id}/device (explain 컷 장치·라벨 변경, 콘티 화면용)
