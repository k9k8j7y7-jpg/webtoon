## 흐름 (도도가 화면에서 보게 되는 것)
**STEP 1 브리프(제품 먼저)** — 입구 카드 "상세페이지"(준비 중 배지 제거)
→ 새 작품 → 브리프 **맨 위에 제품 사진**: 정면 1장 필수 + 선택(측면·
후면·탑뷰·손에 든 사진) → 올리면 분석(라벨·형태·색·크기 비율) → 제품명·
특징·활용법 칸이 분석값으로 **미리 채워짐** → 사용자가 고치고 [웹에서
보완] → 타깃·톤(기획안 톤: 후킹/정보/프리미엄) → [상세페이지 기획안
만들기](0패킷)

**STEP 2 대본(섹션)** — 기획안 형식 **섹션 8개 기본**: Intro(페인포인트)·
Hero(메인 카피+제품샷)·Point 1·2·3(장점)·How to Use(단계)·Check List
(이런 분께)·Outro(CTA). 각 섹션 카드: 제목·본문(편집 가능, 본문 60~180자
권장 표시)·**캐릭터 칩: 등장 / 제품만**(AI 기본값: Intro·How to Use·
Outro 등장, Hero·Point·Check List 제품만)·순서 바꾸기·삭제·[섹션 추가]
(Point 추가, 리뷰 등). 전체 [다시 만들기]·톤 칩. 승인 → 준비

**STEP 3 준비** — 스타일(korean_webtoon 기본)·캐릭터(등장 섹션 있을 때만:
저장된 캐릭터/새로 만들기)·제품 확인. 비율 **2:3 고정**(세로 스택 전제).
형식·장소·연출 강도 숨김. 승인 → 완성

**STEP 4 완성** — 섹션 카드(콘티 없음, 대본이 곧 콘티) 각 [이 섹션 생성 ·
1패킷] + [전부 생성 · N패킷]. 생성 → 검사 → 결과. [다시 그리기] 시트(메모·
캐릭터 칩 변경). **미리보기 = 세로 스택**(섹션 순서대로 이어붙임) ·
내보내기: 세로 긴 이미지 1장(폭 1024 또는 860, 쇼핑몰용) / 섹션별 PNG
zip / 공개(갤러리 배지 "상세페이지", 뷰어 세로 스크롤). "글자가 틀렸나요?"
신고 → 검사 → 환불+재생성(기존 copy-report 재사용)

## 1단계 — DB + 백엔드
- **step39.sql**: `product_photos(id, product_id FK, kind ENUM('front',
  'side','back','top','holding'), image_url, sort, created_at)` + 기존
  products.image_url은 front로 1행 복사(마이그레이션 DML). products.
  holding_photo_url 유지(호환). 리허설·백업·"실행해"
- POST /products/{id}/photos(kind, file) · DELETE. analyze는 front 기준,
  holding 있으면 크기 비율. 이미지 참조는 **front + 있으면 side/back 1장
  씩**(최대 3장, 토큰·비용 고려), holding은 비율 계산용
- purpose **detail_page** 추가: create_initial_gate_status(ratio 2:3,
  format vertical, target_cuts = 섹션 수), AD_STEP_NAMES 4단계(브리프·
  섹션·준비·완성), 이미지 모델 GPT 고정
- **prompts/detail_brief.py**: 기획안 생성 — 입력(제품명·특징·활용법·웹
  보완·타깃·톤) → 섹션 JSON `[{key, title, body, character: bool,
  visual_hint}]` 8개, 도도 기획안(docs/기획안-자연바람허브팩.md)을
  few-shot 예시로. 규칙: 본문은 **입력 사실만**, 수치·인증·효능은 입력에
  있는 것만(없으면 쓰지 않음), 한 섹션 본문 60~180자, 이모지 금지
- **prompts/detail_page.py** build_detail_prompt(section, product,
  style, character?): **3차 요청문 그대로** — "다음 내용을 한국 웹툰
  스타일의 상품 상세페이지 한 섹션(세로 2:3)으로 디자인. 제목·본문·
  포인트를 그림 안에 상세페이지답게 레이아웃. 한글은 정확히 그대로, 그
  외 글자 금지. 제품은 첨부 사진과 똑같이(라벨 포함, 다른 포장 금지)."
  + character면 "주인공 캐릭터(첨부 시트) 등장", 아니면 "사람·손·얼굴
  없이 제품과 인포그래픽만" + palette 강조색. **장치·레이아웃·템플릿
  문구 금지**. 참조: 제품 사진(최대 3) + 캐릭터 시트(등장 시) + 스타일
- **검사**(생성 후, 0패킷): ① 제목·본문 **문장 단위** 포함 여부(check_
  copy_text 확장, · • 등 부호 동치) ② **원문 외 문장 검출** — 비전으로
  이미지의 모든 한글 문장 추출 → 원문·라벨·제품명에 없는 문장이 있으면
  `extra_claims` 기록 → **효능·수치·인증 패턴**("효과", "%", "pH", "테스트
  완료", "인증", "특허", "1위" 등)이면 자동 재시도 1회(프롬프트에 "원문
  외 문장 절대 금지" 강조), 그래도 있으면 사용자에게 경고 배지 "확인
  필요한 문구: …" 표시 ③ 손 검사(등장 섹션만) ④ 제품 포장 일치(기존)
- 세로 스택: compose에 vertical_stack(섹션 순서, 폭 1024, 섹션 간 여백 0)
  → export 세로 1장 + 섹션 zip. 공개 뷰어 purpose detail_page = 세로
  스크롤. 갤러리 배지 "상세페이지"(광고 3종에 추가 → 4종)
- GET /my/works 타입 detail_page, 내 작품 필터 칩 추가, 입구 카드 활성
