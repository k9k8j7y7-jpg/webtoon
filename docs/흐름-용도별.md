# 용도별 흐름 — EziToon

> 배포 코드 기준 2026-10-28

## 핵심 차이 요약

1. **한 컷 광고**만 3단계(브리프→준비→완성), 나머지 광고 2종과 이야기는 5단계
2. 광고 3종은 Gate1에서 **AdBriefForm**(광고 브리프)을 쓰고, 이야기는 **아이디어 정리+등장인물 카드**를 쓴다
3. 한 컷 광고는 Gate1 안에서 대본까지 보여주고 편집·승인 → Gate2가 사용자에게 안 보임
4. 빠른 한 컷은 게이트 시스템 없이 **폼 1장 → 생성 → 결과** 직통 (1패킷)
5. 완성 후 할 수 있는 것(미리보기·인스타·릴스·모션·내보내기·공개)은 모든 트랙이 동일

## ⑤ 빠른 한 컷 (/quick)

**입구 3곳:**
- 랜딩 페이지 → _"한 컷 먼저 만들어보기 (1패킷)"_ 버튼
- 대시보드 → **빠른 한 컷** 카드
- GNB 드로어 → **빠른 한 컷** 메뉴

**게이트 시스템 없음** — 폼 1장 → 생성 → 결과 화면

| 구분 | 사용자 입력·선택 | 기본값 | 필수 |
|---|---|---|---|
| 캐릭터 | 프리셋 6종 버튼 (여성·남성·포메·고양이·어린이·할머니) | — | 필수 |
| 장면 | 한 줄 텍스트 (최대 200자) | 순환 placeholder | 필수 |
| 대사 | 한 줄 텍스트 (최대 100자) | 비어있음 | 선택 |
| 샷 | 자동 / 클로즈업 / 상반신 / 전신 | 자동 | 선택 |
| 스타일 | korean_webtoon / anime / emotional_romance | korean_webtoon | 선택 |
| 비율 | 1:1 / 4:5 / 9:16 | 1:1 | 선택 |
| 제품 사진 | 이미지 업로드 | 없음 | 선택 |

**[만들기]** → `POST /quick` → 프리셋 캐릭터 link + 에피소드 생성(Gate1~4 자동 승인) + 이미지 생성 **1패킷** (후차감)

| 결과 화면 버튼 | 동작 | 비용 |
|---|---|---|
| **인스타 공유** | InstaShareModal (Web Share API) | 0 |
| **PNG 저장** | composed 이미지 다운로드 | 0 |
| **말풍선 고치기** (대사 있을 때만) | CutEditor 모달 열기 | 0 |
| **다시 그리기 · 1패킷** | 확인 단계 → 재생성 | 1패킷 |
| **한 컷 광고로 제대로 만들기** | `POST /quick/{id}/expand?purpose=onecut_ad` → 새 프로젝트·에피소드 → ① 워크플로 | 0 |
| **이야기로 만들기** | `POST /quick/{id}/expand?purpose=story` → 새 프로젝트·에피소드 → ④ 워크플로 | 0 |
| 내 작품에서 보기 | 프로젝트 페이지로 이동 | 0 |
