# 조사: page_format 분기 + "한 컷 페이지" 형식 추가 시 손댈 지점

> 조사일 2026-10-15 · 수정 없음(읽기 전용 조사)

## 요약 6줄

1. **뷰어**: `ViewerPage.jsx:188-254` — `per_page`가 null이면 세로 스크롤(CUT_GAP_PX=48), 있으면 CSS Grid 페이지(cols·rows·frame). 한 컷 페이지는 `per_page:1, cols:1, rows:1`로 정의하면 기존 Grid 경로 타서 틀(테두리·여백·배경) 자동 적용
2. **composePageGrid / 내보내기**: `exportRenderer.js:763-841` — `per_page`가 null이면 원본 캔버스 그대로, 있으면 Canvas로 페이지 합성(margin·gap·border·bg). ZIP은 `pages/page_NN.png`, 세로는 페이지 이어붙이기, 인스타는 페이지별 letterbox, A4는 페이지→A4 맞춤. 한 컷 페이지는 `per_page:1`이면 모든 경로에서 "1컷=1페이지" 동작 — 추가 분기 불필요
3. **Pillow 합성(백엔드)**: 서버 쪽에는 page_format 기반 페이지 합성 없음. compose_cut은 컷 단위 말풍선·효과 렌더만. 백엔드 export(세로·인스타)도 컷 이어붙이기만 — **프론트 Canvas가 유일한 페이지 합성 지점**
4. **비율 잠금**: `page_formats.js`의 `cell_ratio`가 non-null이면 비율 강제(Gate3 비율 버튼 비활성 + 백엔드 검증 `images/service.py:357-363`). 한 컷 페이지는 `cell_ratio: null`(비율 자유)로 정의하면 비율 강제 없음 — 기존 vertical과 동일
5. **틀(frame) 코드 위치**: `pageFormats.js:12-18`의 `DEFAULT_FRAME`(`border_px:3, gap_ratio:0.025, margin_ratio:0.03, bg:#fff, stroke:#000`). 뷰어 CSS(`ViewerPage.jsx:219-227`)와 Canvas(`exportRenderer.js:788-834`)에서 동일 값 사용. 한 컷 페이지는 `frame: { ...DEFAULT_FRAME, gap_ratio: 0 }`(셀 1개이므로 gap 무의미)
6. **손댈 지점**: (A) `pageFormats.js` + `page_formats.py`에 `single` 정의 1줄(`per_page:1, cols:1, rows:1, cell_ratio:null, frame`) (B) Gate3 카드 UI에 아이콘 추가 (C) 콘티 FORMAT_SHOT_GUIDES에 single 가이드 추가(선택) (D) 기존 분기는 `per_page` null 체크로 동작하므로 뷰어·내보내기·A4 추가 코드 0줄 — composePageGrid가 1×1 Grid 자동 처리
