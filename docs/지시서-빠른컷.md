## 목표 (도도가 화면에서 보게 되는 것)
- 입구 3곳: 랜딩 CTA 아래 **[한 컷 먼저 만들어보기]**, 홈(/my) 상단
  카드 **[빠른 한 컷]**, 드로어 "만들기" 섹션 **빠른 한 컷**. 비로그인
  클릭 → 로그인 → /quick 복귀
- **/quick** 한 화면(폰 세로 스크롤):
  1. **누가** — 프리셋 캐릭터 6개 카드(미리보기 그림 + 이름: 여성 · 남성
     · 강아지 · 고양이 · 아이 · 할머니, **도도 확정**) / [내 캐릭터] 탭(기존
     캐릭터 있으면) / [내 사진으로](실사, 기존 실사 캐릭터 흐름·동의
     문구·비용 그대로, "1분쯤 걸려요")
  2. **뭘** — 장면 한 줄(필수, 예: "카운터에서 신메뉴 딸기라떼를 들고
     웃는다") + 대사 한 줄(선택, 예: "오늘만 20% 할인!") + 샷 칩(자동 ·
     클로즈업 · 상반신 · 전신)
  3. **어떻게** — 스타일 칩 **3개**(한국 웹툰체 korean_webtoon 기본 ·
     애니 anime · 감성 로맨스 emotional_romance, 도도 확정) + 비율 칩(1:1
     기본 · 4:5 · 9:16)
  - 하단 고정 **[만들기 · 1패킷]**(잔량 표시, 0이면 "패킷이 필요해요 →
    가격" 안내). 누르면 같은 화면이 "그리는 중… 20초쯤" → 결과
- **결과 화면**: 컷 한 장(말풍선 얹힘, 기존 CutImageWithBubbles) +
  버튼 줄: [인스타 공유] [PNG 저장] [다시 그리기 · 1패킷] [말풍선 고치기
  → 편집기] 그리고 큰 버튼 **[이 컷으로 이야기 만들기 →]**(STEP 1로,
  장면·대사·캐릭터 승계) + 작은 링크 "내 작품에서 보기"
- 만든 컷은 "빠른 컷" 프로젝트(유저당 1개 자동 생성)의 에피소드로
  남아서 내 작품에서 다시 열림

## 1단계 — 백엔드
- **마이그레이션**: characters에 `is_preset TINYINT(1) DEFAULT 0`(+ 인덱스).
  프리셋은 user_id·project_id NULL, is_preset=1. link/조회 가드에
  is_preset 예외(읽기 전용, 수정·삭제는 관리자만)
- **프리셋 6개 생성**(관리자 스크립트, 도도 "실행해", 패킷은 관리자 계정
  6개): 이름·appearance_en·미리보기 1장(정면 상반신, korean_webtoon,
  1:1). 목록은 도도 확정(여성·남성·강아지·고양이·아이·할머니), 외형
  문구는 기본안:
  - 여성: 30대, 긴 검은 머리, 베이지 가디건에 밝은 원피스, 밝은 미소
  - 남성: 30대, 짧은 머리, 흰 셔츠, 친근한 인상
  - 강아지: 갈색 포메라니안, 분홍 하네스
  - 고양이: 회색 줄무늬, 초록 눈
  - 아이: 7세, 노란 티셔츠, 단발
  - 할머니: 60대, 흰 머리 단정하게, 꽃무늬 블라우스, 인자한 미소
- **POST /quick** body {character: {preset_id | character_id}, scene,
  dialogue?, shot, style, aspect}
  - 거부: 로그인 없음 401, scene 빈 값, 패킷 부족 402(기존 코드와 동일
    응답), 이미 running인 quick job 있으면 409 "그리는 중이에요"
  - 유저의 "빠른 컷" 프로젝트 없으면 생성(name "빠른 컷", 일반 프로젝트,
    갤러리 노출은 공개 전까지 없음). 프리셋이면 **캐릭터를 그 프로젝트로
    복사**(appearance·미리보기 참조, is_preset=0, 원본 id는 spec.from_
    preset) — 이후 정식 흐름에서 내 캐릭터로 그대로 쓰이게
  - 에피소드 생성: 제목 = scene 앞 20자, page_format single_page, aspect,
    style, is_ad false. gate_status 1~4 = done(최소 데이터: idea_brief.raw
    = scene(+dialogue), planning_draft.characters=[char], 대본·콘티는
    빈 구조 + `quick: true` 플래그)
  - 컷 1개 spec: action=scene, shot(자동이면 "bust"), characters=[char],
    dialogue = [{type speech, text: dialogue}] (없으면 []), narration 없음
  - 기존 generate_cut_image 경로로 1패킷 차감·백그라운드 job → 202
    {episode_id, cut_id, job_id}. 실패 시 기존 환불 경로
- **GET /quick/{job_id}** → 상태·완료 시 cut(image_url·bubbles) 반환
  (기존 폴링 재사용)
- **다시 그리기** = 기존 /cuts/{id}/regenerate 그대로(1패킷)
- **이야기로 늘리기** = 기존 revert(to_gate=1) 호출 + 그 에피소드의
  idea_brief.raw·characters가 STEP 1 입력에 보이는지(조사 6번 경로).
  quick 플래그는 유지(통계용), 제목은 사용자가 STEP 1에서 바꿈
- generation_logs에 source=quick 기록

## 2단계 — 프론트
- 라우트 `/quick`(로그인 필요, 비로그인은 로그인 후 복귀 state 유지)
- 입구 3곳: 랜딩 히어로 CTA 아래 보조 버튼 "한 컷 먼저 만들어보기(1패킷)"
  (로그인 상태에서도 표시), 홈 /my 상단 카드 "빠른 한 컷 — 캐릭터 고르고
  한 줄이면 끝", 드로어 만들기 섹션 "빠른 한 컷"
- QuickPage: 섹션 3개 세로, 폰에서 한 화면에 1섹션씩 자연 스크롤.
  프리셋 카드 2열(폰)/3열(PC), 선택 테두리. [내 사진으로]는 기존 실사
  캐릭터 모달 재사용. 장면 input 플레이스홀더 예시 2개 로테이션. 샷·
  스타일·비율은 칩. 하단 sticky [만들기 · 1패킷 / 잔량 N]
- 생성 중: 같은 자리에 스켈레톤 + "그리는 중… 보통 20초" + 진행 점
- 결과: 컷(말풍선 오버레이) + 버튼 줄 + [이 컷으로 이야기 만들기 →]
  (revert 후 STEP 1로 이동) + "내 작품에서 보기". [인스타 공유]는 기존
  InstaShareModal(이미지 1장, 크레딧 체크 기본 ON), [PNG 저장]은 기존
  내보내기 1컷 경로, [말풍선 고치기]는 기존 CutEditor
- 잔량 0: 버튼 비활성 + "환영 패킷을 다 썼어요 — 체험 팩 3,900원" 링크
